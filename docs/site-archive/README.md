published (duplicate pages hurt search ranking). To roll back, copy a file over its counterpart in
`docs/site/` and push.

|---|---|
| `index-v1.html` | Landing up to 2 Nov 2026 (icon + gradient screenshot + feature cards) |
| `index-v2.html` | Landing with the live ⌥M demo, before the SEO pass |
| `guide-v2.html` | Guide in the new shell, before the SEO pass |
| `index-v3-seo.html` | Landing after the SEO pass (titles, JSON-LD, keyword lead) |
