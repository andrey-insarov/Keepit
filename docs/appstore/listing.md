## Description (4000 chars max)

Keepit keeps a history of everything you copy and lets you paste any of it again with a single hot key — plus reusable templates for the text you type every day.

PASTE ANYTHING YOU COPIED
• Press ⌥C anywhere: a menu with your recent clips opens right at the text cursor.
• Pick with the mouse, or type 1–9 / A–Z — the item is pasted into the app you're working in.
• Text, rich text, images (with thumbnails) and files are all kept.
• Duplicates are merged; recent items stay on top.

TEMPLATES FOR THE THINGS YOU TYPE EVERY DAY
• Signatures, addresses, canned replies, code snippets — organized in folders.
• ⌥T opens the template menu; give any template its own hot key for one-press pasting.
• Menu separators and shortcut letters, just like a real menu.

A VIEWER FOR EVERYTHING
• Browse history and templates in a tree, edit text and rich text in place, inspect every clipboard format, even as a hex dump.
• Drag history items into templates. Save any format to a file.

PRIVATE BY DESIGN
• Everything stays on your Mac. No account, no cloud, no analytics, no network.
• Copies from password managers are never recorded; concealed clipboard data is ignored.
• Optional password: history and templates are stored AES-256 encrypted; the key is wiped from memory when Keepit locks (manually, when the screen locks, or when the Mac sleeps).
• Touch ID unlock, and a 24-word recovery phrase in case you forget the password.

MADE FOR THE KEYBOARD
• Global hot keys, numbered menu items, per-app paste key overrides.
• Launch at login; lives in the menu bar, out of your way.

Keepit is inspired by the classic Windows clipboard tool CLCL and brings its workflow to macOS as a native app.

Keepit needs the Accessibility permission to paste for you; without it, chosen items are still copied to the clipboard.

## App Review notes
Keepit is a clipboard history manager. It asks for the Accessibility permission for exactly two
things: to send ⌘V to the frontmost application after the user picks an item from the popup menu,
and to read the position of the text cursor so the menu opens next to it. It does not read or
monitor other applications' content. Without the permission the app remains fully functional —
chosen items are copied to the clipboard and the user pastes manually; a dialog explains this.

How to test: launch Keepit (menu bar icon), copy some text in any app, press Option+C, choose the
item — it is pasted. Right-click the menu bar icon for the Viewer; Preferences are under the icon's
left-click menu. Password protection, Touch ID and the recovery phrase can be enabled in Preferences.

No account is needed. The app makes no network connections. Nothing leaves the Mac.
