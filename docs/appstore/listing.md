## Description (4000 chars max)

Keepit keeps a history of everything you copy and pastes any of it back with a single hot key — plus templates for the text you type every day and a paste queue for moving several things at once.

PASTE ANYTHING YOU COPIED
• Press ⌥M anywhere: a menu with your recent clips opens right at the text cursor.
• Type to search, pick with the mouse, or press 1–9 / A–Z — the item is pasted into the app you're working in.
• Hover an item for a preview panel; hold ⇧ for an extended menu: paste as plain text, UPPERCASE, Title Case, single line, add to templates, delete.
• Text, rich text, images (with thumbnails) and files are all kept. Duplicates are merged; recent items stay on top.
• ⌃⌥1–0 paste items 1–10 without opening the menu.

PASTE QUEUE
• Press ⌥N, copy several things in a row — the menu bar icon counts them — then ⌥V pastes them back one by one, in the same order. ⌥⇧N pastes everything that is left at once.

TEMPLATES FOR THE THINGS YOU TYPE EVERY DAY
• Signatures, addresses, canned replies, code snippets — organized in folders; ⌥T opens the template menu.
• Placeholders fill themselves in when you paste: today's date in any format, the clipboard, a question asked on the spot, a choice from a list, and where the cursor should end up.
• Give any template its own hot key. An Examples folder shows what placeholders can do.

A VIEWER FOR EVERYTHING
• Browse history and templates in a tree, search everything at once, edit text in place, inspect any clipboard format — even as a hex dump.
• Drag history items into templates. Save any format to a file.

PRIVATE BY DESIGN
• Everything stays on your Mac; backups, if you switch them on, go encrypted to a folder you choose. No account, no Keepit server, no analytics, no network — the app does not even hold the network entitlement.
• Concealed clipboard data is not recorded; copies from known password managers are excluded; any app can be excluded.
• Optional password: history and templates are stored AES-256 encrypted; the key is wiped from memory when Keepit locks — manually, or after the Mac has been locked or asleep for a time you choose.
• Touch ID unlock, and a 24-word recovery phrase in case you forget the password.
• Automatic encrypted backup to a folder of your choice — iCloud Drive, Dropbox, an external disk. Complete copies, opened with your Keepit password or recovery phrase on any Mac; the provider only ever sees ciphertext. Restore offered on the first launch of a new Mac.
• Save to Archive / Restore: one password-locked archive by hand, any time.

MADE FOR THE MAC
• Settings the Mac way: a pane for every topic, every change applies at once.
• Global hot keys for everything, per-app paste key overrides, launch at login.
• Lives in the menu bar, out of your way. Speaks 21 languages.
• keepit:// URL scheme for Shortcuts, Raycast and Alfred.

FREE AND OPEN SOURCE
Keepit is made by the team behind the it.com domain zone and is free, with no ads or in-app purchases. The source code is published on GitHub under the MIT license. Home: keep.it.com

Keepit needs the Accessibility permission to paste for you; without it, chosen items are still copied to the clipboard.

## App Review notes
Keepit is a clipboard history manager. It asks for the Accessibility permission for exactly two things: to send ⌘V to the frontmost application after the user picks an item from the popup menu, and to read the position of the text cursor so the menu opens next to it. It does not read or monitor other applications' content. Without the permission the app remains fully functional — chosen items are copied to the clipboard and the user pastes manually; a dialog explains this.

How to test: launch Keepit (menu bar icon). Copy some text in any app, press Option+M — the history menu opens; choose an item and it is pasted. Option+T opens the templates menu (an "Examples" folder is created on first launch). Option+E opens the Viewer window; Option+S (or ⌘, in the menu) opens Settings.

Paste queue: press Option+N, copy several things in a row (the menu bar icon shows a counter), then Option+V pastes them back one by one in the same order; Option+Shift+N pastes all remaining at once.

Optional password protection (Settings → Security): history and templates are stored AES-256-GCM encrypted in the app's container; the key is derived from the password and kept only in memory. Touch ID can stand in for the password. A 24-word recovery phrase is offered when the password is set. There is no account and no network use: nothing leaves the Mac. Settings → Advanced → Reset… deletes all local data and returns the app to a fresh install (asks for the password first).

Sandbox note: the only file access is user-selected — open/save panels for backup export/import and for adding files to templates, and a security-scoped bookmark for the automatic-backup folder the user chooses in Settings (entitlement com.apple.security.files.bookmarks.app-scope). Keepit never enumerates iCloud Drive or any other location on its own.
