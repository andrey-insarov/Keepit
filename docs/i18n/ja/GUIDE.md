# Keepitユーザガイド

KeepitはmacOS用の、クリップボード履歴とテンプレートを管理するアプリです。メニューバーに常駐し、コピーしたものをすべて覚えておいて、ショートカットでどの項目でもペーストできます。以下のショートカットはすべてデフォルトのもので、「設定」→「ショートカット」で変更できます。このガイドはKeepit 3について説明しています。Keepit 2.xのガイドは [keep.it.com/v2/guide](https://keep.it.com/v2/guide)（英語）にそのまま残してあります。

## パート1：はじめに

### インストール

**Homebrew**（おすすめ）。`brew upgrade` で常に最新の状態に保てます。

```bash
brew tap andrey-insarov/keepit https://github.com/andrey-insarov/Keepit
brew install --cask andrey-insarov/keepit/keepit
```

**DMG**。[最新リリース](https://github.com/andrey-insarov/Keepit/releases/latest)のページから `Keepit-<version>.dmg` をダウンロードして開き、Keepitを「アプリケーション」にドラッグします。

![DMG：Keepitを「アプリケーション」にドラッグ](site/img/guide/dmg.png)

はじめてアプリを開くと、インターネットからダウンロードされたアプリであり、Appleによるチェックが済んでいることをmacOSが確認します。「開く」をクリックしてください。

![macOSのGatekeeperによる確認](site/img/guide/gatekeeper.png)

Keepitは署名と公証を受けており、自動でアップデートされます。macOS 13 Ventura以降を搭載したAppleシリコンとIntelのMacでネイティブに動作します。

### 初回起動

Keepitはメニューバーアプリです。Dockにアイコンは表示されず、自分で開くまでウインドウもありません。初回起動後、メニューバーに 📎 アイコンが現れ、Keepitが3つのことを尋ねます。

**1. バックアップから復元しますか？** 新しいMacで、Keepitのバックアップ（iCloud Driveなどのフォルダにある自動バックアップ、または書き出した `.keepit` ファイル）がある場合は、「バックアップから復元…」を選ぶと、ほかの設定より先に履歴とテンプレートが戻ります。ファイルのロックは、そのファイルを作ったMacのパスワードかリカバリーフレーズで解除します。「新規に開始」を選ぶとこの手順を飛ばせます。同じ復元はあとから「設定」→「バックアップ」→「復元…」でも行えます。Finderで `.keepit` ファイルをダブルクリックしても開けます。詳しくは[バックアップ](#backup)をご覧ください。

![新しいMacでの最初の質問：バックアップから復元するか、新規に開始するか](site/img/guide/restore-first-run.png)

**2. パスワード（任意）。** Keepitは履歴とテンプレートを暗号化して保存し、Touch IDでロックを解除できます。今決めても、あとから「設定」→「セキュリティ」で決めてもかまいません。仕組みは[パート6](#part-6-security)で説明します。「後で」を選ぶと、すべて暗号化されないままディスクに保存されます。直前にバックアップをそのパスワードで復元した場合は、そのパスワードをこのMacでも使うかどうかをKeepitが尋ねます。

![初回起動時のパスワード設定の案内](site/img/guide/password-offer.png)

![「後で」を選んだ場合：それが何を意味し、どこで変更できるかをはっきり表示します](site/img/guide/no-password-notice.png)

**3. アクセシビリティの許可。** 代わりにペーストするために、Keepitは作業中だったアプリに ⌘V を送ります。macOSがこれを許すのは、「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」のリストにあるアプリだけです。「システム設定を開く」をクリックして、Keepitをオンにしてください。許可がなくても記録とコピーは行われますが、⌘V は自分で押すことになります。

![Keepitがアクセシビリティの許可を求める画面](site/img/guide/accessibility-prompt.png)

![「プライバシーとセキュリティ」→「アクセシビリティ」でKeepitをオンにしたところ](site/img/guide/accessibility-settings.png)

Keepitはデフォルトでログイン時に起動します。「設定」→「一般」でオフにできます。

## パート2：日常の使い方

### 履歴メニュー

どのアプリでも **⌥M** を押すか、📎 アイコンをクリックします。メニューは、Keepitがテキストカーソルの位置を取得できればその位置に、できなければマウスポインタの位置に開きます。

1行が1つのコピー項目で、新しいものが上に並びます。いちばん新しい項目は**太字**で、今クリップボードに入っている内容です。アイコンはコピー元のアプリを示します。タイトルの末尾が `…` の項目には、メニューに表示されている以上の行があります。画像はサムネイルで、ファイルリストはファイル名で表示されます。

![メニューの横のプレビューパネルに、選択中の項目の全体と、コピー元のアプリ、時刻、サイズが表示されます](site/img/guide/menu-preview.png)

![履歴の中の画像：メニューにはサムネイル、プレビューには画像全体](site/img/guide/menu-image.png)

項目をペーストするには、クリックするか、↑ ↓ で移動してReturnを押すか、**⌃⌥** と一緒に番号を押します。`⌃⌥3` で3番目の項目がペーストされます。同じキーは、メニューを開かなくてもどこからでも使えます。

履歴の下には、「テンプレート」サブメニュー、ビューア（⌥E）、設定（⌥S）、「履歴を消去」（⌥C）、「記録を 10 分間一時停止」（⌥P、記録したくないものを入力するときに使います）、パスワード設定時の「Keepit をロック」（⌥L）、アップデートが並びます。**⌥T** はテンプレートメニューだけを開きます。これらのキーはどれも、メニューを開かなくても使えます。

### 検索とプレビュー

**検索。** メニューが開いている状態で文字を入力し始めると、上部のフィールドがタイトルと全文でリストを絞り込みます。長い項目の途中の行も見つかります。Returnで最初の一致をペーストし、Escでフィールドを消去し、もう一度Escを押すとメニューが閉じます。

**プレビュー。** 項目にポインタを合わせる（またはキーボードで移動する）と、メニューの横のパネルに画像全体、または長いテキストの最初の数行が、コピー元のアプリ、日付、サイズとともに表示されます。1行の短いテキストは、メニューの行に全体が表示されているのでプレビューはありません。

![入力するとメニューが絞り込まれ、プレビューパネルに選択中の項目が表示されます](site/img/guide/search-preview.png)

### メニューを開かずにペースト

グローバルショートカットは、どのアプリからでも、その時点の履歴に対して働きます。1番目の項目がクリップボードです。

| キー | 動作 |
|------|--------------|
| `⌃⌥1` … `⌃⌥9`、`⌃⌥0` | 履歴の1〜10番目の項目をペースト |
| `⌥⇧V` | *ひとつ前*の項目（2番目）をペースト。もう一度押すと元に戻ります |
| `⌃⌥V` | クリップボードを書式なしテキストとしてペースト |
| `⌃⌥U` `⌃⌥L` `⌃⌥T` `⌃⌥S` | クリップボードを大文字 / 小文字 / 単語の先頭を大文字 / 文頭を大文字にしてペースト |
| `⌃⌥W` | クリップボードの前後の空白を取り除いてペースト |
| `⌃⌥J` | クリップボードを1行にまとめてペースト |
| `⌃⌥K` `⌃⌥D` `⌃⌥Y` | クリップボードを取り消し線 / 下線 / 波線付きでペースト。チャットを含め、どこでも見た目が保たれる標準テキストです（下記参照） |
| `⌃⌥X` | これらの装飾を取り除いてクリップボードをペースト |
| `⌃⌥A` | クリップボードをテンプレートに追加 |
| `⌃⌥⌫` | 履歴からいちばん新しい項目を削除 |

この3種類の装飾は書式ではありません。KeepitはUnicodeの*結合文字*を1文字ごとに付け加えます（s̶t̶r̶i̶k̶e̶、u̲n̲d̲e̲r̲、w̰a̰v̰y̰）。そのため、本来の書式が失われるメッセンジャーやWebフォーム、ターミナルでも同じ見た目になります。代わりに、テキストのサイズは3倍になり、元の単語で検索しても見つからず、スクリーンリーダーは読み上げにつまずき、フォントによっては線が不ぞろいに描かれます。「装飾を取り除く」（`⌃⌥X`）でこれらの記号を外せます。ほかの場所で装飾されたテキストにも使えます。どちらの場合も、記号は由来に関係なくコードポイントで取り除かれます。同じ記号を文字として使う発音表記（U+0330はIPAのきしみ声の記号でもあります）からも失われ、3種類の装飾も、付ける前にまずこれらを取り除きます。VoiceOverがオンのときは `⌃⌥` がVoiceOver自身の修飾キーになるので、「設定」→「ショートカット」で「最新の項目への操作」に別の修飾キーを割り当ててください。

変換はテキストに適用されます。画像やファイルリストの場合は警告音が鳴ります。これらはすべて「設定」→「ショートカット」で変更したりオフにしたりできます。

### 貼り付けキュー

ある場所で5つのものをコピーして、別の場所に順番どおりペーストしたいことがあります。フォームへのセルの転記や、ページから書類への行の転記などです。貼り付けキューを使えば、メニューを開かずにできます。

1. **⌥N** を押します（またはメニューで「貼り付けキューを開始」を選びます）。メニューバーのアイコンに赤い点とカウンタが表示されます：`📎 ● 0`
2. いつもどおり ⌘C で、好きなだけコピーします。コピーするたびにカウンタが 1、2、3… と増えます。すべて履歴にも記録されます。

   ![キューがオンのときのメニューバー：赤い点とカウンタ](site/img/guide/queue-menubar.png)

3. テキストを入れたい場所に切り替えて、項目ごとに **⌥V** を押します。最初にコピーしたものが最初にペーストされ、カウンタが減っていきます。⌘V はいつもどおりクリップボードをペーストするので、両方を組み合わせて使えます。
4. 最後の項目をペーストするか、コピーもペーストもしないまま2分たつと、キューは自動的にオフになります（時間は調整できます）。もう一度 ⌥N を押すと途中で止められます。

**⌥⇧N** は、キューに残っているものをまとめてペーストします。項目の区切りは改行、タブ、スペース、なしから選べます。設定の「貼り付けキュー」パネルで選び、待ち時間もそこで設定します。キューがオンの間、履歴メニューにはキューの項目に印が付きます。`▶` は次にペーストされる項目、`○` は待機中、`✓` はペースト済みです。

![キューがオンのときの履歴メニュー：○ 待機中、▶ 次、✓ ペースト済み。メニューの行に残りの数が表示されます](site/img/guide/queue-menu.png)

![「設定」→「貼り付けキュー」](site/img/guide/prefs-queue.png)

### 拡張メニュー

履歴メニューが開いている状態で **⇧** を押したままにすると、各項目に `▸` サブメニューが付き、その項目に対するすべての操作が並びます。ペースト、書式なしテキストとしてペースト、コピーのみ（クリップボードに入れるだけでペーストしない）、「変換してペースト」の各種変換、テンプレートに追加、ビューアで表示、削除です。項目にポインタを合わせるか → を押すと開きます。開いたあとは ⇧ を離してかまいません。

![⇧ を押したままにすると各項目にサブメニューが付きます。いちばん新しい項目ではグローバルショートカットが表示されます](site/img/guide/extended-menu.png)

いちばん新しい項目のサブメニューには、上の表のグローバルショートカットが表示されます。同じ操作に同じキーが割り当てられているので、ここで覚えられます。ほかの項目では、操作だけがキーなしで表示されます。ショートカットは、どこでも使えるものだけを表示しています。

![ほかの項目では、同じ操作がショートカットなしで表示されます](site/img/guide/extended-menu-item2.png)

![画像の場合、テキスト用の操作はグレー表示になります。使えるのはペースト、コピーのみ、テンプレートに追加、ビューアで表示、削除だけです](site/img/guide/extended-menu-image.png)

## パート3：テンプレート

テンプレートは、ずっと残しておく項目です。署名、住所、定型の返信、コードのスニペット、よくペーストするロゴなどに使います。フォルダのあるツリーに保存され、履歴メニューの「テンプレート」サブメニューと **⌥T** に表示されます。インストール直後には「例」フォルダがあり、あいさつ文、今日の日付、クリップボードの引用、署名が入っています。自分で書く前に、テンプレートで何ができるかを確かめられます。削除しても編集してもかまいません（設定の「リセット…」で元に戻せます）。

![「例」フォルダ：項目にポインタを合わせるとテキストが表示されます](site/img/guide/template-examples.png)

![テンプレートメニュー：フォルダはサブメニューとして開き、& の後ろの文字がショートカットキーになります](site/img/guide/template-menu-letters.png)

### 作成と整理

**テンプレートを追加する**

- 履歴メニューから：いちばん新しい項目には `⌃⌥A`、メニュー下部の「クリップボードをテンプレートに追加」、または任意の項目について ⇧ → 項目のサブメニュー →「テンプレートに追加」。
- ビューアで：履歴の項目を選んで「テンプレートに追加」をクリックするか、テンプレートのツリーにドラッグします。「新規項目」は空のテキストテンプレートを作ります。「ファイルから新規項目…」（コンテキストメニュー）は、テキストファイルや画像ファイルからテンプレートを作ります。

**整理する**

- 「新規フォルダ」でフォルダを作ります。項目はフォルダ間でドラッグするか、コンテキストメニューの「上へ」/「下へ」で移動します。
- 名前が `-` のテンプレートは、メニューの区切り線になります。
- 名前の中で文字の前に `&` を付けると（たとえば `&Signature`）、その文字がテンプレートメニューでのショートカットキーになります。メニューが開いているときに `S` を押してください。
- コンテキストメニューの「ホットキーを設定…」で、テンプレートに専用のグローバルショートカットを割り当てられます。
- 名前のないテンプレートは最初の行が表示されます。「名前を変更」と「名前を消去」はコンテキストメニューにあります。テキストの上の「名前」フィールドでも編集できます。

### プレースホルダ

テキストテンプレートには `{…}` 形式のプレースホルダを入れられ、ペーストするときに値が埋め込まれます。それ以外の部分はそのままペーストされます。ビューアの **挿入 ▾** にはすべてのプレースホルダが並んでいて、選んだものがカーソル位置に入るので、覚える必要はありません。

![「今日の日付」の例：`{date:EEEE, d MMMM yyyy}` はペースト時に現在の日付になります](site/img/guide/template-examples-date.png)

![ビューアの「挿入 ▾」にはすべてのプレースホルダが並びます](site/img/guide/insert-menu.png)

特に便利なもの：

| プレースホルダ | 結果 |
|-------------|--------|
| `{date}` `{time}` `{datetime}` | 今日の日付 / 現在の時刻（システムの書式） |
| `{date:yyyy-MM-dd}` | 任意の書式（`yyyy MM dd EEEE HH mm …`） |
| `{date:long}` `{time:short}` `{datetime:medium}` | 名前付きのスタイル：`short` `medium` `long` `full` |
| `{date+7d}` `{date-1m:MMMM}` `{time+1h}` `{date+1y-2d}` | ずらした日時：`d` 日、`w` 週、`m` 月、`y` 年、`h` 時間。`date`、`time`、`datetime` で使え、複数を続けて書けます |
| `{clipboard}` `{clipboard:2}` | クリップボード、または履歴のN番目の項目 |
| `{clipboard\|upper}` `{clipboard\|trim\|oneline}` | フィルタ `upper` `lower` `title` `trim` `oneline` `url`。つなげて使えます |
| `{cursor}` | ペースト後にテキストカーソルが置かれる位置 |
| `{user}` `{username}` `{host}` | フルネーム、アカウント名、コンピュータ名 |
| `{uuid}` `{random:1-100}` | 新しいUUID、乱数 |
| `{{` `}}` | 波かっこそのもの。テンプレート `{{"x":1}}` は `{"x":1}` としてペーストされます |

プレースホルダ名は小文字で書きます。`{date}` はプレースホルダですが、`{Date}` と `{DATE}` はただのテキストで、そのままペーストされます。スタイル名とフィルタ名（`{date:LONG}`、`{clipboard|UPPER}`）は大文字でも小文字でもかまいません。

完全な一覧は[プレースホルダ早見表](#placeholder-cheat-sheet)にあります。

### 質問するテンプレート

`{input:Name}` と `{choice:Label=A|B|C}` を使うと、テンプレートが小さなフォームになります。ペーストするとKeepitがまず値を尋ね、それから完成したテキストをペーストします。同じ名前は、何度出てきても尋ねられるのは1回だけです。`{input:Name=Default}` と書くと、フィールドにあらかじめ値が入ります。

![{input:Name} を含むテンプレートをペーストすると、まず値を尋ねられます](site/img/guide/input-dialog.png)

たとえば、返信用のテンプレート：

```
{input:お名前} 様

{date-1d}付のメッセージをありがとうございます。{date+3d:EEEE}までにお返事いたします。
{cursor}
{user}
```

ペーストすると「お名前」を尋ね、日付を埋め、フルネームで署名し、空の行にカーソルを残します。

## パート4：ビューア

メニューの「ビューア…」を選ぶか、📎 アイコンを右クリックすると、3つのツリーがあるウインドウが開きます。**クリップボード**（現在のクリップボードの内容、読み出し専用）、**履歴**（「テキストとファイル」と「画像」）、**テンプレート**です。

![テンプレートを選択した状態のビューア](site/img/guide/viewer.png)

- 項目を選ぶと右側に内容が表示されます。テキストはその場で編集でき、エディタを離れると変更が反映されます。画像はパネルに合わせて表示され、上にピクセルサイズとファイルサイズが出ます。ファイルリストはダブルクリックでファイルを開きます。コンテキストメニューの「16 進ダンプで表示」で生のバイト列を確認できます。
- ツールバー：「クリップボードへ送る」、「ペースト」（元のアプリへ）、「テンプレートに追加」、「新規項目」、「新規フォルダ」、「削除」、「挿入 ▾」（プレースホルダ）、そして **?**（このガイド）。
- **検索**（`⌘F`）：左側のフィールドが履歴とテンプレートを名前と内容で絞り込み、一致した部分をハイライトします。
- 履歴の項目をテンプレートのツリーにドラッグすると保存でき、テンプレートを履歴にドラッグするとコピーして戻せます。並び順はドラッグか「上へ」/「下へ」で変えられます。⌫ で選択中の項目を削除します。
- ステータスバーには日付、コピー元のアプリ、形式、サイズが表示されます。

## パート6：セキュリティ

### パスワードと暗号化

「設定」→「セキュリティ」→「起動時にパスワードを要求」をオンにすると、履歴とテンプレートがAES-256-GCMで暗号化されます。鍵はパスワードから導出され（PBKDF2、200,000回）、メモリ上にだけ存在します。Keepitがロックされると鍵は消去されます。ロックされるのは、「Keepit をロック」（`⌥L`）を実行したとき、終了したとき、そして設定によっては、Macがしばらくロックまたはスリープしていたときです。「Keepit の自動ロック」は、新規インストールでは**しない**になっています（3.0.3からのアップデートでは以前の選択が引き継がれ、画面と一緒にロックする設定がオンだった場合は「すぐに」になります）。休憩のたびにパスワードを求めるクリップボードマネージャは使われなくなってしまいますし、大事な場面では `⌥L` が使えます。「すぐに」は画面と同時にロックします。「5分後」「15分」「1 時間」は短い離席では何もしません。Keepitはロックされずに記録を続け、その時間ずっとMacを離れていた場合にだけロックします。Macがすでにロックされている状態や、別のユーザのセッションが前面にある状態でKeepitが起動した場合（アップデート後の再起動など）も同じで、離席の時間は起動時から数えます。ただしこれは、macOSがその状態をKeepitに伝える範囲での動作です（通常は伝えられます。伝えられない場合は、次のロックかスリープから数え始めます）。Touch IDがオンなら、Macのロックが解除された時点でKeepitがタッチを求めるので、最初の `⌥M` の前に準備が整います。

![オンスクリーンキーボードでパスワードを設定しているところ。これはスクリーンショットではなく画面を撮影した写真です。作者のMacでは、この場面のスクリーンショットにはダイアログしか写りません](site/img/guide/set-password-keyboard.jpg)

パスワードのダイアログには現在のキーボード配列が表示され、Caps Lockがオンのときは警告が出るので、パスワードが通らない理由はたいていすぐわかります。フィールドの横のキーボードボタンを押すと、マウスでパスワードを入力するための**オンスクリーンキーボード**が開きます。クリックがキー入力としてシステムを通ることはなく、キーの配置は開くたびに入れ替わります。また、スクリーンショットや画面収録に写らないようmacOSに要求します（構成によっては除外されますが、保証はされません）。完全には信頼できないMacや、画面を共有しているMacで役に立ちます。起動時とロック後に、Keepitはパスワード（またはTouch ID）を求めます。「アクセスを復旧…」を選ぶと、代わりに24語のフレーズを入力できます。[リカバリーフレーズ](#recovery-phrase)をご覧ください。

![起動時のロック解除：パスワード、終了、またはリカバリーフレーズ。何か入力するまでOKは押せません。上と同じ理由で写真です](site/img/guide/unlock-keyboard.jpg)

![「設定」→「セキュリティ」](site/img/guide/prefs-security.png)

### Touch ID

「Touch ID でロック解除」をオンにすると、鍵は指紋で保護されたSecure Enclaveにも保存され、Keepitはパスワードの代わりにタッチを求めます。パスワードは予備の手段として引き続き使えます（確認画面のパスワードボタン）。ノートブックを閉じた状態で、Touch ID付きの外付けMagic Keyboardを使っている場合は、キーボード側で求められます。「Touch ID でのパスワード変更を許可」をオンにすると、パスワードを変更するときに、古いパスワードの代わりに指紋を使えます。

![Touch IDでのロック解除。パスワードは予備の手段として残ります](site/img/guide/touch-id.png)

### リカバリーフレーズ

パスワードを設定すると、Keepitは24語のフレーズを一度だけ表示します。印刷するか、パスワードマネージャに保管してください。パスワードを忘れた場合は、ロック解除のダイアログで「アクセスを復旧…」を選ぶとデータが開き、新しいパスワードを設定できます。「リカバリーフレーズ」→「新規作成…」で新しいフレーズが発行され、古いものは無効になります。その横の「表示…」を押すと、Touch IDかパスワードで確認したあと、現在のフレーズをもう一度表示できます。

パスワード、同じMacのTouch ID、フレーズのどれもない場合、データは復元できません。サーバはなく、リセットできるものもないからです。

![24語のリカバリーフレーズ（ここでは単語を隠しています）](site/img/guide/recovery-phrase.png)

### バックアップ

Keepitは、履歴とテンプレートの暗号化したコピーを好きなフォルダ（iCloud Drive、Dropbox、Google Drive、外付けディスク、NASなど）に保存し、何か変更があるたびに新しいコピーを書き込めます。Keepitのサーバはありません。フォルダはあなたのものです。そのフォルダを提供している事業者に見えるのは、暗号化されたファイルとそのサイズ、そして暗号化されていない小さなヘッダです（いつ、どのバージョンのKeepitが書き込んだか、鍵の導出方法、ランダムな識別子。Macの名前は、オンにした場合だけ含まれます）。[セキュリティのページ](/security#backups)（英語）に、ヘッダの内容を項目ごとに載せています。

![「設定」→「バックアップ」：自動バックアップ、手動バックアップ、復元](site/img/guide/prefs-backup.png)

**オンにする。** 「設定」→「バックアップ」→「フォルダに自動的にバックアップ」をオンにして、「選択…」でフォルダを選びます（選択画面はiCloud Driveで開きます）。自動バックアップには、「設定」→「セキュリティ」のパスワード保護が必要です。各コピーは保管庫の鍵から導出した鍵で封印されるので、このMacでもほかのMacでも、Keepitのパスワードかリカバリーフレーズで開けます。そのための設定は何も要りません。パスワードが設定されていない場合、チェックボックスは無効になり、その旨が表示されます。

**そのあとの動作：スケジュール。** 最後の変更から約5分後（Keepitが動いている間は遅くとも1日に1回）、Keepitは `Keepit-<date and time>-<installation>-<id>.keepit` という名前のファイルをフォルダに書き込み、読み戻して確認します。そのあとではじめて、「保持する数」（デフォルトは10、1〜100）を超えた自分の古いコピーを削除します。各コピーはそれだけで完結していて、差分ではないので、必要なファイルは常に1つだけです。ほかのMacが作ったコピーや、自分で置いたファイルには手を付けません。1つのフォルダを共有する2台のMacは、それぞれ独立した系列を書き込みます。「自動バックアップ」の見出しの横のステータス行には、最後のコピーの時刻とサイズ、または直前の試行が失敗した理由が表示されます。Keepitがロックされている間は何も行われません。「今すぐバックアップ」（「手動バックアップ」の下）は、変更後の待ち時間を待たずに実行します。

**「この Mac の名前をバックアップファイルに含める」**（デフォルトはオフ）をオンにすると、各ファイルの暗号化されていないヘッダにコンピュータの名前が入り、1つのフォルダにある2つの系列をFinderで見分けやすくなります。ストレージの提供元からもその名前が見えるため、任意の設定にしています。

**復元。** 「復元…」は、ロックを解除したあとでバックアップ（このMacのもの、ほかのMacのもの、書き出したファイル）を開きます。解除には、そのバックアップを作ったMacのパスワードか、そのMacでパスワードを設定したときに表示されたリカバリーフレーズを使います（パスワードのダイアログの「アクセスを復旧…」）。プレビューに、ファイルがいつどこで作られたか、いくつの項目が入っているかが表示され、次のどちらかを選びます。

![復元のプレビュー：ファイルがいつ、どのバージョンのKeepitで書き込まれたか、何が入っているか、「結合」か「置き換え」か](site/img/guide/restore-preview.png)

- 「結合」は、まだないものを追加します。履歴の項目は内容で照合し、バックアップのテンプレートは「読み込み <日付>」という名前の新しいフォルダにまとめて入ります（ホットキーは引き継がれません）。バックアップから来たものがひと目でわかり、移動や削除ができます。今あるものは上書きされません。
- 「置き換え」は、現在の履歴とテンプレートを破棄し、バックアップのものに入れ替えます。その前にKeepitは、現在の内容のコピー（`Keepit-before-restore-…`）をバックアップフォルダか、選んだフォルダに書き込みます。このコピーを書き込めない場合、置き換えは始まりません。Keepitにまだパスワードがない場合は、「アーカイブに保存…」と同じように、このコピー用のパスワードを尋ねられます。

「環境設定も復元する」を選ぶと、ホットキー、上限、オプションがバックアップから戻ります。特定のMacへの信頼を表す設定（Touch ID、URLによる自動化とその信頼済みアプリ、バックアップフォルダ自体）は、常にこのMacの現在の設定のままです。バックアップの履歴がこのMacの上限より大きい場合は、確定する前に、どれだけ収まるかをKeepitが知らせます。

まだパスワードのないMacで、リカバリーフレーズを使ってバックアップを復元した場合、Keepitは先にパスワードを設定するよう求めます。復元したデータが暗号化されないまま保存されるのを防ぐためです。そのフレーズをこのMacでも使い続けるか、新しいフレーズを作るかを選べます。パスワードで復元した場合は、それをこのMacのパスワードとして使うかどうかをKeepitが尋ねます。どちらの場合も、自動バックアップはMacごとの設定です。このMacでオンにしてフォルダを選べば（同じフォルダでかまいません）、古いMacの系列の隣に、このMac独自の系列が作られ始めます。

**新しいMacへの移行**こそが、この機能の目的です。Keepitをインストールし、初回起動時に「バックアップから復元…」を選び、フォルダの中のいちばん新しいファイルを選んで、古いMacのパスワードを入力し、「置き換え」を選びます。そのあと、新しいMacで自動バックアップをオンにします。それまでに作られたコピーは、それぞれが書き込まれた時点で有効だったパスワードとフレーズで開きます。パスワードを変更したあとも、古いコピーには古いパスワードが必要です。

**手動バックアップ。** ボタンは2つあり、役割が違います。「今すぐバックアップ」は、自動バックアップと同じ形式のコピーをすぐに作ります。ファイルの種類も、フォルダも、系列も同じで、Keepitのパスワードかフレーズで開きます。「アーカイブに保存…」は、1つの `.keepit` *アーカイブ*を好きな場所に書き出し、そのために選んだパスワードでロックします。Keepitのパスワード保護は必要なく、書き出したあとのファイルをKeepitは管理しません。データを人に渡すときや、バックアップフォルダの外にコピーを置きたいときに使います。提案されるファイル名を見れば種類がわかります。アーカイブは `Keepit-archive-<date>-manual.keepit`、自動コピーは `Keepit-<date and time>-<installation>-<id>.keepit` です。

![「アーカイブに保存…」：ファイル名に archive と manual が入ります](site/img/guide/save-to-archive.png)

![アーカイブ専用のパスワードと強度メーター。このパスワードはどこにも保存されません](site/img/guide/archive-password.png)

「復元…」はどちらの種類も開けます。アーカイブは、2.xの「書き出す…」/「読み込む…」に代わるものです。このファイルで、直接ダウンロード版とApp Store版の間、またKeepit 2.xと3.xの間でデータを移せます。3.0で書き込んだファイルを開くには3.0以降が必要です。3.0は2.xが書き込んだものをすべて読めます。

**うまくいかないとき。** コピーに失敗するとステータス行に表示され、間隔を少しずつ空けながら再試行されます。以前のコピーは残ります。復元の途中でKeepitが終了したり、Macが落ちたりした場合は、次の起動時に、復元前の状態へ自動的に戻します。まれにそれができない場合（書き込めないファイルがある、ディスクがいっぱいなど）は、そのファイルの名前を表示し、何も変更せずに終了します。ファイルの問題を解消してから、もう一度起動してください。ファイル形式の内部構造を含む詳細は、[セキュリティのページ](/security#backups)（英語）にあります。

## パート7：高度な機能

### 自動化：keepit:// URLスキーム

ショートカット（「URLを開く」）、Raycast、Alfred、Keyboard Maestro、またはシェルの `open` からKeepitを操作できます。ただし、「設定」→「詳細」→「自動化」→「keepit:// URL コマンドを許可」で**オンにした場合だけ**です。デフォルトでオフにしているのは、どのアプリやWebページでもURLを開くことができ、`add` や `paste` はクリップボードを書き換えて前面のアプリに入力するからです。オフの間、KeepitはこうしたURLを警告音とともに無視します。オンにすると、KeepitはだれがURLを開いたかを確認します。何かを変更するコマンド（`paste`、`copy`、`template`、`add`、`add-template`、`pause`、`resume`）がアプリから最初に届いたときは、ダイアログで確認します。「許可」は1回だけ実行し、「常に許可」はそのアプリを信頼済みリストに加えます（同じパネルの「信頼済みアプリを忘れる」で消去できます）。Webブラウザや、macOSが特定できない送信元の場合は、毎回確認します。Keepit自身のウインドウを開くだけのコマンドは、確認なしで実行されます。

| URL | 効果 |
|-----|--------|
| `keepit://paste/2`<br>`keepit://paste/latest`<br>`keepit://paste/previous` | 履歴のN番目（または最新 / ひとつ前）の項目を前面のアプリにペースト |
| `keepit://copy/3` | N番目の項目を、ペーストせずにクリップボードに入れる |
| `keepit://template/Signature`<br>`keepit://template/Work/Reply?copy=1` | 名前またはフォルダのパスで指定したテンプレートをペースト（またはコピー） |
| `keepit://add?text=…` | テキストを履歴とクリップボードに追加 |
| `keepit://add-template?text=…&name=…` | テンプレートを作成 |
| `keepit://history`<br>`keepit://templates`<br>`keepit://viewer`<br>`keepit://settings` | 履歴メニュー、テンプレートメニュー、ビューア、設定を開く |
| `keepit://pause`<br>`keepit://resume` | 記録を10分間一時停止 / 再開 |

テキストはパーセントエンコードしてください（スペースは `%20`）。Keepitがロックされている間、URLは無視されます。

### アップデート

Keepitは1日に1回GitHub Releasesを確認し、アップデートがあればダイアログで知らせます。「アップデートを確認…」を選ぶと、すぐに確認します。アップデートは署名（EdDSA）と公証を受けています。Homebrewを使っている場合は、`brew upgrade --cask keepit` で同じことができます。各ダウンロードのチェックサムは、リリースページの `SHA256SUMS` にあります。

この確認がKeepitの行う唯一のネットワーク通信で、オフにもできます。「設定」→「一般」→「アップデート」→「アップデートを自動的に確認」です。オフにすると、Keepitはどこにも接続しなくなります。手動で確認することもできなくなり、「アップデートを確認…」はメニューから消えます。その場合は、[keep.it.com](https://keep.it.com) からダウンロードするか、Homebrewでアップデートしてください。App Store版にはアップデート機能もこのオプションもなく、App Storeがアップデートします。

### アンインストール

「設定」→「詳細」→「リセットとアンインストール」→「アンインストール…」を選ぶと、アプリ、データフォルダ、キーチェーンの項目（Touch IDの鍵を含む）、ログイン項目、アクセシビリティの登録が削除されます。パスワードまたはTouch ID、`DELETE` の入力、最終確認が求められます。あとでデータが必要になるかもしれない場合は、先にバックアップを書き出してください。Homebrewで入れた場合は、そのあと `brew uninstall --cask --force keepit` を実行して、Homebrew側の登録も消してください。

### トラブルシューティング

**項目を選んでも何もペーストされません。** アクセシビリティの許可がありません。「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」→「Keepit」を確認してください。Keepitがリストにあるのにペーストされない場合は、いったんオフにしてからオンに戻してください。アプリを再インストールすると、macOSは許可を忘れます。

**ショートカットを押しても何も起きません。** ほかのアプリかmacOSがそのキーを使っています。Keepitは起動時にそのことを知らせます。「ショートカット」パネルで別の組み合わせを選んでください。初期状態のMacでは、⌃⌥ と数字・文字の組み合わせは空いています。

**メニューが違う場所に開きます。** 使用中のアプリがテキストカーソルの位置を公開していないため、メニューはマウスポインタの位置に開きます。常にポインタの位置に開きたい場合は、「一般」パネルの「可能ならテキストカーソル位置にメニューを開く」をオフにしてください。

**コピーしたはずのものが見つかりません。** コピー元のアプリが秘匿扱いにしたものは記録されません。パスワードマネージャ（内蔵のリスト）や、無視リストに入れたアプリが前面にあったときのコピーも記録されません。直前まで使っていて切り替えたばかりのアプリも対象です。「設定」→「履歴」と[セキュリティのページ](/security#what-is-not-recorded)（英語）をご覧ください。

**Touch IDが表示されません。** 現在使えるTouch IDセンサーがありません（ノートブックを閉じている、Touch ID付きのキーボードがないなど）。Keepitは設定を保持し、センサーが使えるようになり次第、指紋を求めます。

**バックアップのステータスに、フォルダを利用できないと表示されます。** フォルダが移動、名称変更、マウント解除されたか、（iCloud Driveの場合）ローカルから取り除かれています。マウントするか元に戻せば、次のコピーは成功します。「選択…」で新しいフォルダを選ぶこともできます。新しいフォルダでは新しい系列が始まり、古いファイルは元の場所に残ります。

**バックアップファイルが開きません。** 「パスワードが違います」は、ファイルの認証タグが一致しなかったという意味です。そのファイルを*書き込んだ*Macのパスワード（パスワードを変更したあとも、古いコピーは古いパスワードで開きます）か、そのMacのリカバリーフレーズを使っているか確認してください。「このバックアップには Keepit 3.0 以降が必要です」は、開こうとしているバージョンより新しいバージョンでファイルが書き込まれたという意味です。

**Homebrewが既存のアプリへの上書きインストールを拒否します。** Keepitを終了し、先に `/Applications/Keepit.app` をゴミ箱に入れるか、`--force` を付けてください。

解決しない場合は：[GitHub Issues](https://github.com/andrey-insarov/Keepit/issues) · admin@keep.it.com
