# Keepit 使用手冊

Keepit 是 macOS 上的剪貼板歷史記錄與範本管理工具。它常駐在選單列，記住你拷貝過的所有內容，並能用快速鍵把任何一個項目貼回去。下面提到的快速鍵都是預設值，每一個都可以在「設定」→「快速鍵」中更改。本手冊說明的是 Keepit 3；Keepit 2.x 的手冊原樣保留在 [keep.it.com/v2/guide](https://keep.it.com/v2/guide)（英文）。

## 第 1 部分：開始使用

### 安裝

**Homebrew**（建議使用），因為 `brew upgrade` 可以讓 App 保持最新：

```bash
brew tap andrey-insarov/keepit https://github.com/andrey-insarov/Keepit
brew install --cask andrey-insarov/keepit/keepit
```

**DMG**：從[最新版本](https://github.com/andrey-insarov/Keepit/releases/latest)頁面下載 `Keepit-<版本>.dmg`，打開後把 Keepit 拖到「應用程式」。

![DMG：把 Keepit 拖到「應用程式」](site/img/guide/dmg.png)

第一次打開 App 時，macOS 會確認它是從網際網路下載的，並已通過 Apple 檢查。按一下「打開」。

![macOS Gatekeeper 的確認視窗](site/img/guide/gatekeeper.png)

Keepit 經過簽署和公證，會自動更新，並以原生方式在搭載 Apple 晶片或 Intel 處理器、執行 macOS 13 Ventura 或以上版本的 Mac 上運作。

### 首次啟動

Keepit 是選單列 App：沒有 Dock 圖像，在你主動打開之前也沒有視窗。首次啟動後，選單列上會出現 📎 圖像，Keepit 會問三件事。

**1. 要從備份還原嗎？** 如果這是一部新的 Mac，而你有 Keepit 備份（iCloud 雲碟或其他資料夾中的自動備份，或是匯出的 `.keepit` 檔案），「從備份還原…」會在其他任何事情發生之前先把歷史記錄和範本帶回來。你需要用製作該檔案的 Mac 的密碼或它的復原短語來解鎖檔案。「全新開始」會略過這一步。之後也可以在「設定」→「備份」→「還原…」中進行同樣的還原，在 Finder 中按兩下 `.keepit` 檔案也能打開它。詳情請參閱[備份](#backup)。

![新 Mac 上的第一個問題：從備份還原，還是全新開始](site/img/guide/restore-first-run.png)

**2. 密碼（選用）。** Keepit 可以把歷史記錄和範本加密儲存，並用 Touch ID 解鎖。你可以現在決定，也可以稍後在「設定」→「安全性」中決定；[第 6 部分](#part-6-security)說明了運作方式。選擇「暫時不要」的話，所有內容都會以未加密的形式留在磁碟上。如果你剛才用備份的密碼還原了備份，Keepit 會提議在這部 Mac 上沿用該密碼。

![首次啟動時的密碼設定提議](site/img/guide/password-offer.png)

![選擇「暫時不要」時：清楚說明這代表什麼，以及可以在哪裡更改](site/img/guide/no-password-notice.png)

**3.「輔助使用」權限。** 為了替你貼上，Keepit 會把 ⌘V 傳送到你原本使用的 App。macOS 只允許列在「系統設定」→「隱私權與安全性」（香港版 macOS 顯示為「私隱與保安」）→「輔助使用」中的 App 這樣做。按一下「打開系統設定」，然後開啟 Keepit。沒有這項權限時，Keepit 仍會記錄和拷貝，但需要你自己按 ⌘V。

![Keepit 要求「輔助使用」權限](site/img/guide/accessibility-prompt.png)

![在「隱私權與安全性」→「輔助使用」中已開啟 Keepit](site/img/guide/accessibility-settings.png)

Keepit 預設會在登入時啟動，可在「設定」→「一般」中關閉。

## 第 2 部分：日常使用

### 歷史記錄選單

在任何 App 中按下 **⌥M**，或按一下 📎 圖像。如果 Keepit 找得到文字游標，選單就會在游標旁打開，否則會在滑鼠指標旁打開。

每一行是一個拷貝過的項目，最新的排在最上面。最新的項目以**粗體**顯示，因為它就是目前剪貼板上的內容。圖像代表你拷貝時所在的 App；標題以 `…` 結尾，表示實際行數比選單顯示的多。影像會顯示縮圖，檔案列表會顯示檔案名稱。

![選單旁的預覽面板會完整顯示反白的項目，以及它的來源 App、時間和大小](site/img/guide/menu-preview.png)

![歷史記錄中的影像：選單中是縮圖，預覽中是完整影像](site/img/guide/menu-image.png)

要貼上某個項目，可以按一下它，或用 ↑ ↓ 移到它上面再按 Return，或搭配 **⌃⌥** 按下它的編號：`⌃⌥3` 會貼上第 3 個項目。同樣的按鍵在任何地方都能用，不需要先打開選單。

歷史記錄下方依序是「範本」子選單、檢視器（⌥E）、設定（⌥S）、「清除歷史記錄」（⌥C）、「暫停記錄 10 分鐘」（⌥P，適合在輸入不想被記錄的內容時使用）、已設定密碼時的「鎖定 Keepit」（⌥L），以及更新指令。**⌥T** 會單獨打開範本選單。這些按鍵不打開選單也都能用。

### 搜尋與預覽

**搜尋。** 選單打開時直接開始輸入：頂端的欄位會依標題和全文篩選列表，所以長項目中間的某一行也找得到。Return 會貼上第一個符合的項目；Esc 會清空欄位，再按一次 Esc 則關閉選單。

**預覽。** 把指標移到項目上（或用鍵盤移過去），選單旁的面板就會顯示完整的影像，或長文字的前幾行，以及來源 App、日期和大小。簡短的單行文字沒有預覽，因為選單的那一行已經完整顯示了。

![輸入文字會篩選選單；預覽面板顯示反白的項目](site/img/guide/search-preview.png)

### 不開選單直接貼上

全域快速鍵在任何 App 中都能使用，作用對象是當下的歷史記錄（第 1 個項目就是剪貼板）：

| 按鍵 | 效果 |
|------|--------------|
| `⌃⌥1` … `⌃⌥9`, `⌃⌥0` | 貼上歷史記錄的第 1–10 個項目 |
| `⌥⇧V` | 貼上*前一個*項目（第 2 個項目）；再按一次會換回來 |
| `⌃⌥V` | 以純文字貼上剪貼板內容，去除格式 |
| `⌃⌥U` `⌃⌥L` `⌃⌥T` `⌃⌥S` | 以大寫 / 小寫 / 每個單字首字母大寫 / 句首字母大寫貼上剪貼板內容 |
| `⌃⌥W` | 去除首尾空白後貼上剪貼板內容 |
| `⌃⌥J` | 把剪貼板內容合併成一行後貼上 |
| `⌃⌥K` `⌃⌥D` `⌃⌥Y` | 以刪除線 / 底線 / 波浪底線貼上剪貼板內容。貼上的是純文字，在任何地方（包括聊天軟體）都能保持外觀（見下文） |
| `⌃⌥X` | 移除這些裝飾後貼上剪貼板內容 |
| `⌃⌥A` | 將剪貼板加入範本 |
| `⌃⌥⌫` | 從歷史記錄中刪除最新的項目 |

這三種裝飾並不是格式：Keepit 會在每個字元後面加上一個 Unicode *組合用記號*（刪̶除̶線̶、底̲線̲、波̰浪̰線̰），因此文字在通訊軟體、網頁表單或終端機中看起來都一樣，而真正的格式在這些地方會消失。代價是：這樣的文字大小是原來的三倍，用原本的字詞搜尋找不到它，螢幕閱讀器讀起來會不順，有些字體畫出的線也不平整。「移除裝飾」（`⌃⌥X`）可以把這些記號再拿掉，在別處加上裝飾的文字也適用。無論哪個方向，記號都是依碼位移除的，不管它們來自哪裡：把同樣的記號當作字母使用的音標（U+0330 同時也是國際音標中表示嘎裂聲的符號）會失去這些記號，三種裝飾在套用前也會先移除它們。開啟 VoiceOver 時，`⌃⌥` 是 VoiceOver 本身的變更鍵：請在「設定」→「快速鍵」中為「對最新項目的動作」另外指定一組變更鍵。

轉換只適用於文字；對影像或檔案列表按下這些鍵只會發出提示音。以上所有按鍵都可以在「設定」→「快速鍵」中更改或停用。

### 貼上佇列

有時你想從一個地方拷貝五樣東西，再按順序貼到另一個地方：把儲存格貼進表單，把網頁上的幾行貼進文件。貼上佇列不需要選單就能做到：

1. 按下 **⌥N**（或在選單中選擇「開始貼上佇列」）。選單列圖像會顯示一個紅點和計數器：`📎 ● 0`。
2. 照常用 ⌘C 拷貝，次數不限。每拷貝一次，計數器就加一：1、2、3…所有內容也會記錄到歷史記錄中。

   ![佇列開啟時的選單列：紅點和計數器](site/img/guide/queue-menubar.png)

3. 切換到要放文字的地方，每個項目按一次 **⌥V**。最先拷貝的內容最先貼上，計數器隨之減少。⌘V 仍會照常貼上剪貼板內容，所以兩者可以交替使用。
4. 貼上最後一個項目後，或在兩分鐘內沒有拷貝也沒有貼上時，佇列會自行關閉（時間可以調整）。再按一次 ⌥N 可以提前結束。

**⌥⇧N** 會一次貼上佇列中剩下的所有內容。項目之間可以用換行、Tab、空格連接，或什麼都不加；這要在「設定」的「貼上佇列」面板中選擇，閒置時間也在那裡設定。佇列開啟時，歷史記錄選單會標示佇列中的項目：`▶` 是下一個要貼上的，`○` 是仍在排隊的，`✓` 是已經貼上的。

![佇列開啟時的歷史記錄選單：○ 排隊中、▶ 下一個、✓ 已貼上；選單列項目顯示還剩幾個](site/img/guide/queue-menu.png)

![「設定」→「貼上佇列」](site/img/guide/prefs-queue.png)

### 延伸選單

歷史記錄選單打開時按住 **⇧**，每個項目都會出現一個 `▸` 子選單，列出該項目可用的所有動作：貼上、以純文字貼上、僅拷貝（放到剪貼板但不貼上）、「貼上為」的各種轉換、加入範本、在檢視器中顯示、刪除。把指標移到項目上或按 → 即可打開子選單；打開之後就可以放開 ⇧。

![按住 ⇧：每個項目都會出現子選單；最新項目的子選單會顯示全域快速鍵](site/img/guide/extended-menu.png)

對於最新的項目，子選單會列出上表中的全域快速鍵。動作相同，按鍵也相同，所以可以在這裡學會它們。其他項目只顯示動作而不顯示按鍵：快速鍵要嘛在任何地方都有效，要嘛就不顯示。

![其他項目：同樣的動作，沒有快速鍵](site/img/guide/extended-menu-item2.png)

![對於影像，文字動作會變成灰色；只有貼上、僅拷貝、加入範本、在檢視器中顯示和刪除可用](site/img/guide/extended-menu-image.png)

## 第 3 部分：範本

範本是你長期保留的項目：簽名、地址、制式回覆、程式碼片段、經常貼上的標誌。它們存放在帶有檔案夾的樹狀結構中，並出現在歷史記錄選單的「範本」子選單和 **⌥T** 之下。全新安裝時會附帶一個「範例」檔案夾（一段問候語、今天的日期、剪貼板內容的引用和一個簽名），讓你在自己動手寫之前先看看範本能做什麼。你可以隨意刪除或編輯它們。範例範本可以透過「設定」→「進階」→「重置與解除安裝」→「重置…」恢復，但這項操作也會重置其他資料和設定。

![「範例」檔案夾：把指標移到項目上會顯示它的文字](site/img/guide/template-examples.png)

![範本選單：檔案夾會以子選單打開，& 後面的字母會成為快速鍵](site/img/guide/template-menu-letters.png)

### 建立與整理

**加入範本**

- 從歷史記錄選單：對最新的項目按 `⌃⌥A`，或選擇底部的「將剪貼板加入範本」，或對任何項目使用 ⇧ → 項目的子選單 →「加入範本」。
- 在檢視器中：選擇一個歷史記錄項目，然後按一下「加入範本」，或把它拖到範本樹上。「新增項目」會建立一個空白的文字範本；「從檔案新增項目」（在快速選單中）會用文字檔或影像檔建立範本。

**整理**

- 「新增檔案夾」會建立檔案夾；你可以在檔案夾之間拖移項目，或使用快速選單中的「上移」/「下移」。
- 名稱為 `-` 的範本會在選單中變成分隔線。
- 在名稱中的某個字母前加上 `&`，例如 `&Signature`，該字母就會成為這個項目在範本選單中的快速鍵：選單打開時按 `S`。
- 快速選單中的「設定快速鍵」可以為範本指定專屬的全域快速鍵。
- 沒有名稱的範本會顯示它的第一行；「重新命名」和「清除名稱」在快速選單中，也可以直接編輯文字上方的「名稱」欄位。

### 佔位符

文字範本可以包含 `{…}` 佔位符，它們會在貼上時被填入內容。其餘部分會原樣貼上。在檢視器中，**插入 ▾** 會列出所有佔位符，並把你選的那個放到游標位置，所以什麼都不必背。

![「今天的日期」範例：`{date:EEEE, d MMMM yyyy}` 在貼上時會變成目前的日期](site/img/guide/template-examples-date.png)

![檢視器中的「插入 ▾」會列出所有佔位符](site/img/guide/insert-menu.png)

最實用的幾個：

| 佔位符 | 結果 |
|-------------|--------|
| `{date}` `{time}` `{datetime}` | 今天的日期 / 目前的時間，採用系統格式 |
| `{date:yyyy-MM-dd}` | 任意格式（`yyyy MM dd EEEE HH mm …`） |
| `{date:long}` `{time:short}` `{datetime:medium}` | 具名樣式：`short` `medium` `long` `full` |
| `{date+7d}` `{date-1m:MMMM}` `{time+1h}` `{date+1y-2d}` | 偏移：`d` 天、`w` 週、`m` 月、`y` 年、`h` 小時；適用於 `date`、`time`、`datetime`，可以連續使用多個 |
| `{clipboard}` `{clipboard:2}` | 剪貼板，或歷史記錄的第 N 個項目 |
| `{clipboard\|upper}` `{clipboard\|trim\|oneline}` | 過濾器 `upper` `lower` `title` `trim` `oneline` `url`，可以串接 |
| `{cursor}` | 貼上後文字游標停留的位置 |
| `{user}` `{username}` `{host}` | 全名、帳號名稱、電腦名稱 |
| `{uuid}` `{random:1-100}` | 新的 UUID；隨機數字 |
| `{{` `}}` | 字面上的大括號：範本 `{{"x":1}}` 會貼上 `{"x":1}` |

佔位符的名稱是小寫的：`{date}` 是佔位符，`{Date}` 和 `{DATE}` 則是文字，會原樣貼上。樣式名稱和過濾器（`{date:LONG}`、`{clipboard|UPPER}`）大小寫皆可。

完整列表請見[佔位符速查表](#placeholder-cheat-sheet)。

### 會提問的範本

`{input:姓名}` 和 `{choice:標籤=A|B|C}` 會把範本變成一張小表單：貼上時，Keepit 會先詢問這些值，再貼上完成的文字。同一個名稱不論出現多少次都只問一次；`{input:姓名=預設值}` 會預先填好欄位。

![貼上帶有 {input:Name} 的範本時會先詢問值](site/img/guide/input-dialog.png)

例如，一個回覆範本：

```
{input:姓名}，你好：

謝謝你在 {date-1d} 的來信。我會在 {date+3d:M月d日}之前回覆你。
{cursor}
{user}
```

貼上時會詢問「姓名」、填入日期、以你的全名署名，並把游標留在空白行上。

## 第 4 部分：檢視器

選單中的「檢視器⋯」，或用右鍵按一下 📎 圖像，會打開一個包含三棵樹的視窗：**剪貼板**（目前的剪貼板內容，唯讀）、**歷史記錄**（「文字與檔案」和「影像」）以及**範本**。

![已選取一個範本的檢視器](site/img/guide/viewer.png)

- 選取一個項目，就能在右側看到它。文字可以直接就地編輯，離開編輯區時變更就會套用；影像會縮放到符合面板的大小，上方顯示它的像素尺寸和檔案大小；檔案列表按兩下可以打開檔案。快速選單中的「以十六進位傾印顯示」會顯示原始位元組。

## 第 6 部分：安全性

### 密碼與加密

「設定」→「安全性」→「啟動時要求密碼」會以 AES-256-GCM 加密歷史記錄和範本。密鑰由你的密碼衍生（PBKDF2，200 000 次迭代），只存在於記憶體中；Keepit 鎖定時就會清除它，也就是執行「鎖定 Keepit」（`⌥L`）時、結束時，以及（如果你這樣設定）Mac 鎖定或睡眠一段時間之後。全新安裝時，「自動鎖定 Keepit」是**永不**（從 3.0.3 更新會保留原本的選擇；如果當時勾選了隨螢幕鎖定，就是「立即」）：每次喝杯咖啡回來都要求輸入密碼的剪貼板管理工具，最後沒有人會用，而在真正重要的時刻還有 `⌥L`。「立即」會隨螢幕一起鎖定；「5 分鐘後」、「15 分鐘後」或「1 小時後」不理會短暫的離開（Keepit 保持解鎖並繼續記錄），只有當 Mac 在整段設定的時間內都處於鎖定或睡眠狀態時才會鎖定。Keepit 啟動時 Mac 已經鎖定，或最前面是其他使用者的工作階段（例如更新後重新啟動），也適用同樣的規則：只要 macOS 把這個狀態回報給 Keepit，時間就從啟動時算起（通常會回報；無法回報時，則從下一次鎖定或睡眠開始計算）。開啟 Touch ID 後，Keepit 會在 Mac 解鎖的那一刻要求你觸碰，這樣在你第一次按下 `⌥M` 之前它就已經準備好了。

![使用螢幕鍵盤設定密碼。這是對著螢幕拍的照片，不是截圖：在作者的 Mac 上，這個畫面的截圖只會顯示對話框本身](site/img/guide/set-password-keyboard.jpg)

密碼對話框會顯示目前的鍵盤配置，並在 Caps Lock 開啟時發出警告，所以密碼被拒絕時通常不難找出原因。欄位旁的鍵盤按鈕會打開一個**螢幕鍵盤**，讓你用滑鼠輸入密碼：這些點按不會以按鍵事件的形式經過系統，每次打開時按鍵位置都會打亂，而且它會要求 macOS 不要讓它出現在截圖和螢幕錄製中（在某些設定下它會被排除，但這一點無法保證）。它適合用在你不完全信任的 Mac，或正在共享螢幕的 Mac 上。啟動時以及鎖定之後，Keepit 會要求輸入密碼（或使用 Touch ID）；「復原存取…」則改用 24 個單字的短語，請參閱[復原短語](#recovery-phrase)。

![啟動時解鎖：密碼、結束，或復原短語；在輸入內容之前「好」按鈕會保持停用。基於同樣的原因，這也是照片](site/img/guide/unlock-keyboard.jpg)

![「設定」→「安全性」](site/img/guide/prefs-security.png)

### Touch ID

開啟「使用 Touch ID 解鎖」後，密鑰也會儲存在安全隔離區中，由你的指紋保護：Keepit 會要求你觸碰，而不是輸入密碼。密碼仍可作為備用方式，在提示視窗中選擇「使用密碼」即可。闔上螢幕並使用配備 Touch ID 的外接巧控鍵盤時，Keepit 會在鍵盤上要求觸碰。「允許使用 Touch ID 更改密碼」讓你在更改密碼時，可以用指紋代替舊密碼。

![使用 Touch ID 解鎖；密碼仍可作為備用方式](site/img/guide/touch-id.png)

### 復原短語

設定密碼時，Keepit 會顯示一次由 24 個單字組成的短語。請把它列印出來，或保存在密碼管理工具中。如果忘記密碼，解鎖對話框中的「復原存取…」可以打開資料，並讓你設定新密碼。「復原短語」→「新建…」會產生新的短語，並讓舊的失效；旁邊的「顯示…」會在通過 Touch ID 或密碼驗證後再次顯示目前的短語。

如果沒有密碼、沒有同一部 Mac 上的 Touch ID，也沒有短語，資料就無法復原：沒有伺服器，也沒有任何東西可以重置。

![24 個單字的復原短語（這裡把單字隱藏了）](site/img/guide/recovery-phrase.png)

### 備份

Keepit 可以在你選擇的資料夾（iCloud 雲碟、Dropbox、Google 雲端硬碟、外接磁碟、NAS）中保存一份歷史記錄和範本的加密副本，並在內容有變更時寫入新的副本。Keepit 沒有伺服器：資料夾是你自己的。資料夾背後的服務供應商看得到的是加密檔案、檔案大小，以及一小段未加密的標頭（檔案在何時、由哪個版本的 Keepit 寫入，密鑰如何衍生，隨機識別碼，以及只有在你開啟該選項時才會包含的 Mac 名稱）；[安全性頁面](/security#backups)（英文）逐一列出了每個欄位。

![「設定」→「備份」：自動備份、手動備份、還原](site/img/guide/prefs-backup.png)

**開啟。** 「設定」→「備份」→「自動備份到檔案夾」，然後按「選擇…」挑選資料夾（選擇視窗會在 iCloud 雲碟中打開）。自動備份需要先在「設定」→「安全性」中啟用密碼保護：每份副本都以從你的保險庫密鑰衍生出的密鑰封存，所以在這部 Mac 或任何其他 Mac 上，都能用你的 Keepit 密碼或復原短語打開，不需要另外設定什麼。沒有設定密碼時，這個註記框會停用並說明原因。

**接下來會發生什麼：排程。** 在最後一次變更後大約五分鐘（而且只要 Keepit 在執行，每天至少一次），Keepit 會把名為 `Keepit-<日期和時間>-<安裝>-<id>.keepit` 的檔案寫入資料夾，再讀回來檢查，之後才會刪除自己的副本中超出「保留最近」數量（預設 10，範圍 1–100）的最舊副本。每份副本本身都是完整的，不是增量備份，所以你只需要一個檔案。其他 Mac 製作的副本，或你自己放進去的檔案，絕對不會被動到：共用一個資料夾的兩部 Mac 會寫入兩個各自獨立的系列。「自動備份」標題旁的狀態列會顯示最後一份副本的時間和大小，或上一次嘗試失敗的原因。Keepit 鎖定時什麼都不會發生；「立即備份」（位於「手動備份」下方）不會等待靜止期。

**包含本機名稱**（預設關閉）會把電腦名稱放進每個檔案的未加密標頭，這樣同一個資料夾中的兩個系列在 Finder 裡就很容易分辨。儲存服務供應商看得到這個名稱，這就是它設為選用的原因。

**還原。** 「還原…」會在你解鎖之後打開一份備份（這部 Mac 的、另一部 Mac 的，或匯出的檔案）：解鎖時使用製作該備份的 Mac 的密碼，或那部 Mac 在設定密碼時顯示的復原短語（密碼對話框中的「復原存取…」）。預覽會顯示檔案是在何時、何處製作的，以及包含多少個項目。接著有兩種選擇：

![還原預覽：檔案在何時、由哪個版本的 Keepit 寫入，包含什麼內容，合併或取代](site/img/guide/restore-preview.png)

- 「合併」會加入目前還沒有的內容：歷史記錄項目依內容判斷，備份中的範本則放進一個名為「已匯入 <日期>」的新檔案夾，不帶它們的快速鍵。這樣你就能清楚看到哪些內容來自備份，並加以搬移或刪除。你原有的資料不會被覆寫。
- 「取代」會捨棄目前的歷史記錄和範本，改用備份中的內容。在這之前，Keepit 會把你目前資料的副本（`Keepit-before-restore-…`）寫入備份資料夾，或你挑選的資料夾；如果這份副本無法寫入，取代就不會開始。如果 Keepit 還沒有設定密碼，就會像「儲存為封存檔…」一樣，要求你為這份副本設定一個密碼。

「同時回復偏好設定」會從備份帶回快速鍵、上限和選項；代表對某一部 Mac 的信任的那些設定（Touch ID、URL 自動化及其信任的 App、備份資料夾本身）一律保持這部 Mac 上的現狀。如果備份中的歷史記錄超過這部 Mac 的上限所允許的範圍，Keepit 會在你確認之前告訴你能放進多少。

在還沒有密碼的 Mac 上，用備份的復原短語還原了備份？Keepit 會要求你先設定密碼，這樣還原的資料絕不會以未加密的形式寫入磁碟；它還會讓你選擇在這部 Mac 上沿用那組短語，或取得新的短語。是用密碼還原的？Keepit 會提議把它保留為這部 Mac 的密碼。無論哪種情況，自動備份本身都是每部 Mac 各自的設定：在這裡開啟它並選擇資料夾（用同一個也可以），這部 Mac 就會在舊 Mac 的檔案旁邊開始寫入自己的檔案系列。

**換到新的 Mac** 正是這一切的重點：安裝 Keepit，首次啟動時選擇「從備份還原…」，在你的資料夾中挑選最新的檔案，輸入舊 Mac 的密碼，選擇「取代」；然後在新 Mac 上開啟自動備份。此前製作的副本要用各自寫入當時有效的密碼和短語打開：更改密碼之後，舊的副本仍然需要舊密碼。

**手動備份。** 這裡有兩個按鈕，做的是兩件不同的事。「立即備份」會馬上製作一份和自動備份相同的副本：同樣的檔案類型、同樣的資料夾和系列，用你的 Keepit 密碼或短語打開。「儲存為封存檔…」則會在你選擇的位置寫入一個 `.keepit` *封存檔*，並用你為它另外設定的密碼鎖住：它不需要 Keepit 的密碼保護，Keepit 之後也不會追蹤這個檔案。它適合用來把資料交給別人，或在備份資料夾之外另存一份副本。建議的檔名說明了它是什麼：`Keepit-archive-<日期>-manual.keepit`，有別於自動副本的 `Keepit-<日期和時間>-<安裝>-<id>.keepit`。

![「儲存為封存檔…」：檔名中有 archive 和 manual 字樣](site/img/guide/save-to-archive.png)

![封存檔專用的密碼，附強度指示：不會儲存在任何地方](site/img/guide/archive-password.png)

「還原…」兩種檔案都能打開。封存檔取代了 2.x 的「匯出…」/「匯入…」；這個檔案可以在網站下載版與 App Store 版之間，以及 Keepit 2.x 與 3.x 之間搬移資料。3.0 寫入的檔案需要 3.0 或以上版本才能打開；3.0 可以讀取 2.x 寫入的所有內容。

**如果出了問題。** 失敗的備份會顯示在狀態列中，並以逐漸拉長的間隔重試；先前的副本會保留。如果在還原進行到一半時 Keepit 被結束或 Mac 關機，下次啟動時會悄悄地把一切恢復到還原之前的狀態；在極少數無法恢復的情況下（無法寫入的檔案、磁碟已滿），它會指出是哪個檔案，然後不做任何更動就結束：請先處理該檔案，再重新啟動。更多細節，包括檔案格式的內部結構，都在[安全性頁面](/security#backups)（英文）上。

## 第 7 部分：進階

### 自動化：keepit:// URL 架構

「捷徑」（「打開URL」）、Raycast、Alfred、Keyboard Maestro 或 shell 中的 `open` 都可以控制 Keepit，**前提是你先開啟這項功能**：「設定」→「進階」→「自動化」→「允許 keepit:// URL 指令」。它預設為關閉，因為任何 App 或網頁都能打開 URL，而 `add` / `paste` 會更動剪貼板並在最前面的 App 中輸入文字；關閉時，Keepit 會忽略這類 URL 並發出提示音。開啟後，Keepit 會查看是誰打開了 URL：每個 App 第一次發出會造成變更的指令（`paste`、`copy`、`template`、`add`、`add-template`、`pause`、`resume`）時，都會顯示一個對話框。「允許」只執行這一次，「永遠允許」會把該 App 加入信任列表（可在同一面板中用「忘記信任的 App」清除）。網頁瀏覽器，或 macOS 無法識別的來源，每次都會詢問。只打開 Keepit 自身視窗的指令則從不詢問。

| URL | 效果 |
|-----|--------|
| `keepit://paste/2`<br>`keepit://paste/latest`<br>`keepit://paste/previous` | 把歷史記錄的第 N 個項目（或最新的 / 前一個項目）貼到最前面的 App |
| `keepit://copy/3` | 把第 N 個項目放到剪貼板上，不貼上 |
| `keepit://template/Signature`<br>`keepit://template/Work/Reply?copy=1` | 依名稱或檔案夾路徑貼上（或拷貝）範本 |
| `keepit://add?text=…` | 把文字加入歷史記錄和剪貼板 |
| `keepit://add-template?text=…&name=…` | 建立範本 |
| `keepit://history`<br>`keepit://templates`<br>`keepit://viewer`<br>`keepit://settings` | 打開歷史記錄選單、範本選單、檢視器、設定 |
| `keepit://pause`<br>`keepit://resume` | 暫停記錄 10 分鐘 / 恢復記錄 |

文字需要進行百分比編碼（空格是 `%20`）。Keepit 鎖定時會忽略 URL。

### 更新

Keepit 每天檢查一次 GitHub Releases，並在對話框中提供更新；「檢查更新項目⋯」會立即檢查。更新經過簽署（EdDSA）和公證。使用 Homebrew 時，`brew upgrade --cask keepit` 可以達到相同效果。每個下載項目的檢查碼都在版本頁面的 `SHA256SUMS` 中。

這項檢查是 Keepit 發出的唯一網路請求，而且是選用的：「設定」→「一般」→「更新」→「自動檢查更新」。關閉之後，Keepit 就不會連到任何地方，即使你要求也一樣，「檢查更新項目⋯」也會從選單中消失；這時你可以從 [keep.it.com](https://keep.it.com) 下載，或使用 Homebrew 來更新。App Store 版本沒有更新程式，也沒有這個選項；它由 App Store 更新。

### 解除安裝

「設定」→「進階」→「重置與解除安裝」→「解除安裝…」會移除 App、資料檔案夾、鑰匙圈項目（包括 Touch ID 密鑰）、登入項目和「輔助使用」中的項目。它會要求你輸入密碼或使用 Touch ID、手動輸入 `DELETE`，並再確認一次。如果你之後可能還需要這些資料，請先匯出備份。使用 Homebrew 的話，之後請執行 `brew uninstall --cask --force keepit`，讓 Homebrew 忘掉這個 cask。

## 參考資料

### 疑難排解

**選擇項目後沒有貼上任何內容。** 缺少「輔助使用」權限：「系統設定」→「隱私權與安全性」→「輔助使用」→ Keepit。如果 Keepit 已經在列表中卻仍然無法貼上，請先關閉再重新開啟。重新安裝 App 後，macOS 會忘記先前授予的權限。

**快速鍵沒有反應。** 它被其他 App 或 macOS 佔用了；Keepit 會在啟動時回報這種情況。請在「快速鍵」面板中選擇另一組按鍵。在原廠設定的 Mac 上，⌃⌥ 搭配數字和字母是沒有被佔用的。也可能是 Keepit 空出來的預設快速鍵，因為它在你的某個鍵盤配置中會輸入字元；「快速鍵」面板中該欄位下方的註記會說明。請換一組按鍵，或按一下欄位並按下同一組合鍵以照舊使用。

**選單在錯誤的位置打開。** 你所在的 App 沒有公開它的文字游標位置，所以選單改在滑鼠指標處打開。如果你希望一律使用指標位置，可以關閉「一般」面板中的「盡可能在文字游標處打開選單」來停用游標搜尋。

**我拷貝的某些內容不見了。** 來源 App 標示為隱藏的內容不會被記錄；當密碼管理工具（內建列表）或你的忽略列表中的 App 位於最前面時所拷貝的內容也不會被記錄，這也包括你剛剛才切換離開的那個 App。請參閱「設定」→「歷史記錄」和[安全性頁面](/security#what-is-not-recorded)（英文）。

**沒有出現 Touch ID 選項。** 目前沒有可用的 Touch ID 感測器（螢幕已闔上，也沒有配備 Touch ID 的鍵盤）。Keepit 會保留這項設定，一旦有感測器可用，就會要求你提供指紋。

**備份狀態顯示資料夾無法使用。** 資料夾已被搬移、重新命名、卸載，或（iCloud 雲碟）已從本機儲存空間中移除。重新裝載或恢復它之後，下一次備份就會成功；或者用「選擇…」挑選新的資料夾。新資料夾會開始一個新的系列，舊檔案則留在原處。

**備份檔案打不開。** 「密碼錯誤」表示檔案的認證標籤不相符：請確認你使用的是*寫入*該檔案的那部 Mac 的密碼（更改密碼後，舊副本仍要用舊密碼打開），或它的復原短語。「此備份需要 Keepit 3.0 或更新版本」表示寫入該檔案的版本比正在打開它的版本新。

**Homebrew 拒絕覆蓋安裝現有的 App。** 請先結束 Keepit，並把 `/Applications/Keepit.app` 移到垃圾桶，或加上 `--force`。
