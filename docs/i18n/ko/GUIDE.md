# Keepit 사용 설명서

Keepit은 macOS용 클립보드 기록 및 템플릿 관리자입니다. 메뉴 막대에 자리하고, 복사한 모든 것을
기억하며, 단축키로 어떤 항목이든 다시 붙여넣습니다. 아래의 단축키는 모두 기본값이고 각각
*설정 → 단축키*에서 바꿀 수 있습니다. 이 설명서는 Keepit 3을 다룹니다. Keepit 2.x 설명서는
[keep.it.com/v2/guide](https://keep.it.com/v2/guide)(영어)에 그대로 남아 있습니다.

## 1부. 시작하기

### 설치

**Homebrew.** `brew upgrade`로 최신 상태를 유지할 수 있어서 권장하는 방법입니다.

```bash
brew tap andrey-insarov/keepit https://github.com/andrey-insarov/Keepit
brew install --cask andrey-insarov/keepit/keepit
```

**DMG.** [최신 릴리스](https://github.com/andrey-insarov/Keepit/releases/latest)에서
`Keepit-<버전>.dmg`를 내려받아 열고 Keepit을 *응용 프로그램* 폴더로 드래그합니다.

![DMG: Keepit을 응용 프로그램 폴더로 드래그합니다](site/img/guide/dmg.png)

앱을 처음 열면 macOS가 이 앱이 인터넷에서 내려받은 것이며 Apple이 검사했음을 확인해 줍니다.
*열기*를 클릭하세요.

![macOS Gatekeeper 확인 창](site/img/guide/gatekeeper.png)

Keepit은 서명과 공증을 마쳤고, 스스로 업데이트하며, macOS 13 Ventura 이상이 설치된 Apple Silicon
및 Intel Mac에서 네이티브로 실행됩니다.

### 처음 실행

Keepit은 메뉴 막대 앱입니다. Dock 아이콘이 없고, 직접 열기 전에는 윈도우도 없습니다. 처음
실행하면 메뉴 막대에 📎 아이콘이 나타나고 Keepit이 세 가지를 묻습니다.

**1. 백업에서 복원할까요?** 새 Mac이고 Keepit 백업(iCloud Drive나 다른 폴더의 자동 백업, 또는
내보낸 `.keepit` 파일)이 있다면 *백업에서 복원…*이 다른 어떤 일보다 먼저 기록과 템플릿을
되돌려 놓습니다. 파일은 그 파일을 만든 Mac의 암호나 그 Mac의 복구 문구로 잠금 해제합니다.
*새로 시작*은 이 단계를 건너뜁니다. 같은 복원 기능은 나중에 *설정 → 백업 → 복원…*에서도 쓸 수
있고, Finder에서 `.keepit` 파일을 이중 클릭해도 열립니다. 자세한 내용은 [백업](#backup)에
있습니다.

![새 Mac에서 받는 첫 질문: 백업에서 복원할지, 새로 시작할지](site/img/guide/restore-first-run.png)

**2. 암호(선택 사항).** Keepit은 기록과 템플릿을 암호화해서 저장하고 Touch ID로 잠금 해제할 수
있습니다. 지금 정해도 되고 나중에 *설정 → 보안*에서 정해도 됩니다. 작동 방식은
[6부](#part-6-security)에서 설명합니다. *나중에*를 선택하면 모든 것이 디스크에 암호화되지 않은
채로 남습니다. 방금 백업을 그 백업의 암호로 복원했다면 Keepit이 그 암호를 이 Mac에서도 계속
쓰도록 제안합니다.

![처음 실행할 때의 암호 설정 제안](site/img/guide/password-offer.png)

![나중에를 선택한 경우: 그것이 무엇을 뜻하고 어디에서 바꿀 수 있는지 알려 주는 안내](site/img/guide/no-password-notice.png)

**3. 손쉬운 사용 권한.** Keepit은 사용자 대신 붙여넣기 위해 작업 중이던 앱으로 ⌘V를 보냅니다.
macOS는 *시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용*에 등록된 앱에만 이를 허용합니다.
*시스템 설정 열기*를 클릭하고 Keepit을 켜세요. 이 권한이 없어도 Keepit은 기록하고 복사하지만
⌘V는 직접 눌러야 합니다.

![Keepit이 손쉬운 사용 권한을 요청합니다](site/img/guide/accessibility-prompt.png)

![개인정보 보호 및 보안 → 손쉬운 사용에서 켜진 Keepit](site/img/guide/accessibility-settings.png)

Keepit은 기본적으로 로그인할 때 실행됩니다. *설정 → 일반*에서 끌 수 있습니다.

## 2부. 일상적인 사용

### 기록 메뉴

아무 앱에서나 **⌥M**을 누르거나 📎 아이콘을 클릭합니다. Keepit이 텍스트 커서를 찾을 수 있으면
메뉴가 커서 옆에 열리고, 찾지 못하면 마우스 포인터 옆에 열립니다.

각 줄은 복사한 항목 하나이며 최신 항목이 맨 위에 있습니다. 최신 항목은 **굵게** 표시됩니다.
지금 클립보드에 들어 있는 것이 바로 그 항목이기 때문입니다. 아이콘은 복사한 앱을 나타냅니다.
제목이 `…`로 끝나면 메뉴에 보이는 것보다 줄이 더 있다는 뜻입니다. 이미지는 축소판으로, 파일
목록은 파일 이름으로 표시됩니다.

![메뉴 옆의 미리보기 패널이 강조 표시된 항목 전체와 원본 앱, 시간, 크기를 보여 줍니다](site/img/guide/menu-preview.png)

![기록 속의 이미지: 메뉴에는 축소판, 미리보기에는 전체 이미지](site/img/guide/menu-image.png)

항목을 붙여넣으려면 클릭하거나, ↑ ↓로 이동한 뒤 Return을 누르거나, **⌃⌥**와 함께 항목 번호를
누릅니다. `⌃⌥3`은 3번 항목을 붙여넣습니다. 같은 키는 메뉴를 열지 않아도 어디에서나 작동합니다.

기록 아래에는 *템플릿* 하위 메뉴, 뷰어(⌥E), 설정(⌥S), *기록 지우기*(⌥C), *10분간 기록 일시
정지*(⌥P, 기록에 남기고 싶지 않은 내용을 입력할 때), 암호가 설정된 경우의 *Keepit 잠그기*(⌥L),
그리고 업데이트 항목이 있습니다. **⌥T**는 템플릿 메뉴만 따로 엽니다. 이 키들은 모두 메뉴 없이도
작동합니다.

### 검색과 미리보기

**검색.** 메뉴가 열려 있을 때 입력을 시작하세요. 맨 위의 필드가 제목과 전체 텍스트로 목록을
걸러 내므로 긴 항목 한가운데의 줄도 찾을 수 있습니다. Return은 첫 번째 일치 항목을 붙여넣고,
Esc는 필드를 지우며, Esc를 한 번 더 누르면 메뉴가 닫힙니다.

**미리보기.** 항목 위에 포인터를 올리거나 키보드로 이동하면 메뉴 옆의 패널이 이미지 전체 또는 긴
텍스트의 첫 몇 줄을 원본 앱, 날짜, 크기와 함께 보여 줍니다. 한 줄짜리 짧은 텍스트에는 미리보기가
없습니다. 메뉴의 줄에 이미 전체가 보이기 때문입니다.

![입력하면 메뉴가 걸러지고, 미리보기 패널이 강조 표시된 항목을 보여 줍니다](site/img/guide/search-preview.png)

### 메뉴 없이 붙여넣기

전역 단축키는 어느 앱에서든 그 시점의 기록을 대상으로 작동합니다(1번 항목이 클립보드입니다).

| 키 | 동작 |
|------|--------------|
| `⌃⌥1` … `⌃⌥9`, `⌃⌥0` | 기록의 1–10번 항목을 붙여넣습니다 |
| `⌥⇧V` | *이전* 항목(2번 항목)을 붙여넣습니다. 다시 누르면 서로 자리를 되바꿉니다 |
| `⌃⌥V` | 클립보드를 서식을 뺀 일반 텍스트로 붙여넣습니다 |
| `⌃⌥U` `⌃⌥L` `⌃⌥T` `⌃⌥S` | 클립보드를 대문자 / 소문자 / 단어 첫 글자 대문자 / 문장 첫 글자 대문자로 붙여넣습니다 |
| `⌃⌥W` | 클립보드의 앞뒤 공백을 잘라 내고 붙여넣습니다 |
| `⌃⌥J` | 클립보드를 한 줄로 이어서 붙여넣습니다 |
| `⌃⌥K` `⌃⌥D` `⌃⌥Y` | 클립보드에 취소선 / 밑줄 / 물결 밑줄을 넣어 붙여넣습니다. 채팅을 포함해 어디에서나 모양이 유지되는 일반 텍스트입니다(아래 참고) |
| `⌃⌥X` | 클립보드에서 이 장식들을 없애고 붙여넣습니다 |
| `⌃⌥A` | 클립보드를 템플릿에 추가합니다 |
| `⌃⌥⌫` | 기록에서 최신 항목을 삭제합니다 |

이 세 가지 장식은 서식이 아닙니다. Keepit이 모든 글자 뒤에 유니코드 *결합 문자*를 붙이는 방식입니다
(취̶소̶선̶, 밑̲줄̲, 물̰결̰). 그래서 실제 서식이라면 사라졌을 메신저, 웹 양식, 터미널에서도 텍스트가
똑같이 보입니다. 대가도 있습니다. 이런 텍스트는 크기가 세 배가 되고, 원래 단어로 검색해도 찾을 수
없으며, 화면 읽기 프로그램이 제대로 읽지 못하고, 일부 서체에서는 선이 고르지 않게 그려집니다.
*장식 제거*(`⌃⌥X`)는 이 문자들을 다시 떼어 냅니다. 다른 곳에서 장식한 텍스트에서도 떼어 냅니다.
어느 방향이든 이 문자들은 출처와 관계없이 코드 포인트 기준으로 제거됩니다. 같은 문자를 글자로
쓰는 음성 표기(U+0330은 IPA에서 짜내기 소리를 나타내는 기호이기도 합니다)에서는 그 문자가
사라지고, 세 가지 장식도 먼저 그 문자들을 제거합니다. VoiceOver가 켜져 있으면 `⌃⌥`는 VoiceOver
자체의 보조 키입니다. 설정 → 단축키에서 *최신 항목에 대한 동작*에 다른 보조 키를 지정하세요.

변환은 텍스트에 적용됩니다. 이미지나 파일 목록에서는 키를 눌러도 경고음만 납니다. 이 모든
단축키는 *설정 → 단축키*에서 바꾸거나 끌 수 있습니다.

### 붙여넣기 대기열

한곳에서 다섯 가지를 복사해 다른 곳에 순서대로 붙여넣고 싶을 때가 있습니다. 셀을 양식에, 페이지의
줄을 문서에 옮기는 경우입니다. 붙여넣기 대기열은 메뉴 없이 이 일을 해 줍니다.

1. **⌥N**을 누릅니다(또는 메뉴에서 *붙여넣기 대기열 시작*을 선택합니다). 메뉴 막대 아이콘에
   빨간 점과 카운터가 표시됩니다: `📎 ● 0`.
2. 평소처럼 ⌘C로 원하는 만큼 복사합니다. 복사할 때마다 카운터가 올라갑니다: 1, 2, 3…
   모든 항목은 기록에도 남습니다.

   ![대기열이 켜져 있을 때의 메뉴 막대: 빨간 점과 카운터](site/img/guide/queue-menubar.png)

3. 텍스트를 넣을 곳으로 전환하고 항목마다 **⌥V**를 누릅니다. 가장 먼저 복사한 것이 가장 먼저
   붙여넣어지고 카운터가 내려갑니다. ⌘V는 여전히 평소처럼 클립보드를 붙여넣으므로 둘을 섞어 쓸
   수 있습니다.
4. 대기열은 마지막 항목을 붙여넣은 뒤, 또는 복사나 붙여넣기 없이 2분이 지나면 스스로 꺼집니다
   (시간은 조절할 수 있습니다). ⌥N을 다시 누르면 더 일찍 멈춥니다.

**⌥⇧N**은 대기열에 남아 있는 것을 한꺼번에 붙여넣습니다. 항목은 줄바꿈, 탭, 공백으로 잇거나
아무것도 넣지 않고 이을 수 있습니다. 설정의 *붙여넣기 대기열* 패널에서 선택하며, 대기 시간도
그곳에서 정합니다. 대기열이 켜져 있는 동안 기록 메뉴는 대기열 항목을 표시합니다. `▶`는 다음에
붙여넣을 항목, `○`는 아직 대기 중인 항목, `✓`는 이미 붙여넣은 항목입니다.

![대기열이 켜진 기록 메뉴: ○ 대기 중, ▶ 다음, ✓ 붙여넣음. 메뉴 줄에 남은 개수가 표시됩니다](site/img/guide/queue-menu.png)

![설정 → 붙여넣기 대기열](site/img/guide/prefs-queue.png)

### 확장 메뉴

기록 메뉴가 열려 있을 때 **⇧**를 누르고 있으면 모든 항목에 그 항목에 쓸 수 있는 동작을 모은 `▸`
하위 메뉴가 생깁니다. 붙여넣기, 서식 없는 텍스트로 붙여넣기, 복사만(클립보드에만 넣고 붙여넣지
않음), *다음으로 붙여넣기* 변환, 템플릿에 추가, 뷰어에서 보기, 삭제가 있습니다. 항목을
가리키거나 →를 누르면 하위 메뉴가 열립니다. 열린 뒤에는 ⇧에서 손을 떼도 됩니다.

![⇧를 누르고 있으면 모든 항목에 하위 메뉴가 생깁니다. 최신 항목에서는 전역 단축키가 표시됩니다](site/img/guide/extended-menu.png)

최신 항목의 하위 메뉴에는 위 표의 전역 단축키가 나열됩니다. 같은 키로 하는 같은 동작이므로
여기에서 익힐 수 있습니다. 다른 항목에는 동작이 키 없이 표시됩니다. 단축키는 어디에서나
작동하거나, 아니면 아예 표시되지 않습니다.

![다른 항목의 경우: 같은 동작, 단축키 없음](site/img/guide/extended-menu-item2.png)

![이미지의 경우 텍스트 동작은 흐리게 표시됩니다. 붙여넣기, 복사만, 템플릿에 추가, 뷰어에서 보기, 삭제만 쓸 수 있습니다](site/img/guide/extended-menu-image.png)

## 3부. 템플릿

템플릿은 계속 보관해 두는 항목입니다. 서명, 주소, 준비해 둔 답장, 코드 조각, 자주 붙여넣는 로고
같은 것들입니다. 폴더가 있는 트리에 들어 있고, 기록 메뉴의 *템플릿* 하위 메뉴와 **⌥T**에
나타납니다. 새로 설치하면 *예제* 폴더(인사말, 오늘 날짜, 클립보드 인용, 서명)가 들어 있어서 직접
만들기 전에 템플릿으로 무엇을 할 수 있는지 볼 수 있습니다. 마음대로 삭제하거나 편집하세요. 예제
템플릿은 *설정 → 고급 → 재설정 및 설치 제거 → 재설정…*으로 되돌릴 수 있지만, 이 명령은 다른
데이터와 설정도 함께 재설정합니다.

![예제 폴더: 항목 위에 포인터를 올리면 텍스트가 보입니다](site/img/guide/template-examples.png)

![템플릿 메뉴: 폴더는 하위 메뉴로 열리고, & 뒤의 글자는 단축 문자가 됩니다](site/img/guide/template-menu-letters.png)

### 만들기와 정리하기

**템플릿 추가**

- 기록 메뉴에서: 최신 항목은 `⌃⌥A`, 맨 아래의 *클립보드를 템플릿에 추가*, 또는 아무 항목이나
  ⇧ → 항목의 하위 메뉴 → *템플릿에 추가*.
- 뷰어에서: 기록 항목을 선택하고 *템플릿에 추가*를 클릭하거나 템플릿 트리로 드래그합니다. *새
  항목*은 빈 텍스트 템플릿을 만들고, *파일에서 새 항목*(컨텍스트 메뉴)은 텍스트 파일이나 이미지
  파일로 템플릿을 만듭니다.

**정리**

- *새 폴더*는 폴더를 만듭니다. 항목을 폴더 사이로 드래그하거나 컨텍스트 메뉴의 *위로* /
  *아래로*를 사용하세요.
- 이름이 `-`인 템플릿은 메뉴에서 구분선이 됩니다.
- 이름에서 글자 앞에 `&`를 넣으면(예: `&Signature`) 그 글자가 템플릿 메뉴에서 항목의 단축
  문자가 됩니다. 메뉴가 열려 있을 때 `S`를 누르세요.
- 컨텍스트 메뉴의 *단축키 설정*은 템플릿에 전용 전역 단축키를 지정합니다.
- 이름이 없는 템플릿은 첫 줄이 표시됩니다. *이름 변경*과 *이름 지우기*는 컨텍스트 메뉴에 있고,
  텍스트 위의 *이름* 필드를 편집해도 됩니다.

### 자리표시자

텍스트 템플릿에는 붙여넣는 시점에 채워지는 `{…}` 자리표시자를 넣을 수 있습니다. 나머지는 모두
그대로 붙여넣어집니다. 뷰어의 **삽입 ▾**은 모든 자리표시자를 나열하고 선택한 것을 커서 위치에
넣어 주므로 외울 것이 없습니다.

![오늘 날짜 예제: `{date:EEEE, d MMMM yyyy}`는 붙여넣을 때 현재 날짜가 됩니다](site/img/guide/template-examples-date.png)

![뷰어의 삽입 ▾은 모든 자리표시자를 나열합니다](site/img/guide/insert-menu.png)

가장 유용한 것들:

| 자리표시자 | 결과 |
|-------------|--------|
| `{date}` `{time}` `{datetime}` | 오늘 날짜 / 현재 시간, 시스템 형식 |
| `{date:yyyy-MM-dd}` | 원하는 형식(`yyyy MM dd EEEE HH mm …`) |
| `{date:long}` `{time:short}` `{datetime:medium}` | 이름이 있는 스타일: `short` `medium` `long` `full` |
| `{date+7d}` `{date-1m:MMMM}` `{time+1h}` `{date+1y-2d}` | 이동: `d` 일, `w` 주, `m` 개월, `y` 년, `h` 시간. `date`, `time`, `datetime`에 쓰며 여러 개를 이어 쓸 수 있습니다 |
| `{clipboard}` `{clipboard:2}` | 클립보드, 또는 기록의 N번 항목 |
| `{clipboard\|upper}` `{clipboard\|trim\|oneline}` | 필터 `upper` `lower` `title` `trim` `oneline` `url`, 이어 쓸 수 있습니다 |
| `{cursor}` | 붙여넣은 뒤 텍스트 커서가 놓일 위치 |
| `{user}` `{username}` `{host}` | 전체 이름, 계정 이름, 컴퓨터 이름 |
| `{uuid}` `{random:1-100}` | 새 UUID, 난수 |
| `{{` `}}` | 중괄호 문자 그대로: 템플릿 `{{"x":1}}`은 `{"x":1}`로 붙여넣어집니다 |

자리표시자 이름은 소문자입니다. `{date}`는 자리표시자이고 `{Date}`와 `{DATE}`는 텍스트여서
그대로 붙여넣어집니다. 스타일 이름과 필터(`{date:LONG}`, `{clipboard|UPPER}`)는 어느 쪽으로
써도 됩니다.

전체 목록은 [자리표시자 요약](#placeholder-cheat-sheet)에 있습니다.

### 질문하는 템플릿

`{input:이름}`과 `{choice:레이블=A|B|C}`는 템플릿을 작은 양식으로 바꿉니다. 붙여넣을 때 Keepit이
먼저 값을 묻고, 그다음 완성된 텍스트를 붙여넣습니다. 같은 이름은 몇 번 나오든 한 번만 묻습니다.
`{input:이름=기본값}`은 필드를 미리 채워 둡니다.

![{input:Name}이 들어 있는 템플릿을 붙여넣으면 먼저 값을 묻습니다](site/img/guide/input-dialog.png)

예를 들어 답장 템플릿은 이렇습니다.

```
{input:이름}님, 안녕하세요.

{date-1d}에 보내 주신 메시지 감사합니다. {date+3d:M월 d일}까지 답변드리겠습니다.
{cursor}
{user}
```

붙여넣으면 *이름*을 묻고, 날짜를 채우고, 전체 이름으로 서명하고, 빈 줄에 커서를 둡니다.

## 4부. 뷰어

메뉴의 *뷰어…* 또는 📎 아이콘 오른쪽 클릭으로 트리가 세 개 있는 윈도우를 엽니다. **클립보드**(지금의
클립보드, 읽기 전용), **기록**(*텍스트 및 파일*과 *이미지*), **템플릿**입니다.

![템플릿이 선택된 뷰어](site/img/guide/viewer.png)

- 항목을 선택하면 오른쪽에 표시됩니다. 텍스트는 그 자리에서 편집할 수 있고, 편집기를 벗어날 때
  변경 사항이 적용됩니다. 이미지는 패널에 맞게 크기가 조절되어 표시되고 위에 픽셀 크기와 파일
  크기가 나옵니다. 파일 목록은 이중 클릭으로 파일을 엽니다. 컨텍스트 메뉴의 *16진 덤프로 보기*는
  원시 바이트를 보여 줍니다.
- 도구 막대: *클립보드로 보내기*, *붙여넣기*(직전에 쓰던 앱으로), *템플릿에 추가*, *새 항목*, *새
  폴더*, *삭제*, *삽입 ▾*(자리표시자), 그리고 이 설명서를 여는 **?**.
- **검색**(`⌘F`): 왼쪽의 필드가 기록과 템플릿을 이름과 내용으로 걸러 내고 일치하는 부분을 강조
  표시합니다.
- 기록 항목을 보관하려면 템플릿 트리로 드래그하고, 템플릿을 다시 복사하려면 기록으로
  드래그합니다. 순서는 드래그하거나 *위로* / *아래로*로 바꿉니다. ⌫는 선택한 항목을 삭제합니다.
- 상태 막대에는 날짜, 원본 앱, 형식, 크기가 표시됩니다.

![뷰어에서 검색하면 일치하는 부분이 강조 표시됩니다](site/img/guide/viewer-search.png)

기록, ⌥T 템플릿, ⌥E 뷰어, ⌥S 설정, ⌥C 기록 지우기, ⌥P 일시 정지, ⌥L 잠금, ⌥Q 종료)와 ⌥⇧V, ⌃⌥를

Keepit이 덧붙입니다. macOS나 다른 앱이 어떤 조합을 이미 쓰고 있으면 Keepit이 시작할 때 알려
줍니다. *뷰어* ⌥E, *설정* ⌥S, *기록 지우기* ⌥C, *기록 일시 정지* ⌥P, *Keepit 잠그기* ⌥L,
*Keepit 종료* ⌥Q는 모든 앱에서 작동하며 메뉴에서 각 명령 옆에 표시됩니다. 미국 키보드 배열에서
⌥ + 글자는 보통 특수 문자를 입력합니다(⌥S = ß, ⌥C = ç …). 그런 문자가 필요하면 단축키를 다른
키로 옮기세요.

## 6부. 보안

### 암호와 암호화

*설정 → 보안 → 실행 시 암호 요구*는 기록과 템플릿을 AES-256-GCM으로 암호화합니다. 키는 암호에서
파생되며(PBKDF2, 200 000회 반복) 메모리에만 존재합니다. Keepit이 잠기면 지워집니다. *Keepit
잠그기*(`⌥L`)를 실행할 때, 종료할 때, 그리고 선택한 경우 Mac이 일정 시간 잠겨 있거나 잠자기
상태였을 때입니다. *Keepit 자동 잠금*은 새로 설치한 경우 **안 함**입니다(3.0.3에서 업데이트하면
이전 선택이 유지됩니다. 화면과 함께 잠그기 상자가 켜져 있었다면 *즉시*입니다). 커피를 마시고 올
때마다 암호를 묻는 클립보드 관리자는 결국 쓰지 않게 되고, 중요한 순간에는 `⌥L`이 있기
때문입니다. *즉시*는 화면과 함께 잠급니다. *5분 후*, *15분 후*, *1시간 후*는 잠깐 자리를 비운
것은 그냥 넘기고(Keepit은 잠금 해제된 상태로 계속 기록합니다), Mac이 설정한 시간 내내 잠겨 있거나
잠자기 상태였을 때에만 잠급니다. Mac이 이미 잠겨 있거나 다른 사용자의 세션이 앞에 있는 상태에서
Keepit이 시작될 때(예를 들어 업데이트 후 재실행)에도 마찬가지입니다. macOS가 그 상태를 Keepit에
알려 주는 한 시간은 시작 시점부터 계산됩니다(보통은 알려 줍니다. 알려 줄 수 없으면 다음 잠금이나
잠자기부터 계산이 시작됩니다). Touch ID가 켜져 있으면 Keepit은 Mac의 잠금이 해제되는 순간 터치를
요청하므로 첫 `⌥M` 전에 준비가 끝납니다.

![화면 키보드로 암호 설정하기. 스크린샷이 아니라 화면을 찍은 사진입니다. 제작자의 Mac에서 이 장면을 스크린샷으로 찍으면 대화상자만 나옵니다](site/img/guide/set-password-keyboard.jpg)

암호 대화상자는 현재 키보드 배열을 보여 주고 Caps Lock을 경고하므로, 암호가 거부되는 이유를 알
수 없는 경우는 드뭅니다. 필드 옆의 키보드 버튼은 마우스로 암호를 입력하는 **화면 키보드**를
엽니다. 클릭은 시스템에 키 입력으로 전달되지 않고, 키는 열 때마다 섞이며, 키보드는 스크린샷과
화면 기록에서 자신을 빼 달라고 macOS에 요청합니다(일부 구성에서는 제외되지만 보장되지는
않습니다). 완전히 신뢰하지 못하는 Mac이나 화면을 공유 중인 Mac을 위한 기능입니다. 실행할 때와
잠긴 뒤에 Keepit은 암호(또는 Touch ID)를 묻습니다. *접근 복구…*는 그 대신 24단어 문구를
받습니다. [복구 문구](#recovery-phrase)를 참고하세요.

![실행 시 잠금 해제: 암호, 종료, 또는 복구 문구. 무언가를 입력하기 전까지 확인 버튼은 비활성 상태입니다. 위와 같은 이유로 사진으로 찍었습니다](site/img/guide/unlock-keyboard.jpg)

![설정 → 보안](site/img/guide/prefs-security.png)

### Touch ID

*Touch ID로 잠금 해제*를 켜면 키가 지문으로 보호되는 Secure Enclave에도 저장됩니다. Keepit은 암호
대신 터치를 요청합니다. 암호는 대체 수단으로 계속 작동합니다. 요청 창에서 *암호 사용*을 선택하면
됩니다. 덮개를 닫고 Touch ID가 있는 외장 Magic Keyboard를 쓰는 경우 Keepit은 키보드에서 터치를
요청합니다. *Touch ID로 암호 변경 허용*은 암호를 바꿀 때 지문이 이전 암호를 대신하게 해 줍니다.

![Touch ID로 잠금 해제. 암호는 대체 수단으로 남습니다](site/img/guide/touch-id.png)

### 복구 문구

암호를 설정하면 Keepit이 24단어 문구를 한 번 보여 줍니다. 인쇄하거나 암호 관리자에 보관하세요.
암호를 잊었다면 잠금 해제 대화상자의 *접근 복구…*로 데이터를 열고 새 암호를 설정할 수 있습니다.
*복구 문구 → 새로 만들기…*는 새 문구를 발급하고 이전 문구를 무효로 만듭니다. 그 옆의 *보기…*는
Touch ID나 암호로 확인한 뒤 현재 문구를 다시 보여 줍니다.

암호, 같은 Mac의 Touch ID, 문구 중 어느 것도 없으면 데이터를 복구할 수 없습니다. 서버가 없고
재설정할 것도 없기 때문입니다.

![24단어 복구 문구(여기에서는 단어를 가렸습니다)](site/img/guide/recovery-phrase.png)

### 백업

Keepit은 기록과 템플릿의 암호화된 사본을 사용자가 고른 폴더(iCloud Drive, Dropbox, Google Drive,
외장 디스크, NAS)에 보관하고, 무언가 바뀔 때마다 새 사본을 기록할 수 있습니다. Keepit 서버는
없습니다. 폴더는 사용자의 것입니다. 그 폴더를 제공하는 업체가 볼 수 있는 것은 암호화된 파일, 파일
크기, 그리고 암호화되지 않은 작은 헤더입니다(언제 어떤 Keepit이 기록했는지, 키를 어떻게
파생하는지, 임의의 식별자, 그리고 켰을 때에만 Mac의 이름). [보안 페이지](/security#backups)(영어)에
필드별로 나와 있습니다.

![설정 → 백업: 자동 백업, 수동 백업, 복원](site/img/guide/prefs-backup.png)

**켜기.** *설정 → 백업 → 폴더에 자동으로 백업*을 켠 다음 *선택…*으로 폴더를 고릅니다(선택 창은
iCloud Drive에서 열립니다). 자동 백업에는 *설정 → 보안*의 암호 보호가 필요합니다. 각 사본은
보관소의 키에서 파생된 키로 봉인되므로, 이 Mac이든 다른 Mac이든 Keepit 암호나 복구 문구로 열 수
있고 따로 설정할 것이 없습니다. 암호가 없으면 체크상자가 비활성화되고 그 이유가 표시됩니다.

**그다음에 일어나는 일: 일정.** 마지막 변경으로부터 약 5분 뒤에(그리고 Keepit이 실행 중인 동안
적어도 하루에 한 번) Keepit은 `Keepit-<날짜와 시간>-<설치>-<id>.keepit`이라는 이름의 파일을
폴더에 기록하고, 다시 읽어서 확인한 다음에야 *보관 개수*(기본값 10, 범위 1–100)를 넘는 자신의
가장 오래된 사본을 삭제합니다. 각 사본은 증분이 아니라 그 자체로 완전하므로 파일 하나만 있으면
됩니다. 다른 Mac이 만든 사본이나 사용자가 직접 넣어 둔 파일은 절대 건드리지 않습니다. 폴더 하나를
함께 쓰는 Mac 두 대는 서로 독립된 두 계열을 기록합니다. *자동 백업* 제목 옆의 상태 줄에는 마지막
사본의 시간과 크기, 또는 마지막 시도가 실패한 이유가 표시됩니다. Keepit이 잠겨 있는 동안에는
아무 일도 일어나지 않습니다. *지금 백업*(*수동 백업* 아래)은 대기 시간을 기다리지 않습니다.

**이 Mac의 이름 포함**(기본적으로 꺼짐)은 각 파일의 암호화되지 않은 헤더에 컴퓨터 이름을 넣어서
한 폴더 안의 두 계열을 Finder에서 쉽게 구분할 수 있게 합니다. 저장소 제공업체가 그 이름을 볼 수
있으므로 선택 사항으로 두었습니다.

**복원.** *복원…*은 잠금을 해제한 뒤 백업(이 Mac의 것, 다른 Mac의 것, 또는 내보낸 파일)을 엽니다.
잠금 해제에는 그 백업을 만든 Mac의 암호, 또는 그 Mac이 암호를 설정할 때 보여 준 복구 문구(암호
대화상자의 *접근 복구…*)를 씁니다. 미리보기에서 파일이 언제 어디에서 만들어졌고 항목이 몇 개
들어 있는지 볼 수 있습니다. 그다음 두 가지 선택이 있습니다.

![복원 미리보기: 파일을 언제 어떤 Keepit이 기록했는지, 무엇이 들어 있는지, 병합 또는 대치](site/img/guide/restore-preview.png)

- *병합*은 아직 없는 것만 추가합니다. 기록 항목은 내용을 기준으로 추가하고, 백업의 템플릿은
  단축키 없이 *가져옴 <날짜>*라는 새 폴더 하나로 추가합니다. 그래서 백업에서 무엇이 왔는지 정확히
  볼 수 있고 옮기거나 삭제할 수 있습니다. 기존 데이터는 아무것도 덮어쓰지 않습니다.
- *대치*는 현재의 기록과 템플릿을 버리고 백업의 것으로 바꿉니다. 그 전에 Keepit은 지금 가지고
  있는 것의 사본(`Keepit-before-restore-…`)을 백업 폴더나 사용자가 고른 폴더에 기록합니다. 그
  사본을 기록할 수 없으면 대치는 시작되지 않습니다. Keepit에 아직 암호가 없으면 *아카이브로
  저장…*과 마찬가지로 그 사본에 쓸 암호를 묻습니다.

*환경설정도 복원*은 백업에서 단축키, 한도, 옵션을 가져옵니다. 특정 Mac에 대한 신뢰를 나타내는
설정(Touch ID, URL 자동화와 신뢰하는 앱, 백업 폴더 자체)은 항상 이 Mac의 값 그대로 남습니다.
백업의 기록이 이 Mac의 한도보다 크면 Keepit이 확인을 받기 전에 얼마나 들어갈지 알려 줍니다.

아직 암호가 없는 Mac에서 백업을 그 백업의 복구 문구로 복원했나요? Keepit은 먼저 암호를 설정하라고
요청하므로 복원된 데이터가 암호화되지 않은 채 저장되는 일은 없습니다. 그리고 그 문구를 이
Mac에서도 계속 쓸지 새 문구를 받을지 고를 수 있습니다. 암호로 복원했나요? Keepit이 그 암호를 이
Mac의 암호로 유지하도록 제안합니다. 어느 경우든 자동 백업 자체는 Mac마다 따로 정하는 설정입니다.
여기에서 켜고 폴더를 선택하면(같은 폴더여도 됩니다) 이 Mac은 이전 Mac의 파일 옆에 자신의 파일
계열을 시작합니다.

**새 Mac으로 옮기기**가 이 기능의 핵심입니다. Keepit을 설치하고, 처음 실행할 때 *백업에서
복원…*을 선택하고, 폴더에서 가장 최신 파일을 고르고, 이전 Mac의 암호를 입력하고, *대치*를
선택합니다. 그런 다음 새 Mac에서 자동 백업을 켭니다. 그때까지 만들어진 사본은 각각 기록될 당시에
쓰이던 암호와 문구로 열립니다. 암호를 바꾼 뒤에도 예전 사본에는 예전 암호가 필요합니다.

**수동 백업.** 버튼이 두 개 있고 하는 일이 서로 다릅니다. *지금 백업*은 자동 백업과 같은 종류의
사본을 바로 만듭니다. 같은 종류의 파일, 같은 폴더와 계열이며 Keepit 암호나 문구로 엽니다.
*아카이브로 저장…*은 사용자가 고른 위치에 `.keepit` *아카이브* 하나를 기록하고, 그 아카이브용으로
정한 암호로 잠급니다. Keepit의 암호 보호가 없어도 되고, 그 뒤로 Keepit은 이 파일을 추적하지
않습니다. 데이터를 넘겨줄 때나 백업 폴더 밖에 사본을 둘 때 씁니다. 제안되는 이름을 보면 무엇인지
알 수 있습니다. 자동 사본은 `Keepit-<날짜와 시간>-<설치>-<id>.keepit`이고 아카이브는
`Keepit-archive-<날짜>-manual.keepit`입니다.

![아카이브로 저장…: 파일 이름에 archive와 manual이 들어 있습니다](site/img/guide/save-to-archive.png)

![강도 표시기가 있는 아카이브 전용 암호: 어디에도 저장되지 않습니다](site/img/guide/archive-password.png)

*복원…*은 두 종류를 모두 엽니다. 아카이브는 2.x의 *내보내기…* / *가져오기…*를 대신합니다. 이
파일로 사이트에서 내려받는 에디션과 App Store 에디션 사이, 그리고 Keepit 2.x와 3.x 사이에서
데이터를 옮깁니다. 3.0이 기록한 파일을 열려면 3.0 이상이 필요하고, 3.0은 2.x가 기록한 모든 것을
읽습니다.

**문제가 생겼을 때.** 실패한 사본은 상태 줄에 표시되고 간격을 점점 늘려 가며 다시 시도합니다.
이전 사본은 그대로 남습니다. 복원 도중에 Keepit이 종료되었거나 Mac이 꺼졌다면 다음 실행 때 모든
것을 복원 전 상태로 조용히 되돌립니다. 드물게 그렇게 할 수 없는 경우(기록할 수 없는 파일, 가득
찬 디스크)에는 파일 이름을 알려 주고 아무것도 바꾸지 않은 채 종료합니다. 파일 문제를 해결하고
다시 실행하세요. 파일 형식의 내부 구조를 포함한 자세한 내용은
[보안 페이지](/security#backups)(영어)에 있습니다.

## 7부. 고급

### 자동화: keepit:// URL 스킴

단축어(*URL 열기*), Raycast, Alfred, Keyboard Maestro, 또는 셸의 `open`으로 Keepit을 조작할 수
있습니다. 단, *설정 → 고급 → 자동화 → keepit:// URL 명령 허용*에서 **켠 다음에만** 가능합니다.
어떤 앱이나 웹 페이지든 URL을 열 수 있고 `add` / `paste`는 클립보드를 바꾸고 맨 앞의 앱에 입력하기
때문에 기본적으로 꺼져 있습니다. 꺼져 있을 때 Keepit은 그런 URL을 경고음과 함께 무시합니다. 켜져
있으면 Keepit은 누가 URL을 열었는지 확인합니다. 각 앱에서 무언가를 바꾸는 첫 명령(`paste`, `copy`,
`template`, `add`, `add-template`, `pause`, `resume`)은 대화상자에 표시됩니다. *허용*은 한 번만
실행하고, *항상 허용*은 그 앱을 신뢰하는 앱 목록에 넣습니다(같은 패널의 *신뢰하는 앱 잊기*로 목록을
비웁니다). 웹 브라우저나 macOS가 이름을 알 수 없는 발신자에게는 매번 묻습니다. Keepit 자신의
윈도우만 여는 명령은 묻지 않습니다.

| URL | 효과 |
|-----|--------|
| `keepit://paste/2`<br>`keepit://paste/latest`<br>`keepit://paste/previous` | 기록의 N번 항목(또는 최신 항목 / 이전 항목)을 맨 앞의 앱에 붙여넣습니다 |
| `keepit://copy/3` | N번 항목을 붙여넣지 않고 클립보드에 넣습니다 |
| `keepit://template/Signature`<br>`keepit://template/Work/Reply?copy=1` | 이름이나 폴더 경로로 지정한 템플릿을 붙여넣습니다(또는 복사합니다) |
| `keepit://add?text=…` | 기록과 클립보드에 텍스트를 추가합니다 |
| `keepit://add-template?text=…&name=…` | 템플릿을 만듭니다 |
| `keepit://history`<br>`keepit://templates`<br>`keepit://viewer`<br>`keepit://settings` | 기록 메뉴, 템플릿 메뉴, 뷰어, 설정을 엽니다 |
| `keepit://pause`<br>`keepit://resume` | 기록을 10분간 일시 정지 / 다시 시작합니다 |

텍스트는 퍼센트 인코딩하세요(공백은 `%20`). Keepit이 잠겨 있는 동안에는 URL이 무시됩니다.

### 업데이트

Keepit은 하루에 한 번 GitHub Releases를 확인하고 대화상자로 업데이트를 제안합니다. *업데이트
확인…*은 바로 확인합니다. 업데이트는 서명(EdDSA)과 공증을 거칩니다. Homebrew에서는
`brew upgrade --cask keepit`이 같은 일을 합니다. 모든 다운로드의 체크섬은 릴리스 페이지의
`SHA256SUMS`에 있습니다.

이 확인은 Keepit이 보내는 유일한 네트워크 요청이며 선택 사항입니다: *설정 → 일반 → 업데이트 →
자동으로 업데이트 확인*. 끄면 Keepit은 사용자가 요청하더라도 어디에도 연결하지 않고, *업데이트
확인…*은 메뉴에서 사라집니다. 그때는 [keep.it.com](https://keep.it.com)에서 내려받거나
Homebrew로 업데이트합니다. App Store 에디션에는 업데이트 기능도 이 옵션도 없습니다. App Store가
업데이트합니다.

### 설치 제거

*설정 → 고급 → 재설정 및 설치 제거 → 설치 제거…*는 앱, 데이터 폴더, 키체인 항목(Touch ID 키
포함), 로그인 항목, 손쉬운 사용 항목을 제거합니다. 암호나 Touch ID, 직접 입력하는 `DELETE`,
그리고 확인을 요구합니다. 데이터가 다시 필요할 수도 있다면 먼저 백업을 내보내세요. Homebrew를
쓴다면 그 뒤에 `brew uninstall --cask --force keepit`을 실행해 Homebrew가 cask를 잊게 하세요.

![설정 → 고급](site/img/guide/prefs-advanced.png)

## 참고 자료

### 문제 해결

**항목을 선택해도 아무것도 붙여넣어지지 않습니다.** 손쉬운 사용 권한이 없습니다: *시스템 설정 →
개인정보 보호 및 보안 → 손쉬운 사용 → Keepit*. Keepit이 목록에 있는데도 붙여넣지 않으면 껐다가
다시 켜세요. 앱을 다시 설치하면 macOS가 허용했던 권한을 잊습니다.

**단축키가 아무 동작도 하지 않습니다.** 다른 앱이나 macOS가 그 키를 쓰고 있습니다. Keepit은 실행할
때 이를 알려 줍니다. *단축키* 패널에서 다른 조합을 고르세요. 숫자나 글자와 함께 쓰는 ⌃⌥ 조합은
기본 상태의 Mac에서 비어 있습니다.

**메뉴가 엉뚱한 곳에 열립니다.** 사용 중인 앱이 텍스트 커서 위치를 알려 주지 않아서 메뉴가 마우스
포인터 위치에 열리는 것입니다. 항상 포인터 위치가 좋다면 일반 패널의 *가능하면 텍스트 커서 위치에
메뉴 열기*를 꺼서 커서 찾기를 끌 수 있습니다.

**복사한 것이 보이지 않습니다.** 복사한 앱이 숨김으로 표시한 것은 기록되지 않습니다. 암호
관리자(내장 목록)나 무시 목록에 있는 앱이 맨 앞에 있을 때 복사한 것도 기록되지 않으며, 방금 다른
앱으로 전환하기 직전까지 쓰던 앱도 여기에 포함됩니다. *설정 → 기록*과
[보안 페이지](/security#what-is-not-recorded)(영어)를 참고하세요.

**Touch ID가 제안되지 않습니다.** 지금 사용할 수 있는 Touch ID 센서가 없습니다(덮개가 닫혀 있고
Touch ID 키보드가 없음). Keepit은 설정을 유지하고 센서를 사용할 수 있게 되는 즉시 지문을
요청합니다.

**백업 상태에 폴더를 사용할 수 없다고 나옵니다.** 폴더가 이동되었거나, 이름이 바뀌었거나, 마운트가
해제되었거나, (iCloud Drive의 경우) 로컬 저장 공간에서 제거되었습니다. 다시 마운트하거나 되돌려
놓으면 다음 사본이 정상적으로 기록됩니다. 또는 *선택…*으로 새 폴더를 고르세요. 새 폴더에서는 새
계열이 시작되고 이전 파일은 있던 자리에 남습니다.

**백업 파일이 열리지 않습니다.** *암호가 틀렸습니다*는 파일의 인증 태그가 일치하지 않았다는
뜻입니다. 그 파일을 *기록한* Mac의 암호(암호를 바꾼 뒤에도 예전 사본은 예전 암호로 열립니다)나 그
Mac의 복구 문구를 쓰고 있는지 확인하세요. *이 백업에는 Keepit 3.0 이상이 필요합니다*는 파일을
여는 버전보다 새로운 버전이 그 파일을 기록했다는 뜻입니다.

**Homebrew가 기존 앱 위에 설치하기를 거부합니다.** 먼저 Keepit을 종료하고
`/Applications/Keepit.app`을 휴지통으로 옮기거나 `--force`를 붙이세요.

여전히 해결되지 않나요? [GitHub Issues](https://github.com/andrey-insarov/Keepit/issues) · admin@keep.it.com
