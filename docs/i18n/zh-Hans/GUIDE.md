# Keepit 使用指南

Keepit 是一款 macOS 上的剪贴板历史记录和模板管理工具。它常驻菜单栏，记住你复制过的所有内容，并能用快捷键把其中任意一项粘贴回来。下面列出的都是默认快捷键，每一个都可以在“设置”→“快捷键”中更改。本指南介绍的是 Keepit 3。Keepit 2.x 的指南原样保留在 [keep.it.com/v2/guide](https://keep.it.com/v2/guide)（英文）。

## 第 1 部分：入门

### 安装

**Homebrew**（推荐），因为 `brew upgrade` 可以让应用保持最新：

```bash
brew tap andrey-insarov/keepit https://github.com/andrey-insarov/Keepit
brew install --cask andrey-insarov/keepit/keepit
```

**DMG**：从[最新版本](https://github.com/andrey-insarov/Keepit/releases/latest)页面下载 `Keepit-<version>.dmg`，打开后把 Keepit 拖到“应用程序”文件夹。

![DMG：把 Keepit 拖到“应用程序”](site/img/guide/dmg.png)

第一次打开应用时，macOS 会确认它是从互联网下载的，并且已经过 Apple 检查。点按“打开”。

![macOS 门禁的确认提示](site/img/guide/gatekeeper.png)

Keepit 经过签名和公证，可以自动更新，并能在装有 macOS 13 Ventura 或更高版本的 Apple 芯片和 Intel Mac 上原生运行。

### 首次启动

Keepit 是一款菜单栏应用：程序坞里没有图标，你不打开就没有窗口。首次启动后，菜单栏中会出现 📎 图标，Keepit 会问你三件事。

**1. 要从备份恢复吗？** 如果这是一台新 Mac，而你有 Keepit 的备份（iCloud 云盘或其他文件夹中的自动备份，或者导出的 `.keepit` 文件），选取“从备份恢复…”可以在进行其他操作之前先把历史记录和模板找回来。文件要用生成它的那台 Mac 的密码或恢复短语来解锁。选取“全新开始”可以跳过这一步。以后也可以在“设置”→“备份”→“恢复…”中进行同样的恢复，在访达中连按 `.keepit` 文件也能打开它。详情请见[备份](#backup)。

![新 Mac 上的第一个问题：从备份恢复，还是全新开始](site/img/guide/restore-first-run.png)

**2. 密码（可选）。** Keepit 可以把历史记录和模板加密保存，并用 Touch ID 解锁。你可以现在决定，也可以稍后在“设置”→“安全”中决定。[第 6 部分](#part-6-security)说明了它的工作方式。选取“暂不”的话，所有内容都以未加密的形式保存在磁盘上。如果你刚刚用备份的密码恢复了备份，Keepit 会询问是否在这台 Mac 上继续使用这个密码。

![首次启动时的密码设置提示](site/img/guide/password-offer.png)

![选取“暂不”时：明确说明这意味着什么，以及在哪里可以更改](site/img/guide/no-password-notice.png)

**3. 辅助功能权限。** 为了替你粘贴，Keepit 会向你刚才使用的应用发送 ⌘V。macOS 只允许“系统设置”→“隐私与安全性”→“辅助功能”列表中的应用这样做。点按“打开系统设置”，然后把 Keepit 打开。没有这项权限时，Keepit 仍会记录和复制，但 ⌘V 需要你自己按。

![Keepit 请求辅助功能权限](site/img/guide/accessibility-prompt.png)

![已在“隐私与安全性”→“辅助功能”中打开 Keepit](site/img/guide/accessibility-settings.png)

Keepit 默认在登录时启动，可以在“设置”→“通用”中关闭。

## 第 2 部分：日常使用

### 历史记录菜单

在任意应用中按 **⌥M**，或者点按 📎 图标。如果 Keepit 能找到文本光标，菜单就在光标处打开，否则在鼠标指针处打开。

每一行是一条复制的内容，最新的排在最前面。最新的一条以**粗体**显示，它就是当前剪贴板里的内容。图标表示内容是从哪个应用复制的。标题以 `…` 结尾，说明这一项的行数比菜单中显示的多。图片显示为缩略图，文件列表显示文件名。

![菜单旁边的预览面板完整显示高亮的项目，并附有来源应用、时间和大小](site/img/guide/menu-preview.png)

![历史记录中的图片：菜单中是缩略图，预览中是完整图片](site/img/guide/menu-image.png)

要粘贴某一项，可以点按它，或者用 ↑ ↓ 移到它上面再按 Return 键，或者按住 **⌃⌥** 再按它的编号：`⌃⌥3` 粘贴第 3 项。这个按键在任何地方都能用，不需要打开菜单。

历史记录下方依次是“模板”子菜单、查看器（⌥E）、设置（⌥S）、“清除历史记录”（⌥C）、“暂停记录 10 分钟”（⌥P，输入不想被记录的内容时使用）、设置了密码时的“锁定 Keepit”（⌥L），以及更新。**⌥T** 单独打开模板菜单。这些按键不打开菜单也都能用。

### 搜索和预览

**搜索。** 菜单打开时直接输入文字：顶部的搜索栏会按标题和全文过滤列表，所以长内容中间的某一行也能找到。按 Return 键粘贴第一个匹配项，按 Esc 清空搜索栏，再按一次 Esc 关闭菜单。

**预览。** 把指针停在某一项上（或用键盘移到它上面），菜单旁边的面板就会显示完整的图片，或者长文本的开头几行，并附有来源应用、日期和大小。只有一行的短文本没有预览，因为菜单里已经显示了全部内容。

![输入文字会过滤菜单，预览面板显示高亮的项目](site/img/guide/search-preview.png)

### 不打开菜单直接粘贴

全局快捷键在任何应用中都能使用，它们作用于当前的历史记录。第 1 项就是剪贴板：

| 按键 | 效果 |
|------|--------------|
| `⌃⌥1` … `⌃⌥9`、`⌃⌥0` | 粘贴历史记录中的第 1 到第 10 项 |
| `⌥⇧V` | 粘贴*上一项*（第 2 项），再按一次换回来 |
| `⌃⌥V` | 把剪贴板内容以纯文本粘贴，去掉格式 |
| `⌃⌥U` `⌃⌥L` `⌃⌥T` `⌃⌥S` | 把剪贴板内容转成大写 / 小写 / 每个单词首字母大写 / 句首字母大写后粘贴 |
| `⌃⌥W` | 去掉剪贴板内容的首尾空白后粘贴 |
| `⌃⌥J` | 把剪贴板内容合并成一行后粘贴 |
| `⌃⌥K` `⌃⌥D` `⌃⌥Y` | 给剪贴板内容加上删除线 / 下划线 / 波浪下划线后粘贴。粘贴的是纯文本，在任何地方（包括聊天软件）都能保持这个样子（见下文） |
| `⌃⌥X` | 去掉这些装饰后粘贴剪贴板内容 |
| `⌃⌥A` | 将剪贴板添加到模板 |
| `⌃⌥⌫` | 从历史记录中删除最新的一项 |

这三种装饰并不是格式。Keepit 是在每个字符后面加上一个 Unicode *组合用记号*（s̶t̶r̶i̶k̶e̶、u̲n̲d̲e̲r̲、w̰a̰v̰y̰），所以文本在聊天软件、网页表单或终端里看起来都一样，而真正的格式在这些地方会丢失。代价是：这样的文本体积是原来的三倍，搜索原来的词找不到它，屏幕阅读器读起来会磕磕绊绊，有些字体画出的线也不均匀。“移除装饰”（`⌃⌥X`）可以把这些记号去掉，在别处加了装饰的文本也适用。两种情况下，记号都是按码位移除的，不管它们来自哪里：把同样的记号当作字母使用的音标（U+0330 同时也是国际音标中表示嘎裂声的符号）会失去这些记号，而三种装饰在添加之前也会先移除它们。打开旁白时，`⌃⌥` 是旁白自己的修饰键，请在“设置”→“快捷键”中给“对最新项的操作”换一个修饰键。

转换只对文本有效。如果是图片或文件列表，按键只会发出提示音。以上这些都可以在“设置”→“快捷键”中更改或关闭。

### 粘贴队列

有时你想在一个地方复制五样东西，再按顺序粘贴到另一个地方，比如把单元格填进表单，或者把网页上的几行文字贴进文稿。粘贴队列不用打开菜单就能做到：

1. 按 **⌥N**（或在菜单中选取“开始粘贴队列”）。菜单栏图标上会出现一个红点和一个计数器：`📎 ● 0`
2. 像平时一样用 ⌘C 复制，次数不限。每复制一次，计数器就加一：1、2、3… 所有内容也会记入历史记录。

   ![队列开启时的菜单栏：红点和计数器](site/img/guide/queue-menubar.png)

3. 切换到要放文字的地方，每一项按一次 **⌥V**。最先复制的最先粘贴，计数器随之减少。⌘V 仍然像平时一样粘贴剪贴板内容，所以两种方式可以混着用。
4. 粘贴完最后一项，或者两分钟内既没有复制也没有粘贴（这个时间可以调整），队列会自动关闭。再按一次 ⌥N 可以提前结束。

**⌥⇧N** 一次性粘贴队列中剩下的所有内容。各项之间可以用换行、制表符、空格连接，或者什么都不加。这在“设置”的“粘贴队列”面板中选择，空闲时间也在那里设置。队列开启时，历史记录菜单会标出队列中的项目：`▶` 表示下一个要粘贴，`○` 表示还在排队，`✓` 表示已经粘贴。

![队列开启时的历史记录菜单：○ 排队中，▶ 下一项，✓ 已粘贴；菜单中的那一行显示还剩多少项](site/img/guide/queue-menu.png)

![“设置”→“粘贴队列”](site/img/guide/prefs-queue.png)

### 扩展菜单

历史记录菜单打开时按住 **⇧**，每一项都会多出一个 `▸` 子菜单，里面是针对这一项的全部操作：粘贴、以纯文本粘贴、仅复制（只放入剪贴板，不粘贴）、“粘贴为”中的各种转换、添加到模板、在查看器中显示、删除。把指针移到某一项上，或者按 →，即可打开子菜单。打开之后就可以松开 ⇧ 了。

![按住 ⇧：每一项都有一个子菜单；最新的一项的子菜单中会显示全局快捷键](site/img/guide/extended-menu.png)

对于最新的一项，子菜单中会列出上表中的全局快捷键。操作和按键都是一样的，所以可以在这里熟悉它们。其他项目只显示操作，不显示按键：快捷键要么在任何地方都有效，要么就不显示。

![其他项目：同样的操作，没有快捷键](site/img/guide/extended-menu-item2.png)

![对于图片，文本相关的操作会变灰，只能使用粘贴、仅复制、添加到模板、在查看器中显示和删除](site/img/guide/extended-menu-image.png)

## 第 3 部分：模板

模板是你要长期保留的内容：签名、地址、常用回复、代码片段、经常粘贴的徽标。它们保存在带文件夹的树状结构中，出现在历史记录菜单的“模板”子菜单里，也可以用 **⌥T** 调出。全新安装时会自带一个“示例”文件夹，里面有问候语、当天日期、剪贴板引用和签名，让你在动手写自己的模板之前先看看模板能做什么。这些示例可以随意删除或编辑（“设置”中的“重置…”可以把它们找回来）。

![“示例”文件夹：把指针停在某一项上会显示它的文本](site/img/guide/template-examples.png)

![模板菜单：文件夹以子菜单的形式打开，& 后面的字母会成为快捷按键](site/img/guide/template-menu-letters.png)

### 创建和整理

**添加模板**

- 在历史记录菜单中：对最新的一项按 `⌃⌥A`，或选取菜单底部的“将剪贴板添加到模板”，或者对任意一项按 ⇧ → 该项的子菜单 →“添加到模板”。
- 在查看器中：选中一条历史记录，点按“添加到模板”，或者把它拖到模板树上。“新建项”会创建一个空白的文本模板。“从文件新建项…”（上下文菜单）可以用文本文件或图片文件创建模板。

**整理**

- “新建文件夹”用来创建文件夹。可以在文件夹之间拖移项目，也可以使用上下文菜单中的“上移”/“下移”。
- 名称为 `-` 的模板在菜单中会变成一条分隔线。
- 在名称中的某个字母前加 `&`（例如 `&Signature`），这个字母就成为该项在模板菜单中的快捷按键：菜单打开时按 `S` 即可。
- 上下文菜单中的“设置快捷键…”可以给模板指定专属的全局快捷键。
- 没有名称的模板会显示它的第一行。“重命名”和“清除名称”在上下文菜单中，也可以直接编辑文本上方的“名称”栏。

### 占位符

文本模板中可以包含 `{…}` 形式的占位符，它们会在粘贴时被填入实际的值。其余内容原样粘贴。在查看器中，**插入 ▾** 列出了所有占位符，选中的那个会放到光标处，所以什么都不用背。

![“今天的日期”示例：`{date:EEEE, d MMMM yyyy}` 在粘贴时会变成当前日期](site/img/guide/template-examples-date.png)

![查看器中的“插入 ▾”列出了所有占位符](site/img/guide/insert-menu.png)

最常用的几个：

| 占位符 | 结果 |
|-------------|--------|
| `{date}` `{time}` `{datetime}` | 今天的日期 / 当前时间，采用系统格式 |
| `{date:yyyy-MM-dd}` | 任意格式（`yyyy MM dd EEEE HH mm …`） |
| `{date:long}` `{time:short}` `{datetime:medium}` | 预设样式：`short` `medium` `long` `full` |
| `{date+7d}` `{date-1m:MMMM}` `{time+1h}` `{date+1y-2d}` | 偏移：`d` 天、`w` 周、`m` 月、`y` 年、`h` 小时。可用于 `date`、`time`、`datetime`，也可以连写多个 |
| `{clipboard}` `{clipboard:2}` | 剪贴板，或历史记录中的第 N 项 |
| `{clipboard\|upper}` `{clipboard\|trim\|oneline}` | 过滤器 `upper` `lower` `title` `trim` `oneline` `url`，可以串联使用 |
| `{cursor}` | 粘贴后文本光标所在的位置 |
| `{user}` `{username}` `{host}` | 全名、账户名、电脑名称 |
| `{uuid}` `{random:1-100}` | 一个新的 UUID；一个随机数 |
| `{{` `}}` | 花括号本身：模板 `{{"x":1}}` 粘贴出来是 `{"x":1}` |

占位符的名称要用小写：`{date}` 是占位符，而 `{Date}` 和 `{DATE}` 只是普通文本，会原样粘贴。样式名称和过滤器（`{date:LONG}`、`{clipboard|UPPER}`）大小写均可。

完整列表见[占位符速查表](#placeholder-cheat-sheet)。

### 会提问的模板

`{input:Name}` 和 `{choice:Label=A|B|C}` 可以把模板变成一个小表单：粘贴时，Keepit 先询问各项的值，然后粘贴填好的文本。同一个名称不管出现多少次都只问一次。`{input:Name=Default}` 会预先填好输入栏。

![粘贴带有 {input:Name} 的模板时，会先询问它的值](site/img/guide/input-dialog.png)

例如，一个回复模板：

```
{input:姓名}，你好：

感谢你 {date-1d} 的来信。我会在{date+3d:EEEE}之前答复你。
{cursor}
{user}
```

粘贴时它会询问“姓名”，填好日期，用你的全名落款，并把光标留在空行上。

## 第 4 部分：查看器

在菜单中选取“查看器…”，或者右键点按 📎 图标，会打开一个包含三棵树的窗口：**剪贴板**（当前剪贴板的内容，只读）、**历史记录**（“文本和文件”与“图片”）和**模板**。

![选中了一个模板的查看器](site/img/guide/viewer.png)

- 选中一项，右侧就会显示它的内容。文本可以就地编辑，离开编辑区时更改生效。图片会缩放到适合面板的大小，上方显示像素尺寸和文件大小。在文件列表中连按可以打开文件。上下文菜单中的“以十六进制转储显示”可以查看原始字节。
- 工具栏：“发送到剪贴板”、“粘贴”（粘贴到你来自的那个应用）、“添加到模板”、“新建项”、“新建文件夹”、“删除”、“插入 ▾”（占位符），以及 **?**（也就是本指南）。
- **搜索**（`⌘F`）：左侧的搜索栏按名称和内容过滤历史记录和模板，并高亮显示匹配的内容。
- 把历史记录中的项目拖到模板树上可以保留它们，把模板拖到“历史记录”可以把它们复制回去。通过拖移或“上移”/“下移”可以调整顺序。⌫ 删除选中的项目。
- 状态栏显示日期、来源应用、格式和大小。

![在查看器中搜索时，匹配的内容会高亮显示](site/img/guide/viewer-search.png)

## 第 5 部分：设置

在菜单中按 `⌘,` 或选取“设置…”，或者在任意应用中按 ⌥S。这个窗口的用法和 Mac 上其他设置窗口一样：在工具栏中选一个面板，所做的更改会立即生效。没有“保存”按钮。用 ⌘W 或 Esc 关闭窗口。旁边带有 **?** 的选项都有弹出式说明。

![“设置”→“通用”](site/img/guide/prefs-general.png)

## 第 6 部分：安全

### 密码和加密

打开“设置”→“安全”→“启动时要求输入密码”后，历史记录和模板会用 AES-256-GCM 加密。密钥由你的密码派生（PBKDF2，200,000 轮），只存在于内存中。Keepit 锁定时密钥会被清除。锁定发生在以下几种情况：执行“锁定 Keepit”（`⌥L`）时，退出时，以及（可选）Mac 锁定或睡眠了一段时间之后。全新安装时，“自动锁定 Keepit”为**从不**（从 3.0.3 更新上来的会保留原来的选择：如果之前勾选了随屏幕一起锁定，则为“立即”）。每次喝杯咖啡回来都要输密码的剪贴板管理工具，大家很快就不用了，而在真正需要的时候可以按 `⌥L`。“立即”表示随屏幕一起锁定。“5 分钟后”、“15 分钟”或“1 小时”不理会短暂的离开：Keepit 保持解锁并继续记录，只有 Mac 在整段时间里都处于离开状态时才会锁定。如果 Keepit 启动时 Mac 已经锁定，或者前台是另一位用户的会话（比如更新后重新启动），情况也一样：离开的时间从启动时算起，前提是 macOS 把这个状态告诉了 Keepit（通常会；如果没有，则从下一次锁定或睡眠开始计时）。打开 Touch ID 后，Mac 一解锁，Keepit 就会请你按指纹，这样在你第一次按 `⌥M` 之前它就已经准备好了。

![用屏幕键盘设置密码。这是对着屏幕拍的照片，不是截屏：在作者的 Mac 上，这个场景的截屏里只有对话框](site/img/guide/set-password-keyboard.jpg)

密码对话框会显示当前的键盘布局，并在大写锁定打开时给出警告，所以密码被拒绝时一般都能很快找到原因。输入栏旁边的键盘按钮会打开一个**屏幕键盘**，可以用鼠标输入密码：这些点按不会作为按键事件经过系统，按键的位置每次打开都会打乱，并且它会请求 macOS 不要让它出现在截屏和屏幕录制中（在某些配置下它会被排除，但不能保证）。它适合用在你不完全信任的 Mac 上，或者正在共享屏幕的 Mac 上。启动时以及锁定之后，Keepit 会要求输入密码（或使用 Touch ID）。“恢复访问…”则接受 24 个单词的恢复短语，见[恢复短语](#recovery-phrase)。

![启动时解锁：密码、退出，或恢复短语；在输入内容之前，“好”按钮不可用。出于同样的原因，这也是照片](site/img/guide/unlock-keyboard.jpg)

![“设置”→“安全”](site/img/guide/prefs-security.png)

### Touch ID

打开“使用 Touch ID 解锁”后，密钥还会保存在安全隔区中，并由你的指纹保护：Keepit 会请你按指纹，而不是输入密码。密码仍然可以作为备用方式使用（提示中的密码按钮）。合上屏幕并使用带 Touch ID 的外接妙控键盘时，Keepit 会在键盘上请求指纹。打开“允许使用 Touch ID 更改密码”后，更改密码时可以用指纹代替旧密码。

![使用 Touch ID 解锁；密码仍可作为备用方式](site/img/guide/touch-id.png)

### 恢复短语

设置密码时，Keepit 会显示一次由 24 个单词组成的短语。请把它打印出来，或者存进密码管理器。如果忘记了密码，在解锁对话框中选取“恢复访问…”可以打开数据，并让你设置新密码。“恢复短语”→“新建…”会生成新的短语，并让旧的失效。旁边的“显示…”在通过 Touch ID 或密码验证后，可以再次显示当前的短语。

如果既没有密码，也没有同一台 Mac 上的 Touch ID，也没有恢复短语，数据就无法恢复：没有服务器，也没有可以重置的东西。

![24 个单词的恢复短语（这里隐藏了单词）](site/img/guide/recovery-phrase.png)

### 备份

Keepit 可以把历史记录和模板的加密副本保存在你选择的文件夹中（iCloud 云盘、Dropbox、Google Drive、外置磁盘、NAS），每当有内容变化时就写入一份新的。Keepit 没有服务器，文件夹是你自己的。文件夹背后的服务商能看到的只有加密的文件、文件的大小，以及一小段未加密的文件头（文件是什么时候、由哪个版本的 Keepit 写入的，密钥的派生方式，一些随机标识符；只有在你打开相应选项时才包含 Mac 的名称）。[安全说明页面](/security#backups)（英文）逐个字段列出了文件头的内容。

![“设置”→“备份”：自动备份、手动备份、恢复](site/img/guide/prefs-backup.png)

**打开自动备份。** 打开“设置”→“备份”→“自动备份到文件夹”，然后用“选择…”选一个文件夹（选择窗口会在 iCloud 云盘中打开）。自动备份需要先在“设置”→“安全”中开启密码保护：每份副本都用由你的保险库密钥派生的密钥封存，所以在这台 Mac 或其他任何 Mac 上，都可以用你的 Keepit 密码或恢复短语打开，不需要另外设置什么。没有设置密码时，这个复选框不可用，旁边会说明原因。

**之后会发生什么：备份的时间安排。** 最后一次更改之后大约五分钟（Keepit 运行期间最迟每天一次），Keepit 会向文件夹写入一个名为 `Keepit-<date and time>-<installation>-<id>.keepit` 的文件，再把它读回来核对，然后才删除超出“保留最近”（默认 10 份，可设为 1 到 100）的那些最旧的自己的副本。每份副本本身都是完整的，不是增量，所以任何时候只需要一个文件就够了。其他 Mac 生成的副本，或者你自己放进去的文件，Keepit 都不会动：共用一个文件夹的两台 Mac 会各自写入一个独立的系列。“自动备份”标题旁边的状态行显示最近一份副本的时间和大小，或者上一次尝试失败的原因。Keepit 锁定期间不会进行任何操作。“立即备份”（在“手动备份”下）不会等待那段静止时间。

**“在备份文件中包含本机名称”**（默认关闭）会把电脑的名称写进每个文件未加密的文件头，这样同一个文件夹中的两个系列在访达里就很容易区分。存储服务商能看到这个名称，所以这个选项由你决定是否打开。

**恢复。** “恢复…”可以打开一份备份（本机的、其他 Mac 的，或者导出的文件），但需要先解锁：使用生成它的那台 Mac 的密码，或者那台 Mac 在设置密码时显示的恢复短语（密码对话框中的“恢复访问…”）。预览中会显示文件是什么时候、在哪里生成的，以及其中有多少个项目。接下来有两种选择：

![恢复预览：文件是什么时候、由哪个版本的 Keepit 写入的，里面有什么，合并还是替换](site/img/guide/restore-preview.png)

- “合并”会添加现在还没有的内容：历史记录按内容比对，备份中的模板则放进一个名为“导入 <日期>”的新文件夹，不带它们原来的快捷键。这样你能清楚地看到哪些内容来自备份，并可以移动或删除它们。你现有的内容不会被覆盖。
- “替换”会丢弃当前的历史记录和模板，改用备份中的内容。在此之前，Keepit 会把你现有的内容写成一份副本（`Keepit-before-restore-…`），存到备份文件夹或你选择的文件夹。如果这份副本无法写入，替换就不会开始。如果 Keepit 还没有设置密码，会像“保存为归档…”一样，请你为这份副本设置一个密码。

“同时恢复偏好设置”会从备份中恢复快捷键、数量上限和各个选项。那些体现对某台 Mac 的信任的设置（Touch ID、URL 自动化及其受信任的应用、备份文件夹本身）始终保持这台 Mac 上现有的状态。如果备份中的历史记录超出了这台 Mac 的数量上限，Keepit 会在你确认之前告诉你能容纳多少。

在一台还没有设置密码的 Mac 上用恢复短语恢复了备份？Keepit 会先请你设置密码，这样恢复的数据就不会以未加密的形式落到磁盘上，并且让你选择在这台 Mac 上继续使用这个短语，还是生成一个新的。是用密码恢复的？Keepit 会询问是否把它作为这台 Mac 的密码。两种情况下，自动备份都是每台 Mac 各自的设置：在这台 Mac 上打开它并选择文件夹（用同一个文件夹也可以），这台 Mac 就会在旧 Mac 的系列旁边开始写入自己的系列。

**迁移到新 Mac** 正是这项功能的用途：安装 Keepit，首次启动时选取“从备份恢复…”，在你的文件夹中选最新的文件，输入旧 Mac 的密码，选择“替换”，然后在新 Mac 上打开自动备份。在此之前生成的副本，要用各自写入时有效的密码和短语才能打开：更改密码之后，旧的副本仍然需要旧密码。

**手动备份。** 有两个按钮，用途不同。“立即备份”会马上生成一份和自动备份一样的副本：同样的文件类型，同样的文件夹和系列，用你的 Keepit 密码或恢复短语打开。“保存为归档…”会在你指定的位置写入一个 `.keepit` *归档*，并用你专门为它设置的密码锁定。它不需要 Keepit 的密码保护，写入之后 Keepit 也不再跟踪这个文件。它适合用来把数据交给别人，或者在备份文件夹之外另存一份。从建议的文件名就能看出它是什么：归档是 `Keepit-archive-<date>-manual.keepit`，自动副本是 `Keepit-<date and time>-<installation>-<id>.keepit`。

![“保存为归档…”：文件名中带有 archive 和 manual](site/img/guide/save-to-archive.png)

![归档专用的密码，带有强度指示：这个密码不会保存在任何地方](site/img/guide/archive-password.png)

“恢复…”两种文件都能打开。归档取代了 2.x 中的“导出…”/“导入…”。这种文件可以在直接下载版本和 App Store 版本之间转移数据，也可以在 Keepit 2.x 和 3.x 之间转移数据。3.0 写入的文件需要 3.0 或更高版本才能打开；3.0 可以读取 2.x 写入的所有内容。

**如果出了问题。** 副本写入失败时，状态行会给出提示，并以逐渐拉长的间隔重试。之前的副本会保留。如果恢复进行到一半时 Keepit 被退出或者 Mac 关机了，下次启动时会悄悄把一切还原到恢复之前的状态。在极少数无法还原的情况下（某个文件无法写入，或者磁盘已满），Keepit 会指出是哪个文件，然后不做任何更改就退出：解决这个文件的问题后，再重新启动即可。更多细节，包括文件格式的内部结构，请见[安全说明页面](/security#backups)（英文）。

## 第 7 部分：高级功能

### 自动化：keepit:// URL 方案

快捷指令（“打开 URL”）、Raycast、Alfred、Keyboard Maestro，或者 shell 中的 `open` 命令，都可以控制 Keepit，**前提是你已经打开了这项功能**：“设置”→“高级”→“自动化”→“允许 keepit:// URL 命令”。它默认关闭，因为任何应用或网页都可以打开 URL，而 `add` / `paste` 会更改剪贴板，并向前台应用输入内容。关闭时，Keepit 会忽略这类 URL，并发出提示音。打开后，Keepit 会查看是谁打开了 URL：每个应用发来的第一条会更改内容的命令（`paste`、`copy`、`template`、`add`、`add-template`、`pause`、`resume`）都会显示在一个对话框中。“允许”只执行这一次，“始终允许”会把这个应用加入受信任列表（可以在同一个面板中用“忘记受信任的应用”清空）。对于网页浏览器，或者 macOS 无法识别的发送方，每次都会询问。只是打开 Keepit 自己窗口的命令从不询问。

| URL | 效果 |
|-----|--------|
| `keepit://paste/2`<br>`keepit://paste/latest`<br>`keepit://paste/previous` | 把历史记录中的第 N 项（或最新的一项 / 上一项）粘贴到前台应用 |
| `keepit://copy/3` | 把第 N 项放入剪贴板，但不粘贴 |
| `keepit://template/Signature`<br>`keepit://template/Work/Reply?copy=1` | 按名称或文件夹路径粘贴（或复制）模板 |
| `keepit://add?text=…` | 把文本添加到历史记录和剪贴板 |
| `keepit://add-template?text=…&name=…` | 创建模板 |
| `keepit://history`<br>`keepit://templates`<br>`keepit://viewer`<br>`keepit://settings` | 打开历史记录菜单、模板菜单、查看器、设置 |
| `keepit://pause`<br>`keepit://resume` | 暂停记录 10 分钟 / 恢复记录 |

文本需要进行百分号编码（空格写作 `%20`）。Keepit 锁定期间会忽略 URL。

### 更新

Keepit 每天检查一次 GitHub Releases，有更新时会用对话框提示。选取“检查更新…”可以立即检查。更新经过签名（EdDSA）和公证。如果使用 Homebrew，`brew upgrade --cask keepit` 可以达到同样的效果。每个下载文件的校验和都在版本发布页面的 `SHA256SUMS` 中。

这项检查是 Keepit 发出的唯一网络请求，而且可以关闭：“设置”→“通用”→“更新”→“自动检查更新”。关闭后，Keepit 不会连接任何地方，即使你主动要求也不会，“检查更新…”也会从菜单中消失。这时可以从 [keep.it.com](https://keep.it.com) 下载，或者用 Homebrew 来更新。App Store 版本没有更新程序，也没有这个选项，它由 App Store 负责更新。

### 卸载

“设置”→“高级”→“重置与卸载”→“卸载…”会移除应用、数据文件夹、钥匙串条目（包括 Touch ID 密钥）、登录项和辅助功能中的条目。它会要求你输入密码或使用 Touch ID，键入 `DELETE`，并再次确认。如果以后可能还需要这些数据，请先导出一份备份。如果是用 Homebrew 安装的，之后请运行 `brew uninstall --cask --force keepit`，让 Homebrew 也清除这个 cask 的记录。

## 参考

### 故障排除

**选择项目后没有粘贴任何内容。** 缺少辅助功能权限：请检查“系统设置”→“隐私与安全性”→“辅助功能”→“Keepit”。如果 Keepit 已经在列表中却仍然不粘贴，请先关闭再重新打开：重新安装应用后，macOS 会忘记之前的授权。

**某个快捷键没有反应。** 它被其他应用或 macOS 占用了，Keepit 在启动时会报告这一点。请在“快捷键”面板中换一个组合键。在一台没有额外配置的 Mac 上，⌃⌥ 加数字和字母的组合是空闲的。

**菜单打开的位置不对。** 你正在使用的应用没有提供文本光标的位置，所以菜单改为在鼠标指针处打开。如果你希望菜单始终在指针处打开，可以关闭“通用”面板中的“尽可能在文本光标处打开菜单”。

**我复制的某些内容不见了。** 来源应用标记为隐藏的内容不会被记录。当前台是密码管理器（内置列表）或你的忽略列表中的应用时所做的复制也不会被记录，包括你刚刚从中切换出来的那个应用。请参阅“设置”→“历史记录”和[安全说明页面](/security#what-is-not-recorded)（英文）。

**没有提供 Touch ID 选项。** 目前没有可用的 Touch ID 传感器（屏幕合上了，也没有带 Touch ID 的键盘）。Keepit 会保留这项设置，一旦有传感器可用，就会请求指纹。

**备份状态显示文件夹不可用。** 文件夹被移动、改名、推出，或者（iCloud 云盘）被从本地移除了。把它重新装载或恢复之后，下一份副本就能正常写入。也可以用“选择…”换一个新文件夹：新文件夹会开始一个新的系列，旧文件留在原处。

**备份文件打不开。** “密码错误”表示文件的认证标签不匹配：请确认你使用的是*写入*这个文件的那台 Mac 的密码（更改密码之后，旧的副本仍然要用旧密码打开），或者它的恢复短语。“此备份需要 Keepit 3.0 或更新版本”表示写入这个文件的版本比现在打开它的版本新。

**Homebrew 拒绝覆盖安装已有的应用。** 请先退出 Keepit，把 `/Applications/Keepit.app` 移到废纸篓，或者加上 `--force`。
