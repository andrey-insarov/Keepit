# המדריך למשתמש של Keepit

Keepit הוא מנהל של היסטוריית הלוח ושל תבניות ל-macOS. הוא יושב בשורת התפריטים, זוכר כל מה שאתם מעתיקים ומדביק כל פריט בחזרה במקש קיצור. כל הקיצורים שמופיעים כאן הם ברירות המחדל, ואת כולם אפשר לשנות ב“הגדרות ← קיצורים”. המדריך הזה מתאר את Keepit 3; המדריך של Keepit 2.x נשמר ללא שינוי בכתובת [keep.it.com/v2/guide](https://keep.it.com/v2/guide) (באנגלית).

## חלק 1: צעדים ראשונים

### התקנה

**Homebrew.** זו הדרך המומלצת, כי `brew upgrade` שומר על היישום מעודכן:

```bash
brew tap andrey-insarov/keepit https://github.com/andrey-insarov/Keepit
brew install --cask andrey-insarov/keepit/keepit
```

**DMG.** הורידו את `Keepit-<גרסה>.dmg` מעמוד [הגרסה האחרונה](https://github.com/andrey-insarov/Keepit/releases/latest), פתחו אותו וגררו את Keepit אל “יישומים”.

![ה-DMG: גררו את Keepit אל “יישומים”](site/img/guide/dmg.png)

בפעם הראשונה שפותחים את היישום, macOS מאשר שהוא הורד מהאינטרנט ונבדק על ידי Apple. לחצו על “פתח”.

![האישור של Gatekeeper ב-macOS](site/img/guide/gatekeeper.png)

Keepit חתום דיגיטלית ואושר על ידי Apple, מתעדכן בעצמו ופועל ללא אמולציה במחשבי Mac עם Apple silicon או מעבד Intel, עם macOS 13 Ventura ומעלה.

### הפעלה ראשונה

Keepit הוא יישום של שורת התפריטים: אין לו צלמית ב-Dock, ואין חלון עד שפותחים אחד. אחרי ההפעלה הראשונה מופיעה בשורת התפריטים הצלמית 📎, ו-Keepit שואל שלושה דברים.

**1. לשחזר מגיבוי?** אם זה Mac חדש ויש לכם גיבוי של Keepit (גיבוי אוטומטי ב-iCloud Drive או בתיקייה אחרת, או קובץ `.keepit` שיוצא), “שחזור מגיבוי…” מחזיר את ההיסטוריה ואת התבניות לפני שקורה כל דבר אחר. את הקובץ פותחים בסיסמה של ה-Mac שממנו הגיע, או במשפט השחזור שלו. “התחל מחדש” מדלג על השלב. אותו שחזור זמין אחר כך ב“הגדרות ← גיבוי ← שחזר…”, וגם לחיצה כפולה על קובץ `.keepit` ב-Finder פותחת אותו. הפרטים נמצאים בסעיף [גיבוי](#backup).

![השאלה הראשונה ב-Mac חדש: לשחזר מגיבוי או להתחיל מחדש](site/img/guide/restore-first-run.png)

**2. סיסמה (לא חובה).** Keepit יכול לשמור את ההיסטוריה ואת התבניות מוצפנות ולבטל את הנעילה באמצעות Touch ID. אפשר להחליט עכשיו או אחר כך ב“הגדרות ← אבטחה”; [חלק 6](#part-6-security) מסביר איך זה עובד. עם “לא עכשיו” הכול נשאר בדיסק בלי הצפנה. אם שחזרתם לפני רגע גיבוי באמצעות הסיסמה שלו, Keepit מציע להשאיר את הסיסמה הזאת גם ל-Mac הזה.

![ההצעה להגדיר סיסמה בהפעלה הראשונה](site/img/guide/password-offer.png)

![כשבוחרים “לא עכשיו”: הסבר ברור מה המשמעות ואיפה אפשר לשנות](site/img/guide/no-password-notice.png)

**3. הרשאת הנגישות.** כדי להדביק במקומכם, Keepit שולח ‎⌘V‎ ליישום שבו עבדתם. macOS מתיר זאת רק ליישומים שמופיעים תחת “הגדרות המערכת ← פרטיות ואבטחה ← נגישות”. לחצו על “פתח את הגדרות המערכת” והפעילו את Keepit. בלי ההרשאה Keepit ממשיך לתעד ולהעתיק, אבל על ‎⌘V‎ לוחצים בעצמכם.

![Keepit מבקש את הרשאת הנגישות](site/img/guide/accessibility-prompt.png)

![Keepit מופעל תחת “פרטיות ואבטחה ← נגישות”](site/img/guide/accessibility-settings.png)

כברירת מחדל Keepit מופעל בהתחברות. אפשר לכבות זאת ב“הגדרות ← כללי”.

## חלק 2: שימוש יומיומי

### תפריט ההיסטוריה

לחצו על **‎⌥M‎** בכל יישום, או לחצו על הצלמית 📎. התפריט נפתח ליד סמן הטקסט אם Keepit מצליח למצוא אותו, ואם לא, ליד מצביע העכבר.

כל שורה היא פריט אחד שהועתק, והחדש ביותר למעלה. החדש ביותר מופיע ב**הדגשה**, כי הוא מה שנמצא עכשיו בלוח. הצלמית מראה מאיזה יישום העתקתם. כותרת שמסתיימת ב-`…` כוללת יותר שורות ממה שהתפריט מציג. תמונות מוצגות כתמונה ממוזערת, ורשימות קבצים מציגות את שמות הקבצים.

![חלונית התצוגה המקדימה שליד התפריט מציגה את הפריט המסומן במלואו, עם יישום המקור, השעה והגודל](site/img/guide/menu-preview.png)

![תמונה בהיסטוריה: תמונה ממוזערת בתפריט, התמונה המלאה בתצוגה המקדימה](site/img/guide/menu-image.png)

כדי להדביק פריט לחצו עליו, או עברו אליו עם ↑ ↓ ולחצו על Return, או לחצו על המספר שלו יחד עם **‎⌃⌥‎**: `⌃⌥3` מדביק את פריט 3. אותו מקש פועל מכל מקום, גם בלי לפתוח את התפריט.

מתחת להיסטוריה נמצאים תת-התפריט “תבניות”, המציג (‎⌥E‎), ההגדרות (‎⌥S‎), “נקה היסטוריה” (‎⌥C‎), “השהה הקלטה ל‑10 דקות” (‎⌥P‎, למקרה שמקלידים משהו שלא רוצים שיתועד), “נעל את Keepit” (‎⌥L‎) אם הוגדרה סיסמה, ופקודת העדכון. **‎⌥T‎** פותח את תפריט התבניות לבדו. כל המקשים האלה פועלים גם בלי התפריט.

### חיפוש ותצוגה מקדימה

**חיפוש.** כשהתפריט פתוח, התחילו להקליד: השדה שלמעלה מסנן את הרשימה לפי הכותרת ולפי הטקסט המלא, כך שנמצאת גם שורה מאמצע פריט ארוך. Return מדביק את ההתאמה הראשונה, Esc מנקה את השדה, ו-Esc נוסף סוגר את התפריט.

**תצוגה מקדימה.** רחפו מעל פריט (או עברו אליו במקלדת), וחלונית ליד התפריט תציג את התמונה המלאה או את השורות הראשונות של טקסט ארוך, יחד עם יישום המקור, התאריך והגודל. לטקסטים קצרים של שורה אחת אין תצוגה מקדימה, כי שורת התפריט כבר מציגה אותם במלואם.

![ההקלדה מסננת את התפריט; חלונית התצוגה המקדימה מציגה את הפריט המסומן](site/img/guide/search-preview.png)

### הדבקה בלי התפריט

מקשי הקיצור הגלובליים פועלים על ההיסטוריה כפי שהיא באותו רגע (פריט 1 הוא הלוח), מכל יישום:

| מקשים | מה קורה |
|------|--------------|
| `⌃⌥1` … `⌃⌥9`, `⌃⌥0` | מדביק את פריט ההיסטוריה 1–10 |
| `⌥⇧V` | מדביק את הפריט *הקודם* (פריט 2); לחיצה נוספת מחליפה ביניהם בחזרה |
| `⌃⌥V` | מדביק את הלוח כטקסט פשוט, בלי עיצוב |
| `⌃⌥U` `⌃⌥L` `⌃⌥T` `⌃⌥S` | מדביק את הלוח באותיות גדולות / באותיות קטנות / עם אות גדולה בתחילת כל מילה / עם אות גדולה בתחילת משפט |
| `⌃⌥W` | מדביק את הלוח בלי רווחים בהתחלה ובסוף |
| `⌃⌥J` | מדביק את הלוח מאוחד לשורה אחת |
| `⌃⌥K` `⌃⌥D` `⌃⌥Y` | מדביק את הלוח עם קו חוצה / קו תחתון / קו תחתון גלי, כטקסט פשוט ששומר על המראה שלו בכל מקום, כולל צ׳אטים (ראו בהמשך) |
| `⌃⌥X` | מדביק את הלוח אחרי הסרת העיטורים האלה |
| `⌃⌥A` | מוסיף את הלוח לתבניות |
| `⌃⌥⌫` | מוחק מההיסטוריה את הפריט החדש ביותר |

שלושת העיטורים אינם עיצוב: Keepit מוסיף אחרי כל תו *סימן משלב* של Unicode (s̶t̶r̶u̶c̶k̶, u̲n̲d̲e̲r̲, w̰a̰v̰y̰), ולכן הטקסט נראה אותו דבר ביישום מסרים, בטופס באינטרנט או בטרמינל, שבהם עיצוב אמיתי היה הולך לאיבוד. יש לזה מחיר: טקסט כזה גדול פי שלושה, חיפוש של המילה הרגילה לא ימצא אותו, קוראי מסך נתקעים עליו, ויש גופנים שמציירים את הקו בצורה לא אחידה. “הסרת עיטורים” (`⌃⌥X`) מסירה את הסימנים בחזרה, גם מטקסט שעוטר במקום אחר. בשני הכיוונים הסימנים מוסרים לפי נקודת קוד, בלי קשר למקור שלהם: תעתיק פונטי שמשתמש באותם סימנים כאותיות (U+0330 הוא גם סימן ה-IPA לקול חורק) מאבד אותם, וגם שלושת העיטורים מסירים אותם קודם. כש-VoiceOver פועל, `⌃⌥` הוא מקש הצירוף של VoiceOver עצמו: הקצו ל“פעולות על הפריט האחרון” צירוף אחר ב“הגדרות ← קיצורים”.

ההמרות חלות על טקסט; בתמונה או ברשימת קבצים המקש רק משמיע צפצוף. את כל המקשים האלה אפשר לשנות או לכבות ב“הגדרות ← קיצורים”.

### תור ההדבקה

לפעמים רוצים להעתיק חמישה דברים ממקום אחד ולהדביק אותם לפי הסדר במקום אחר: תאים לתוך טופס, שורות מעמוד לתוך מסמך. תור ההדבקה עושה זאת בלי התפריט:

1. לחצו על **‎⌥N‎** (או בחרו בתפריט “הפעלת תור הדבקה”). הצלמית בשורת התפריטים מציגה נקודה אדומה ומונה: `📎 ● 0`.
2. העתיקו כרגיל עם ‎⌘C‎, כמה פעמים שתרצו. המונה עולה בכל העתקה: 1, 2, 3… הכול מתועד גם בהיסטוריה.

   ![שורת התפריטים כשהתור פועל: נקודה אדומה ומונה](site/img/guide/queue-menubar.png)

3. עברו למקום שבו הטקסט צריך להיות ולחצו על **‎⌥V‎** לכל פריט. מה שהעתקתם ראשון מודבק ראשון, והמונה יורד. ‎⌘V‎ ממשיך להדביק את הלוח כרגיל, כך שאפשר לשלב בין השניים.
4. התור נכבה מעצמו אחרי הדבקת הפריט האחרון, או אחרי שתי דקות בלי העתקה ובלי הדבקה (את הזמן אפשר לכוונן). לחיצה נוספת על ‎⌥N‎ עוצרת אותו מוקדם יותר.

**‎⌥⇧N‎** מדביק בבת אחת את כל מה שנשאר בתור. הפריטים מחוברים במעבר שורה, בטאב, ברווח או בלי כלום; בוחרים זאת בחלונית “תור הדבקה” בהגדרות, ושם מגדירים גם את זמן ההמתנה. כל עוד התור פועל, תפריט ההיסטוריה מסמן את הפריטים שלו: `▶` הבא להדבקה, `○` עדיין בתור, `✓` כבר הודבק.

![תפריט ההיסטוריה כשהתור פועל: ○ בתור, ▶ הבא, ✓ הודבק; שורת התפריט מראה כמה נשארו](site/img/guide/queue-menu.png)

![הגדרות ← תור הדבקה](site/img/guide/prefs-queue.png)

### התפריט המורחב

החזיקו את **‎⇧‎** כשתפריט ההיסטוריה פתוח, וכל פריט יקבל תת-תפריט `▸` עם כל הפעולות לאותו פריט: הדבק, הדבק כטקסט פשוט, העתק בלבד (ללוח, בלי להדביק), ההמרות של “הדבק בתור”, הוסף לתבניות, הצג במציג, מחק. הצביעו על פריט או לחצו על → כדי לפתוח אותו; אחרי שנפתח אפשר לשחרר את ‎⇧‎.

![החזיקו את ‎⇧‎: כל פריט מקבל תת-תפריט; בפריט החדש ביותר הוא מציג את מקשי הקיצור הגלובליים](site/img/guide/extended-menu.png)

בפריט החדש ביותר תת-התפריט מפרט את מקשי הקיצור הגלובליים מהטבלה שלמעלה. אלה אותן פעולות עם אותם מקשים, כך שאפשר ללמוד אותם כאן. בשאר הפריטים הפעולות מוצגות בלי מקשים: קיצור או שפועל בכל מקום, או שאינו מוצג.

![בשאר הפריטים: אותן פעולות, בלי קיצורים](site/img/guide/extended-menu-item2.png)

![בתמונה פעולות הטקסט מעומעמות; זמינות רק הדבק, העתק בלבד, הוסף לתבניות, הצג במציג ומחק](site/img/guide/extended-menu-image.png)

## חלק 3: תבניות

תבניות הן פריטים ששומרים לתמיד: חתימות, כתובות, תשובות מוכנות, קטעי קוד, לוגו שמדביקים לעיתים קרובות. הן שמורות בעץ עם תיקיות ומופיעות בתת-התפריט “תבניות” שבתפריט ההיסטוריה ותחת **‎⌥T‎**. התקנה חדשה מגיעה עם תיקיית “דוגמאות” (ברכה, התאריך של היום, ציטוט של הלוח וחתימה), כדי שתראו מה תבניות יכולות לעשות לפני שתכתבו משלכם. אפשר למחוק או לערוך אותן כרצונכם. את תבניות הדוגמה מחזירים דרך “הגדרות ← מתקדם ← איפוס והסרה ← איפוס…”, אבל הפעולה הזאת מאפסת גם את שאר הנתונים וההגדרות.

![תיקיית “דוגמאות”: ריחוף מעל פריט מציג את הטקסט שלו](site/img/guide/template-examples.png)

![תפריט התבניות: תיקיות נפתחות כתת-תפריטים, והאותיות שאחרי & הופכות לקיצורים](site/img/guide/template-menu-letters.png)

### יצירה וארגון

**הוספת תבנית**

- מתפריט ההיסטוריה: `⌃⌥A` לפריט החדש ביותר, “הוסף את הלוח לתבניות” בתחתית, או ‎⇧‎ ← תת-התפריט של הפריט ← “הוסף לתבניות” לכל פריט.
- במציג: בחרו פריט מההיסטוריה ולחצו על “הוסף לתבניות”, או גררו אותו אל עץ התבניות. “פריט חדש” יוצר תבנית טקסט ריקה; “פריט חדש מקובץ” (בתפריט ההקשר) יוצר תבנית מקובץ טקסט או מקובץ תמונה.

**ארגון**

- “תיקייה חדשה” יוצרת תיקייה. גררו פריטים בין תיקיות, או השתמשו ב“למעלה” / “למטה” שבתפריט ההקשר.
- תבנית ששמה `-` הופכת בתפריט לקו מפריד.
- `&` לפני אות בשם, למשל `&Signature`, הופך את האות הזאת לקיצור של הפריט בתפריט התבניות: לחצו על `S` כשהתפריט פתוח.
- “הגדר מקש קיצור” שבתפריט ההקשר נותן לתבנית מקש קיצור גלובלי משלה.
- תבנית בלי שם מציגה את השורה הראשונה שלה. “שנה שם” ו“נקה שם” נמצאים בתפריט ההקשר, ואפשר גם לערוך את השדה “שם” שמעל הטקסט.

### מצייני מקום

תבניות טקסט יכולות להכיל מצייני מקום `{…}` שמתמלאים ברגע ההדבקה. כל השאר מודבק בלי שינוי. במציג, **הוסף ▾** מפרט את כל מצייני המקום ומציב את זה שנבחר במקום הסמן, כך שאין מה לשנן.

![הדוגמה “התאריך של היום”: `{date:EEEE, d MMMM yyyy}` הופך בהדבקה לתאריך הנוכחי](site/img/guide/template-examples-date.png)

![“הוסף ▾” במציג מפרט את כל מצייני המקום](site/img/guide/insert-menu.png)

השימושיים ביותר:

| מציין מקום | תוצאה |
|-------------|--------|
| `{date}` `{time}` `{datetime}` | התאריך של היום / השעה הנוכחית, בפורמט המערכת |
| `{date:yyyy-MM-dd}` | כל פורמט שהוא (`yyyy MM dd EEEE HH mm …`) |
| `{date:long}` `{time:short}` `{datetime:medium}` | סגנון בעל שם: `short` `medium` `long` `full` |
| `{date+7d}` `{date-1m:MMMM}` `{time+1h}` `{date+1y-2d}` | הזזה: `d` ימים, `w` שבועות, `m` חודשים, `y` שנים, `h` שעות; ב-`date`, `time`, `datetime`, ואפשר כמה ברצף |
| `{clipboard}` `{clipboard:2}` | הלוח, או פריט N מההיסטוריה |
| `{clipboard\|upper}` `{clipboard\|trim\|oneline}` | המסננים `upper` `lower` `title` `trim` `oneline` `url`, ואפשר לשרשר אותם |
| `{cursor}` | המקום שבו יעמוד סמן הטקסט אחרי ההדבקה |
| `{user}` `{username}` `{host}` | שם מלא, שם החשבון, שם המחשב |
| `{uuid}` `{random:1-100}` | UUID חדש; מספר אקראי |
| `{{` `}}` | סוגריים מסולסלים כלשונם: התבנית `{{"x":1}}` מדביקה `{"x":1}` |

שמות מצייני המקום נכתבים באותיות קטנות: `{date}` הוא מציין מקום, ואילו `{Date}` ו-`{DATE}` הם טקסט ומודבקים כמו שהם. את שמות הסגנונות ואת המסננים (`{date:LONG}`, `{clipboard|UPPER}`) אפשר לכתוב בשתי הצורות.

הרשימה המלאה נמצאת ב[דף העזר למצייני מקום](#placeholder-cheat-sheet).

### תבניות ששואלות שאלות

`{input:שם}` ו-`{choice:תווית=A|B|C}` הופכים תבנית לטופס קטן: כשמדביקים אותה, Keepit שואל קודם על הערכים ואז מדביק את הטקסט המוגמר. על אותו שם שואלים רק פעם אחת, לא משנה כמה פעמים הוא מופיע; `{input:שם=ברירת מחדל}` ממלא את השדה מראש.

![הדבקת תבנית עם {input:Name} שואלת קודם על הערך](site/img/guide/input-dialog.png)

למשל, תבנית של תשובה:

```
שלום {input:שם},

תודה על ההודעה מ-{date-1d}. אחזור אליך עד {date+3d:EEEE}.
{cursor}
{user}
```

בהדבקה היא שואלת על “שם”, ממלאת את התאריכים, חותמת בשמכם המלא ומשאירה את הסמן בשורה הריקה.

## חלק 4: המציג

“מציג…” בתפריט, או לחיצה ימנית על הצלמית 📎, פותחים חלון עם שלושה עצים: **לוח** (הלוח כרגע, לקריאה בלבד), **היסטוריה** (“טקסט וקבצים” ו“תמונות”) ו**תבניות**.

![המציג עם תבנית שנבחרה](site/img/guide/viewer.png)

- בחרו פריט כדי לראות אותו מימין. את הטקסט אפשר לערוך במקום, והשינויים חלים כשיוצאים מהעורך. תמונה מוצגת בגודל שמתאים לחלונית, ומעליה הגודל בפיקסלים וגודל הקובץ. ברשימות קבצים לחיצה כפולה פותחת את הקובץ. “הצג כ‑hex dump” שבתפריט ההקשר מציג את הבייטים הגולמיים.
- סרגל הכלים: “שלח ללוח”, “הדבק” (ליישום שממנו הגעתם), “הוסף לתבניות”, “פריט חדש”, “תיקייה חדשה”, “מחק”, “הוסף ▾” (מצייני מקום) ו-**?**, שפותח את המדריך הזה.
- **חיפוש** (`⌘F`): השדה שבצד מסנן את ההיסטוריה ואת התבניות לפי שם ותוכן ומדגיש את ההתאמה.
- גררו פריטים מההיסטוריה אל עץ התבניות כדי לשמור אותם, ותבניות אל ההיסטוריה כדי להעתיק אותן בחזרה; את הסדר משנים בגרירה או ב“למעלה” / “למטה”. ⌫ מוחק את הפריט שנבחר.
- שורת המצב מציגה את התאריך, יישום המקור, הפורמט והגודל.

![חיפוש במציג מדגיש את ההתאמות](site/img/guide/viewer-search.png)

בחלונית **קיצורים** לחצו על שדה ולחצו על צירוף מקשים; ⌫ מכבה מקש. צירוף שכבר משמש פקודה אחרת נדחה, והסיבה מוצגת מתחת לשדות. “אפס לברירת מחדל” מחזיר את הסדרה של ‎⌥‎ + אות (‎⌥M‎ היסטוריה, ‎⌥T‎ תבניות, ‎⌥E‎ מציג, ‎⌥S‎ הגדרות, ‎⌥C‎ ניקוי ההיסטוריה, ‎⌥P‎ השהיה, ‎⌥L‎ נעילה, ‎⌥Q‎ יציאה), את ‎⌥⇧V‎ ואת ‎⌃⌥‎. “הדבק פריט לפי מספר” ו“פעולות על הפריט האחרון” מקבלים רק מקשי צירוף; את הספרה או את האות מוסיף Keepit. אם macOS או יישום אחר כבר מחזיקים בצירוף כלשהו, Keepit מודיע על כך בהפעלה. “מציג” ‎⌥E‎, “הגדרות” ‎⌥S‎, “נקה היסטוריה” ‎⌥C‎, “השהיית ההקלטה” ‎⌥P‎, “נעל את Keepit” ‎⌥L‎ ו“צא מ‑Keepit” ‎⌥Q‎ פועלים מכל יישום ומוצגים בתפריט ליד הפקודות שלהם. בפריסת מקלדת אמריקאית ‎⌥‎ + אות מקליד בדרך כלל תו מיוחד (‎⌥S‎ = ß, ‎⌥C‎ = ç …); אם אתם צריכים אחד מהם, העבירו את הקיצור למקש אחר. Keepit גם קורא את פריסות המקלדת שלכם: האותיות שמוצגות בהגדרות ובתפריטים הן אלה שעל מקשי הפריסה שבה אתם משתמשים, וקיצור ברירת מחדל שהיה לוקח תו שהפריסה שלכם צריכה (‎⌥L‎ מקליד @ בגרמנית ו‑ł בפולנית) נשאר פנוי כש‑Keepit מופעל; ההערה מתחת לשדה שלו אומרת זאת. לחצו על השדה והקישו את הצירוף כדי להשתמש בו בכל זאת. בפריסה שאינה לטינית, כמו העברית, השמות נלקחים מהפריסה הלטינית ש‑macOS מצמיד לה, כמו בתפריטי המערכת עצמה.

## חלק 6: אבטחה

### סיסמה והצפנה

“הגדרות ← אבטחה ← דרוש סיסמה בהפעלה” מצפין את ההיסטוריה ואת התבניות ב-AES-256-GCM. המפתח נגזר מהסיסמה שלכם (PBKDF2, 200 000 סבבים) וקיים רק בזיכרון. הוא נמחק כש-Keepit ננעל: בפקודה “נעל את Keepit” (`⌥L`), ביציאה, ולפי בחירה אחרי שה-Mac היה נעול או במצב שינה למשך זמן מה. “נעילה אוטומטית של Keepit” מוגדרת בהתקנה חדשה ל**אף פעם** (עדכון מגרסה 3.0.3 שומר על הבחירה הקודמת, כלומר “מיד” אם התיבה של נעילה יחד עם המסך הייתה מסומנת): במנהל לוח שמבקש סיסמה אחרי כל הפסקת קפה מפסיקים להשתמש, ולרגעים החשובים יש `⌥L`. “מיד” נועל יחד עם המסך. “אחרי 5 דקות”, “אחרי 15 דקות” ו“אחרי שעה” מתעלמים מהיעדרות קצרה (Keepit נשאר לא נעול וממשיך לתעד) ונועלים רק אם ה-Mac היה נעול או במצב שינה במשך כל הזמן שהוגדר. אותו דבר נכון כש-Keepit מופעל בזמן שה-Mac כבר נעול או שבחזית נמצאת הפעלה של משתמש אחר (למשל הפעלה מחדש אחרי עדכון): הזמן נספר מההפעלה, ככל ש-macOS מדווח על המצב הזה ל-Keepit (בדרך כלל כן; כשאינו יכול, הספירה מתחילה בנעילה או בשינה הבאה). כש-Touch ID מופעל, Keepit מבקש נגיעה ברגע שנעילת ה-Mac מבוטלת, כך שהוא מוכן לפני ה-`⌥M` הראשון.

![הגדרת הסיסמה באמצעות המקלדת שעל המסך. זה תצלום של המסך ולא צילום מסך: ב-Mac של המחבר צילום מסך של המצב הזה מראה רק את תיבת הדו-שיח](site/img/guide/set-password-keyboard.jpg)

תיבות הדו-שיח של הסיסמה מציגות את פריסת המקלדת הנוכחית ומזהירות מפני Caps Lock, כך שסיסמה שנדחתה היא רק לעיתים רחוקות תעלומה. כפתור המקלדת שליד השדה פותח **מקלדת על המסך** להקלדת הסיסמה בעכבר: הלחיצות לעולם אינן עוברות במערכת כהקשות מקשים, המקשים מעורבבים בכל פתיחה, והמקלדת מבקשת מ-macOS להשאיר אותה מחוץ לצילומי מסך ולהקלטות מסך (בתצורות מסוימות היא אכן לא נכללת; אין לכך ערובה). היא מיועדת ל-Mac שאינכם סומכים עליו לגמרי, או ל-Mac שהמסך שלו משותף. בהפעלה ואחרי נעילה Keepit מבקש את הסיסמה (או Touch ID); “שחזור גישה…” מקבל במקומה את המשפט של 24 המילים, ראו [משפט שחזור](#recovery-phrase).

![ביטול נעילה בהפעלה: סיסמה, יציאה או משפט השחזור; “אישור” נשאר מושבת עד שמקלידים משהו. צולם מאותה סיבה כמו למעלה](site/img/guide/unlock-keyboard.jpg)

![הגדרות ← אבטחה](site/img/guide/prefs-security.png)

### Touch ID

עם “בטל נעילה באמצעות Touch ID” המפתח נשמר גם ב-Secure Enclave, מאחורי טביעת האצבע שלכם: Keepit מבקש נגיעה במקום הסיסמה. הסיסמה ממשיכה לפעול כגיבוי; בחרו ב“שימוש בסיסמה…” שבחלון הבקשה. כשהמכסה סגור ומחוברת Magic Keyboard חיצונית עם Touch ID, Keepit מבקש את הנגיעה במקלדת. “אפשר שינוי סיסמה באמצעות Touch ID” מאפשר לטביעת אצבע לבוא במקום הסיסמה הישנה כשמשנים אותה.

![ביטול נעילה באמצעות Touch ID; הסיסמה נשארת כגיבוי](site/img/guide/touch-id.png)

### משפט שחזור

כשמגדירים סיסמה, Keepit מציג פעם אחת משפט של 24 מילים. הדפיסו אותו או שמרו אותו במנהל סיסמאות. אם שכחתם את הסיסמה, “שחזור גישה…” שבתיבת ביטול הנעילה פותח את הנתונים ומאפשר להגדיר סיסמה חדשה. “משפט שחזור ← יצירת חדש…” מנפיק משפט חדש ומבטל את הישן; “הצגה…” שלידו מציג שוב את המשפט הנוכחי אחרי אימות ב-Touch ID או בסיסמה.

בלי הסיסמה, בלי Touch ID באותו Mac ובלי המשפט, אי אפשר לשחזר את הנתונים: אין שרת, ואין מה לאפס.

![משפט השחזור של 24 המילים (המילים מוסתרות כאן)](site/img/guide/recovery-phrase.png)

### גיבוי

Keepit יכול לשמור עותק מוצפן של ההיסטוריה ושל התבניות בתיקייה שתבחרו (iCloud Drive, Dropbox, Google Drive, דיסק חיצוני, NAS) ולכתוב עותק חדש בכל פעם שמשהו השתנה. אין שרת של Keepit: התיקייה שלכם. מה שהספק שמאחוריה יכול לראות הוא הקובץ המוצפן, הגודל שלו וכותרת קטנה לא מוצפנת (מתי ובאיזו גרסה של Keepit הקובץ נכתב, איך המפתח נגזר, מזהים אקראיים, ושם ה-Mac שלכם רק אם הפעלתם זאת); [עמוד האבטחה](/security#backups) (באנגלית) מפרט אותה שדה אחר שדה.

![הגדרות ← גיבוי: גיבוי אוטומטי, גיבוי ידני, שחזור](site/img/guide/prefs-backup.png)

**הפעלה.** “הגדרות ← גיבוי ← גיבוי אוטומטי לתיקייה”, ואז “בחירה…” של תיקייה (חלון הבחירה נפתח ב-iCloud Drive). גיבוי אוטומטי דורש את ההגנה בסיסמה מ“הגדרות ← אבטחה”: כל עותק מוצפן במפתח שנגזר ממפתח הכספת שלכם, ולכן הוא נפתח בסיסמת Keepit שלכם או במשפט השחזור, ב-Mac הזה או בכל Mac אחר, ואין צורך להגדיר לשם כך שום דבר נוסף. בלי סיסמה תיבת הסימון מושבתת ומציינת את הסיבה.

**מה קורה אחר כך: לוח הזמנים.** כחמש דקות אחרי השינוי האחרון (ולפחות פעם ביום כל עוד Keepit פועל) Keepit כותב לתיקייה קובץ בשם `Keepit-<תאריך ושעה>-<התקנה>-<מזהה>.keepit`, קורא אותו בחזרה כדי לבדוק אותו, ורק אז מוחק את הישנים ביותר מבין העותקים שלו שמעבר למספר שב“לשמור אחרונים” (10 כברירת מחדל, 1–100). כל עותק שלם בפני עצמו ואינו תוספת, כך שקובץ אחד הוא כל מה שתצטרכו. בעותקים ש-Mac אחר יצר, או בקבצים ששמתם שם בעצמכם, Keepit לא נוגע לעולם: שני מחשבי Mac שחולקים תיקייה כותבים שתי סדרות נפרדות. שורת המצב שליד הכותרת “גיבוי אוטומטי” מציגה את השעה והגודל של העותק האחרון, או את הסיבה שהניסיון האחרון נכשל. כש-Keepit נעול לא קורה דבר; “גבה עכשיו” (תחת “גיבוי ידני”) לא מחכה לתקופת השקט.

**לכלול את שם ה‑Mac הזה** (כבוי כברירת מחדל) מכניס את שם המחשב לכותרת הלא מוצפנת של כל קובץ, כך שקל להבחין ב-Finder בין שתי סדרות באותה תיקייה. ספק האחסון יכול לראות את השם הזה, ולכן האפשרות נתונה לבחירתכם.

**שחזור.** “שחזר…” פותח גיבוי (של ה-Mac הזה, של Mac אחר או קובץ שיוצא) אחרי שביטלתם את הנעילה שלו: בסיסמה של ה-Mac שבו הוא נוצר, או במשפט השחזור שאותו Mac הציג כשהוגדרה הסיסמה (“שחזור גישה…” בתיבת הסיסמה). תצוגה מקדימה מראה מתי ואיפה הקובץ נוצר וכמה פריטים יש בו. אחר כך יש שתי אפשרויות:

![התצוגה המקדימה של השחזור: מתי ובאיזו גרסה של Keepit הקובץ נכתב, מה יש בו, מזג או החלף](site/img/guide/restore-preview.png)

- “מזג” מוסיף את מה שעדיין אין: פריטי היסטוריה לפי תוכן, ואת התבניות מהגיבוי כתיקייה חדשה אחת בשם “יובא <תאריך>”, בלי מקשי הקיצור שלהן. כך רואים בדיוק מה הגיע מהגיבוי ואפשר להעביר או למחוק אותו. שום דבר משלכם לא נדרס.
- “החלף” משליך את ההיסטוריה ואת התבניות הנוכחיות ולוקח במקומן את אלה שבגיבוי. לפני כן Keepit כותב עותק של מה שיש לכם עכשיו (`Keepit-before-restore-…`) לתיקיית הגיבוי, או לתיקייה שתבחרו; אם אי אפשר לכתוב את העותק הזה, ההחלפה לא מתחילה. אם ל-Keepit עדיין אין סיסמה, תתבקשו להגדיר סיסמה לעותק הזה, כמו ב“שמירה לארכיון…”.

“שחזר גם העדפות” מביא מהגיבוי את מקשי הקיצור, המגבלות והאפשרויות. ההגדרות שמבטאות אמון ב-Mac מסוים (Touch ID, האוטומציה דרך URL והיישומים המהימנים שלה, תיקיית הגיבוי עצמה) נשארות תמיד כפי שהן כאן. אם ההיסטוריה שבגיבוי גדולה ממה שהמגבלות של ה-Mac הזה מתירות, Keepit אומר כמה ייכנס לפני שתאשרו.

שחזרתם גיבוי באמצעות משפט השחזור שלו ב-Mac שעדיין אין לו סיסמה? Keepit מבקש להגדיר קודם סיסמה, כדי שהנתונים המשוחזרים לעולם לא יישמרו בלי הצפנה, ומאפשר להשאיר את המשפט הזה ל-Mac הזה או לקבל משפט חדש. שחזרתם בסיסמה? Keepit מציע להשאיר אותה כסיסמה של ה-Mac הזה. בשני המקרים הגיבוי האוטומטי עצמו הוא הגדרה נפרדת לכל Mac: הפעילו אותו כאן ובחרו את התיקייה (אפשר את אותה תיקייה), וה-Mac הזה יתחיל סדרת קבצים משלו לצד הקבצים של ה-Mac הישן.

**מעבר ל-Mac חדש** הוא כל העניין: התקינו את Keepit, בחרו בהפעלה הראשונה ב“שחזור מגיבוי…”, בחרו את הקובץ החדש ביותר בתיקייה שלכם, הקלידו את הסיסמה של ה-Mac הישן ובחרו ב“החלף”; אחר כך הפעילו את הגיבוי האוטומטי ב-Mac החדש. העותקים שנוצרו עד אז נפתחים בסיסמה ובמשפט שהיו בתוקף כשכל אחד מהם נכתב: אחרי שינוי סיסמה, הישנים עדיין דורשים את הסיסמה הישנה.

**גיבוי ידני.** יש שני כפתורים, והם עושים שני דברים שונים. “גבה עכשיו” יוצר מיד עותק כמו האוטומטיים: אותו סוג קובץ, אותה תיקייה ואותה סדרה, והוא נפתח בסיסמת Keepit שלכם או במשפט. “שמירה לארכיון…” כותב *ארכיון* `.keepit` אחד במקום שתבחרו ונועל אותו בסיסמה שתבחרו בשבילו. הוא אינו דורש את ההגנה בסיסמה של Keepit, ו-Keepit לא עוקב אחרי הקובץ אחר כך. הוא מיועד למסירת נתונים או לעותק מחוץ לתיקיית הגיבוי. השם המוצע אומר מה זה: `Keepit-archive-<תאריך>-manual.keepit`, לעומת `Keepit-<תאריך ושעה>-<התקנה>-<מזהה>.keepit` של העותקים האוטומטיים.

![“שמירה לארכיון…”: בשם הקובץ מופיעות המילים archive ו-manual](site/img/guide/save-to-archive.png)

![הסיסמה של הארכיון עצמו, עם מד חוזק: היא לא נשמרת בשום מקום](site/img/guide/archive-password.png)

“שחזר…” פותח את שני הסוגים. הארכיון מחליף את “ייצוא…” / “ייבוא…” של 2.x. הקובץ מעביר נתונים בין המהדורה שמורידים מהאתר לבין מהדורת ה-App Store, ובין Keepit 2.x ל-3.x: קובץ שנכתב ב-3.0 דורש 3.0 ומעלה כדי להיפתח; 3.0 קורא כל מה ש-2.x כתב.

**אם משהו משתבש.** עותק שנכשל מדווח בשורת המצב, והניסיון חוזר בהפסקות הולכות וגדלות; העותקים הקודמים נשארים. אם יצאתם מ-Keepit או שה-Mac כבה באמצע שחזור, ההפעלה הבאה מחזירה בשקט את הכול למצב שלפני השחזור. במקרה הנדיר שזה לא אפשרי (קובץ שאי אפשר לכתוב, דיסק מלא), Keepit נוקב בשם הקובץ ויוצא בלי לשנות דבר: תקנו את הבעיה בקובץ והפעילו שוב. הפרטים, כולל המבנה הפנימי של פורמט הקובץ, נמצאים ב[עמוד האבטחה](/security#backups) (באנגלית).

## חלק 7: למתקדמים

### אוטומציה: סכמת ה-URL‏ keepit://

קיצורים (“פתיחת כתובות אינטרנט”), Raycast, Alfred, Keyboard Maestro או `open` בשורת הפקודה יכולים להפעיל את Keepit, **אחרי שתפעילו זאת** ב“הגדרות ← מתקדם ← אוטומציה ← אפשר פקודות URL של keepit://”. זה כבוי כברירת מחדל, כי כל יישום או עמוד אינטרנט יכולים לפתוח URL, ו-`add` / `paste` משנים את הלוח ומקלידים ביישום שבחזית; כשזה כבוי, Keepit מתעלם מכתובות כאלה ומשמיע צפצוף. כשזה מופעל, Keepit בודק מי פתח את ה-URL: הפקודה הראשונה מכל יישום שמשנה משהו (`paste`, `copy`, `template`, `add`, `add-template`, `pause`, `resume`) מוצגת בתיבת דו-שיח. “אפשר” מריץ אותה פעם אחת, “אפשר תמיד” מוסיף את היישום לרשימת המהימנים (מנקים אותה ב“שכח אפליקציות מהימנות” שבאותה חלונית). דפדפן אינטרנט, או שולח ש-macOS אינו יכול לזהות, נשאלים בכל פעם. פקודות שרק פותחות את החלונות של Keepit עצמו אינן שואלות לעולם.

| URL | השפעה |
|-----|--------|
| `keepit://paste/2`<br>`keepit://paste/latest`<br>`keepit://paste/previous` | מדביק את פריט N מההיסטוריה (או את האחרון / הקודם) ביישום שבחזית |
| `keepit://copy/3` | שם את פריט N בלוח בלי להדביק |
| `keepit://template/Signature`<br>`keepit://template/Work/Reply?copy=1` | מדביק (או מעתיק) תבנית לפי שם או לפי נתיב תיקייה |
| `keepit://add?text=…` | מוסיף טקסט להיסטוריה וללוח |
| `keepit://add-template?text=…&name=…` | יוצר תבנית |
| `keepit://history`<br>`keepit://templates`<br>`keepit://viewer`<br>`keepit://settings` | פותח את תפריט ההיסטוריה, את תפריט התבניות, את המציג, את ההגדרות |
| `keepit://pause`<br>`keepit://resume` | משהה את ההקלטה ל-10 דקות / מחדש אותה |

קודדו את הטקסט בקידוד אחוזים (`%20` לרווח). כש-Keepit נעול, מתעלמים מכתובות ה-URL.

### עדכונים

Keepit בודק את GitHub Releases פעם ביום ומציע עדכונים בתיבת דו-שיח; “בדוק עדכונים…” עושה זאת מיד. העדכונים חתומים (EdDSA) ואושרו על ידי Apple. עם Homebrew, `brew upgrade --cask keepit` עושה את אותו דבר. סכומי הביקורת של כל הורדה נמצאים ב-`SHA256SUMS` בעמוד הגרסה.

הבדיקה הזאת היא בקשת הרשת היחידה ש-Keepit שולח, והיא נתונה לבחירתכם: “הגדרות ← כללי ← עדכונים ← בדיקת עדכונים אוטומטית”. כשהיא כבויה, Keepit לא פונה לשום מקום, גם לא כשמבקשים ממנו, ו“בדוק עדכונים…” נעלם מהתפריטים. אז מעדכנים בהורדה מ-[keep.it.com](https://keep.it.com) או באמצעות Homebrew. במהדורת ה-App Store אין מעדכן ואין אפשרות כזאת; ה-App Store מעדכן אותה.

### הסרת ההתקנה

“הגדרות ← מתקדם ← איפוס והסרה ← הסרת התקנה…” מסיר את היישום, את תיקיית הנתונים, את הרשומות בצרור המפתחות (כולל המפתח של Touch ID), את פריט ההתחברות ואת הרשומה בנגישות. הוא מבקש את הסיסמה או Touch ID, הקלדה של `DELETE` ואישור. אם ייתכן שתרצו את הנתונים בחזרה, ייצאו קודם גיבוי. עם Homebrew הריצו אחר כך `brew uninstall --cask --force keepit`, כדי ש-Homebrew ישכח את ה-cask.

![הגדרות ← מתקדם](site/img/guide/prefs-advanced.png)

## עזר

### פתרון בעיות

**אחרי בחירת פריט לא מודבק דבר.** חסרה הרשאת הנגישות: “הגדרות המערכת ← פרטיות ואבטחה ← נגישות ← Keepit”. אם Keepit מופיע ברשימה ועדיין לא מדביק, כבו אותו והפעילו שוב. macOS שוכח את ההרשאה כשהיישום מותקן מחדש.

**מקש קיצור לא עושה כלום.** יישום אחר או macOS מחזיקים בו; Keepit מדווח על כך בהפעלה. בחרו צירוף אחר בחלונית “קיצורים”. הצירוף ‎⌃⌥‎ עם ספרות ואותיות פנוי ב-Mac במצב היצרן. או שזה קיצור ברירת מחדל ש‑Keepit השאיר פנוי מפני שהוא מקליד תו באחת מפריסות המקלדת שלכם; ההערה מתחת לשדה שלו בחלונית “קיצורי מקלדת” אומרת זאת. בחרו צירוף אחר, או לחצו על השדה והקישו את אותו צירוף כדי להשתמש בו בכל זאת. ‎⌃⌥V‎ לא מדביק דבר כל עוד תפריט של Keepit פתוח: macOS משתמש ב‑‎⌃V‎ (וגם ב‑‎⌃N‎ ו‑‎⌃P‎) כדי להזיז את הבחירה בתפריטים. סגרו קודם את התפריט, או החזיקו ‎⇧‎ ובחרו “הדבק כטקסט פשוט” בתפריט המשנה של הפריט. מאותה סיבה הקיצור של “נעל את Keepit” לא יכול להיות ‎⌃‎ עם V, N או P.

**התפריט נפתח במקום הלא נכון.** היישום שבו אתם נמצאים אינו חושף את סמן הטקסט שלו, ולכן התפריט נפתח ליד מצביע העכבר. “פתח את התפריט ליד סמן הטקסט כשאפשר” שבחלונית “כללי” מכבה את חיפוש הסמן, אם אתם מעדיפים תמיד את המצביע.

**משהו שהעתקתי חסר.** מה שהיישום המעתיק סימן כמוסתר אינו מתועד, וגם לא העתקה שנעשתה כשבחזית היה מנהל סיסמאות (רשימה מובנית) או יישום מרשימת ההתעלמות שלכם, כולל היישום שממנו עברתם לפני רגע. ראו “הגדרות ← היסטוריה” ואת [עמוד האבטחה](/security#what-is-not-recorded) (באנגלית).

**Touch ID אינו מוצע.** כרגע אין חיישן Touch ID זמין (המכסה סגור, אין מקלדת עם Touch ID). Keepit שומר על ההגדרה ומבקש את טביעת האצבע ברגע שחיישן נעשה זמין.

**מצב הגיבוי אומר שהתיקייה אינה זמינה.** התיקייה הועברה, שמה שונה, היא נותקה או (ב-iCloud Drive) הוסרה מהאחסון המקומי. חברו או שחזרו אותה, והעותק הבא ייכתב; או השתמשו ב“בחירה…” כדי לבחור תיקייה חדשה. תיקייה חדשה מתחילה סדרה חדשה, והקבצים הישנים נשארים במקומם.

**קובץ גיבוי לא נפתח.** “סיסמה שגויה” פירושו שתג האימות של הקובץ לא התאים: ודאו שאתם משתמשים בסיסמה של ה-Mac ש*כתב* את הקובץ (אחרי שינוי סיסמה, עותקים ישנים עדיין נפתחים בסיסמה הישנה), או במשפט השחזור שלו. “גיבוי זה דורש Keepit 3.0 או חדש יותר” פירושו שהקובץ נכתב בגרסה חדשה מזו שפותחת אותו.

**Homebrew מסרב להתקין מעל יישום קיים.** צאו קודם מ-Keepit והעבירו את `/Applications/Keepit.app` לפח האשפה, או הוסיפו `--force`.

עדיין לא הסתדר? [GitHub Issues](https://github.com/andrey-insarov/Keepit/issues) · admin@keep.it.com
