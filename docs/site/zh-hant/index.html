剪貼板歷史記錄隨手可得，按下 ⌥M 就行。

Keepit 是 Mac 上免費、開放原始碼的剪貼板管理工具。它會保存你拷貝過的所有內容，並把任何一個項目貼到你正在輸入的位置。範本能加快你每天重複輸入的文字工作。設定密碼後，資料會以加密形式儲存在磁碟上，並可用 Touch ID 解鎖。無論如何，資料都留在你的 Mac 上，不需要帳號，也不使用雲端儲存。你也可以選擇備份到自己的資料夾，這些備份同樣經過加密。定期檢查更新的功能可以關閉。

剪貼板歷史記錄：三個一分鐘就能記住的快速鍵

Keepit 常駐在選單列，不會打擾你。下面的快速鍵在任何 App 裡都能用，而且每一個都可以更改。

⌥M

歷史記錄選單

選單會在文字游標旁打開。直接輸入即可搜尋，按數字鍵或按一下，項目就會貼到游標所在的位置。按住 ⇧，每個項目都會出現子選單：純文字、大寫、刪除線文字、加入範本、刪除，以及其他功能。

⌃⌥1

不開選單直接貼上

⌃⌥1…⌃⌥0 會立即貼上第 1–10 個項目；⌥⇧V 會貼上前一個項目。⌃⌥V 以純文字貼上，⌃⌥U 以大寫貼上，⌃⌥T 則讓每個單字首字母大寫。

⌥T

範本

你一天要寄出許多次的簽名、地址和回覆都放在檔案夾裡，各有自己的快速鍵。佔位符會詢問姓名、插入今天的日期或剪貼板內容，並把游標留在你需要的位置。

會自動填寫的範本，也就是內建的文字片段管理工具

範本就是帶有佔位符的普通文字。貼上時，Keepit 會詢問需要的值、補上其餘文字，並把游標放在原本 {cursor} 所在的位置。

{input:姓名}，你好： 感謝你的訂購，商品將於 {date+2d:M月d日 EEEE}出貨。 追蹤編號：{clipboard} {cursor} Andrey 敬上
{date}{time}{clipboard}{input:…}{choice:a|b}{cursor}|upper|trim|url

文字、影像、檔案

帶格式的文字、附縮圖的截圖、來自 Finder 的檔案列表。重複的內容會合併成一筆記錄。

檢視器

一次搜尋所有項目、直接就地編輯，還能把歷史記錄拖到範本裡。狀態列會顯示每筆記錄的資訊。

Keepit 可搭配「捷徑」、Raycast 與 Alfred 使用

keepit:// URL 架構可以貼上第 N 個項目或依名稱貼上範本、把文字加入歷史記錄或範本，以及暫停記錄。不需要學習任何工序指令字典。這個選項預設為關閉，要到「設定」→「進階」中開啟後才會生效。

open "keepit://template/Signature" open "keepit://add?text=…" open "keepit://pause"

連續拷貝五段文字，再按同樣的順序貼上

按下 ⌥N，需要多少就拷貝多少（選單列上的計數器會幫你計數）。接著每按一次 ⌥V，就會按相同順序貼上一個。⌘V 照常運作。

只在選單列

在你主動打開之前，沒有 Dock 圖像，也沒有視窗。Keepit 會在登入時啟動，只佔用幾 MB，並且每 0.3 秒查詢一次剪貼板，所有剪貼板管理工具都是這樣運作的。

備份到任何資料夾：網路資料夾、iCloud、Dropbox 等等。這些資料同樣經過加密

選擇一個資料夾（iCloud 雲碟、Dropbox、磁碟），Keepit 就會在那裡保存完整的加密副本；在自動模式下，每次變更後幾分鐘就會製作一份副本。在任何一部 Mac 上都能用你的 Keepit 密碼或復原短語打開它們。儲存服務供應商看得到密文和一小段標頭，但看不到內容。Keepit 沒有伺服器，以後也不會有。和密碼一樣，這項功能你完全可以不開啟。

為個別 App 指定貼上按鍵

有些 App 用 ⌘⇧V 或 ⌃V 貼上。只要針對該 App 告訴 Keepit 一次，它就會在那裡使用正確的按鍵。

自動更新

App 以 Developer ID 簽署，並通過 Apple 公證。它每天檢查一次 GitHub Releases，按一下就能安裝更新；每個更新在執行前都會驗證簽名。檢查功能可以關閉，關閉後 Keepit 不會向網際網路發出任何請求。

隱私來自設計，而不是承諾

剪貼板管理工具看得到密碼、地址和寫到一半的訊息。Keepit 的設計確保這些內容不會流向任何你沒有主動選擇的地方。

沒有帳號、伺服器或自己的同步服務。沒有任何地方需要登入。
沒有App 內的分析、當機報告或追蹤器，連匿名的也沒有。網站只統計頁面瀏覽次數，不使用 Cookie。
一個網路請求：每天到 GitHub 檢查更新。這項檢查可以關閉；App Store 版本甚至沒有網路存取權限。你可以自行驗證（英文）。
一個位於你 Mac 上的資料夾，所有資料都在裡面。如果你有備份，還會多一個備份資料夾。把它們刪除，Keepit 就不留任何痕跡。
  • 設定密碼後，歷史記錄和範本會以 AES-256-GCM 加密儲存；密鑰透過 PBKDF2（200 000 次迭代）衍生，並在每次 Keepit 鎖定時從記憶體中清除。
  • 使用 Touch ID 解鎖。密碼仍可作為備用方式；只顯示一次的 24 個單字復原短語，能在你忘記密碼時打開資料。密碼可以在螢幕鍵盤上輸入：按鍵位置會打亂，而且不會產生可被記錄的鍵盤事件。
  • 為了保護隱私，Keepit 不會保存從 1Password、Bitwarden、KeePassXC、Apple「密碼」及其他密碼管理工具拷貝的內容，也不會保存來源 App 標示為隱藏的內容。排除的對象依 App 辨識（盡力而為，詳情為英文）。你也可以加入自己的排除項目。
  • Keepit 可以透過選單或快速鍵鎖定，也可以選擇在 Mac 持續鎖定或睡眠達到設定的時間後鎖定。這個選項預設為關閉，可在設定中開啟。原始碼公開，可從帶標籤的提交重現建置，簽署密鑰保存在受保護的儲存環境中。安全性頁面（英文）

常見問題

Keepit 為什麼需要「輔助使用」權限？

有兩個用途。第一，在你選擇項目後，把 ⌘V 傳送到你原本使用的 App。第二，找出文字游標的位置，好讓選單在它旁邊打開。Keepit 不會讀取或監視其他 App。如果不授予權限，它仍會記錄歷史記錄，並把所選項目放到剪貼板上，只是需要你自己貼上。

會有任何東西離開我的 Mac 嗎？

資料只儲存在本機，也就是你自己的電腦上。Keepit 沒有伺服器。唯一的網路請求是每天到 GitHub Releases 檢查更新，你可以在「設定」→「一般」中把它關閉，之後 Keepit 就不會發出任何請求。App Store 版本連這個請求也不會發出。沒有帳號、沒有遙測，也沒有當機報告。只有在你開啟自動備份到雲端資料夾時，資料才會進入網際網路：加密的副本會寫入你選擇的資料夾，如果該資料夾位於 iCloud 雲碟或 Dropbox 中，就由該服務以你的帳號進行同步。Keepit 本身不會與它連線。

忘記密碼怎麼辦？

你可以使用開啟保護時 Keepit 顯示的 24 個單字復原短語，或在同一部 Mac 上使用 Touch ID。兩者都沒有的話，資料就無法復原。這是刻意的設計。

真的免費嗎？有什麼附帶條件？

是的，完全免費：App 以 MIT 授權條款釋出，程式碼放在 GitHub 上。Keepit 是 it.com 網域區的創辦人為了自己使用而製作的，後來才想到它可以成為展示 it.com 用途的好例子。所以這裡沒有廣告、沒有 App 內購買，也沒有付費版本：使用這個程式本身就是在向大家介紹我們的服務。

怎麼會想到要做這樣一款 App？

Keepit 最初是想把 Windows 經典剪貼板工具 CLCL 的工作方式搬到 macOS 上，後來成長為一款獨立的 App。它以 Swift 從零寫成，並吸收了許多剪貼板與文字片段管理工具的想法。本專案與 CLCL 的作者沒有關聯，但我們感謝他帶來的靈感。

如何把資料轉移到另一部 Mac，或在不同版本之間轉移？

開啟「設定」→「備份」→「自動備份到資料夾」，然後選擇 iCloud 雲碟（或任何資料夾）：Keepit 會在那裡保存完整的加密 .keepit 副本。在新的 Mac 上首次啟動時選擇「從備份還原…」，輸入舊 Mac 的密碼或復原短語，再選擇「取代」或「合併」。如果只是匯出一次，可以使用「儲存為封存檔…」，它有自己的密碼。所有內容都以 AES-256-GCM 加密，所以 USB 隨身碟或雲端資料夾都適用。同一個檔案在兩種版本中都能使用。

支援哪些 Mac？

macOS 13 Ventura 或以上版本，Apple 晶片與 Intel。使用 Touch ID 解鎖需要配備 Touch ID 的 Mac。
