剪贴板历史记录，按 ⌥M 即可调出。

Keepit 是一款免费开源的 Mac 剪贴板管理工具。它会保存你复制过的所有内容，并把其中任意一项粘贴到你正在输入的位置。每天都要输入的文字可以存成模板，用起来更快。设置密码后，数据会加密保存在磁盘上，并可用 Touch ID 解锁。无论是否设置密码，数据都留在你的 Mac 上，不需要账户，也不使用云存储。你还可以选择把备份存到自己的文件夹里，备份同样是加密的。定期检查更新的功能可以关闭。

剪贴板历史记录：三个按键，一分钟就能记住

Keepit 常驻菜单栏，不打扰你工作。下面的快捷键在任何应用里都能用，而且每一个都可以更改。

⌥M

历史记录菜单

菜单会在文本光标旁边打开。输入文字即可搜索，按数字键或点按某一项，它就会粘贴到光标所在的位置。按住 ⇧ 时，每一项都会出现子菜单，里面有纯文本、大写、删除线、添加到模板、删除等操作。

⌃⌥1

不打开菜单直接粘贴

⌃⌥1…⌃⌥0 直接粘贴第 1 到第 10 项，⌥⇧V 粘贴上一项。⌃⌥V 以纯文本粘贴，⌃⌥U 转成大写后粘贴，⌃⌥T 把每个单词的首字母大写后粘贴。

⌥T

模板

签名、地址、每天要发好多遍的回复，都可以放进文件夹，并各自设置快捷键。占位符可以询问姓名，插入当天的日期或剪贴板内容，并把光标留在你需要的位置。

会自动填写的模板：内置的文本片段管理器

模板就是带占位符的普通文本。粘贴时，Keepit 会询问所需的值，填好其余内容，并把光标放在 {cursor} 原来的位置。

{input:姓名}，你好： 感谢你的订购，商品将于 {date+2d:M月d日EEEE} 发出。 快递单号：{clipboard} {cursor} 祝好，Andrey
{date}{time}{clipboard}{input:…}{choice:a|b}{cursor}|upper|trim|url

文本、图片、文件

支持带格式的文本、带缩略图的截屏，以及来自访达的文件列表。重复的内容会合并成一项。

查看器

可以一次搜索所有项目，就地编辑，还能把历史记录拖到模板里。状态栏会显示每一项的详细信息。

可与快捷指令、Raycast 和 Alfred 配合使用

通过 keepit:// URL 方案，可以粘贴第 N 项或按名称粘贴模板，把文本添加到历史记录或模板，以及暂停记录。不需要学习脚本字典。这项功能默认关闭，需要你在“设置”→“高级”中打开。

open "keepit://template/Signature" open "keepit://add?text=…" open "keepit://pause"

连续复制五段文字，再按原顺序粘贴

按 ⌥N，然后想复制多少就复制多少，菜单栏里的计数器会帮你计数。之后每按一次 ⌥V，就按原来的顺序粘贴一项。⌘V 照常可用。

只在菜单栏中运行

程序坞里没有图标，你不打开就不会出现窗口。Keepit 在登录时启动，只占用几兆字节内存，每 0.3 秒检查一次剪贴板，所有剪贴板管理工具都是这样工作的。

备份到任意文件夹：网络文件夹、iCloud、Dropbox 等，备份同样加密

选一个文件夹（iCloud 云盘、Dropbox 或某个磁盘），Keepit 就会在其中保存完整的加密副本。在自动模式下，每次有改动后几分钟就会生成一份新副本。在任何一台 Mac 上，都可以用你的 Keepit 密码或恢复短语打开这些副本。存储服务商只能看到密文和一小段文件头，看不到内容。Keepit 没有服务器，以后也不会有。和密码一样，这项功能不想用可以不开。

为不同的应用设置粘贴键

有些应用用 ⌘⇧V 或 ⌃V 粘贴。针对这样的应用告诉 Keepit 一次，它以后就会在那里使用正确的按键。

自动更新

应用使用 Developer ID 签名，并通过了 Apple 公证。它每天检查一次 GitHub Releases，点按一下即可安装更新。每个更新在运行前都会验证签名。检查更新可以关闭，关闭后 Keepit 不会发出任何网络请求。

隐私靠设计来保证，而不是靠承诺

剪贴板管理工具会看到密码、地址和写到一半的信息。Keepit 的设计保证了这些内容不会去往任何你没有亲自选择的地方。

没有账户、服务器，也没有自己的同步服务。根本没有需要登录的地方。
没有应用内的分析、崩溃报告和跟踪器，匿名的也没有。网站只统计页面浏览量，不使用 Cookie。
一个网络请求：每天到 GitHub 检查一次更新。这项检查可以关闭。App Store 版本连网络访问权限都没有，你可以自己验证（英文）。
一个文件夹，所有数据都在你 Mac 上的这个文件夹里。如果你做了备份，还有一个备份文件夹。把它们删掉，Keepit 就不留任何痕迹。
  • 设置密码后，历史记录和模板会用 AES-256-GCM 加密保存。密钥通过 PBKDF2（200,000 轮）派生，每次 Keepit 锁定时都会从内存中清除。
  • 可用 Touch ID 解锁。密码仍可作为备用方式。恢复短语由 24 个单词组成，只显示一次，忘记密码时可以用它打开数据。密码可以在屏幕键盘上输入：按键位置每次都会打乱，也不会产生可被记录的键盘事件。
  • 为了保护隐私，从 1Password、Bitwarden、KeePassXC、Apple“密码”等密码管理器复制的内容，以及来源应用标记为隐藏的内容，Keepit 都不会保存。排除是按应用来识别的（尽力而为，具体方式见此，英文）。你也可以添加自己的排除项。
  • Keepit 可以通过菜单或快捷键锁定，也可以按你的选择，在 Mac 锁定或睡眠超过设定的时间后自动锁定。自动锁定默认关闭，可在设置中打开。源代码是公开的，构建可以从带标签的提交重现，签名密钥保存在受保护的环境中。安全说明页面（英文）

常见问题

Keepit 为什么要请求辅助功能权限？

有两个用途。第一，在你选好项目之后，向你刚才使用的应用发送 ⌘V。第二，找到文本光标的位置，把菜单打开在它旁边。Keepit 不会读取或监视其他应用。不给这项权限，它照样会记录历史，并把选中的项目放进剪贴板，只是需要你自己来粘贴。

有什么数据会离开我的 Mac 吗？

数据只保存在本地，也就是你自己的电脑上。Keepit 没有服务器。唯一的网络请求是每天到 GitHub Releases 检查一次更新，你可以在“设置”→“通用”中把它关掉，之后 Keepit 就不再发出任何请求。App Store 版本连这个请求也没有。没有账户，没有遥测，也没有崩溃报告。只有当你开启了自动备份，并把备份文件夹选在云端时，数据才会进入互联网：加密的副本会写入你选择的文件夹，如果这个文件夹位于 iCloud 云盘或 Dropbox 中，相应的服务会用你的账户同步它们。Keepit 本身不会与这些服务通信。

忘记密码怎么办？

可以使用开启保护时 Keepit 显示的 24 个单词的恢复短语，或者在同一台 Mac 上使用 Touch ID。两者都没有的话，数据无法恢复。这是有意这样设计的。

真的免费吗？有什么附加条件？

是的，完全免费。应用以 MIT 许可证发布，代码放在 GitHub 上。Keepit 是域名区 it.com 的创始人为自己使用而开发的，后来他想到，这个应用正好可以作为 it.com 域名用途的一个好例子。所以这里没有广告，没有应用内购买，也没有付费版本：大家使用这个程序，本身就是在向人们介绍我们的服务。

为什么想到做这样一个应用？

Keepit 起初是想把 Windows 上的经典剪贴板工具 CLCL 的使用方式搬到 macOS 上，后来发展成了一款独立的应用，完全用 Swift 从头编写，并吸收了许多剪贴板管理工具和文本片段管理工具的想法。本项目与 CLCL 的作者没有关联，但我们感谢他带来的启发。

怎样把数据转移到另一台 Mac，或者在不同版本之间转移？

打开“设置”→“备份”→“自动备份到文件夹”，并选择 iCloud 云盘（或任意文件夹）。Keepit 会在其中保存完整的加密 .keepit 副本。在新 Mac 上首次启动时选取“从备份恢复…”，输入旧 Mac 的密码或恢复短语，然后选择“替换”或“合并”。如果只想导出一次，可以用“保存为归档…”，并为它单独设置密码。所有内容都用 AES-256-GCM 加密，所以放在 U 盘或云端文件夹里都可以。同一个文件在两个版本中都能使用。

支持哪些 Mac？

支持 macOS 13 Ventura 或更高版本，Apple 芯片和 Intel 均可。使用 Touch ID 解锁需要配备 Touch ID 的 Mac。
