기능개인정보 보호설치사용 설명서보안지원

클립보드 기록을 언제든 꺼내 쓰세요. ⌥M만 누르면 됩니다.

Keepit은 Mac용 무료 오픈 소스 클립보드 관리자입니다. 복사한 모든 것의 기록을 보관하고, 원하는 항목을 지금 입력하고 있는 곳에 붙여넣습니다. 템플릿은 매일 입력하는 텍스트 작업을 빠르게 해 줍니다. 암호를 설정하면 데이터가 디스크에 암호화되어 저장되고 Touch ID로 잠금을 해제합니다. 어떤 경우에도 데이터는 계정이나 클라우드 저장 없이 내 Mac에 남습니다. 원하면 내 폴더로 백업하도록 설정할 수 있고, 백업 데이터도 암호화됩니다. 정기적인 업데이트 확인은 끌 수 있습니다.

클립보드 기록: 1분이면 익히는 단축키 세 개

Keepit은 메뉴 막대에 자리하며 작업을 방해하지 않습니다. 아래 단축키는 모든 앱에서 작동하고, 하나하나 바꿀 수 있습니다.

⌥M

기록 메뉴

텍스트 커서 옆에 열립니다. 입력해서 검색하거나 숫자를 누르거나 클릭하면 항목이 커서 위치에 붙여넣어집니다. ⇧를 누르고 있으면 항목마다 하위 메뉴가 나타납니다. 서식 없는 텍스트, 대문자, 취소선 텍스트, 템플릿에 추가, 삭제 등의 기능이 있습니다.

⌃⌥1

메뉴 없이 붙여넣기

⌃⌥1…⌃⌥0은 1–10번 항목을 바로 붙여넣고, ⌥⇧V는 이전 항목을 붙여넣습니다. ⌃⌥V는 서식 없는 텍스트로, ⌃⌥U는 대문자로, ⌃⌥T는 단어 첫 글자 대문자로 붙여넣습니다.

⌥T

템플릿

하루에도 여러 번 보내는 서명, 주소, 답장을 폴더에 넣어 두고 전용 단축키로 불러옵니다. 자리표시자는 이름을 묻고, 오늘 날짜나 클립보드 내용을 넣고, 커서를 원하는 위치에 둡니다.

스스로 채워지는 템플릿, 곧 내장 스니펫 관리자

템플릿은 자리표시자가 들어 있는 일반 텍스트입니다. 붙여넣을 때 Keepit이 필요한 값을 묻고 나머지 텍스트를 채운 다음 {cursor}가 있던 자리에 커서를 둡니다.

{input:이름}님, 안녕하세요. 주문해 주셔서 감사합니다. 상품은 {date+2d:M월 d일 EEEE}에 발송됩니다. 운송장 번호: {clipboard} {cursor} 감사합니다. Andrey 드림
{date}{time}{clipboard}{input:…}{choice:a|b}{cursor}|upper|trim|url

텍스트, 이미지, 파일

서식 있는 텍스트, 축소판이 있는 스크린샷, Finder의 파일 목록. 중복 항목은 하나로 합쳐집니다.

뷰어

모든 항목을 한 번에 검색하고, 그 자리에서 편집하고, 기록을 템플릿으로 드래그하세요. 상태 막대에 각 항목의 정보가 표시됩니다.

Keepit은 단축어, Raycast, Alfred와 함께 작동합니다

keepit:// URL 체계로 N번 항목이나 이름으로 지정한 템플릿을 붙여넣고, 기록이나 템플릿에 텍스트를 추가하고, 기록을 일시 정지할 수 있습니다. 스크립팅 사전을 배울 필요가 없습니다. 이 옵션은 설정 → 고급에서 켜기 전까지 꺼져 있습니다.

open "keepit://template/Signature" open "keepit://add?text=…" open "keepit://pause"

텍스트 다섯 개를 연달아 복사하고 같은 순서로 붙여넣기

⌥N을 누르고 필요한 만큼 복사하세요(메뉴 막대의 카운터가 개수를 셉니다). 그런 다음 ⌥V를 누를 때마다 같은 순서로 하나씩 붙여넣어집니다. ⌘V는 평소처럼 작동합니다.

메뉴 막대에만

직접 열기 전에는 Dock 아이콘도 윈도우도 없습니다. 로그인할 때 실행되고, 몇 메가바이트만 차지하며, 다른 모든 클립보드 관리자처럼 0.3초마다 클립보드를 확인합니다.

네트워크 폴더, iCloud, Dropbox 등 원하는 폴더로 백업. 백업 데이터도 암호화됩니다

폴더(iCloud Drive, Dropbox, 디스크)를 선택하면 Keepit이 그곳에 암호화된 전체 사본을 보관합니다. 자동 모드에서는 변경이 있을 때마다 몇 분 뒤에 사본이 만들어집니다. 사본은 어느 Mac에서든 Keepit 암호나 복구 문구로 열 수 있습니다. 저장소 제공업체는 암호문과 짧은 헤더만 볼 수 있고 내용은 볼 수 없습니다. Keepit 서버는 없으며 앞으로도 없을 것입니다. 암호와 마찬가지로 이 기능도 켜지 않고 그냥 둘 수 있습니다.

앱마다 다른 붙여넣기 키

어떤 앱은 ⌘⇧V나 ⌃V로 붙여넣습니다. 앱별로 한 번만 지정해 두면 Keepit이 그 앱에서 알맞은 키를 사용합니다.

스스로 업데이트

앱은 Developer ID로 서명되고 Apple의 공증을 받았습니다. 하루에 한 번 GitHub Releases를 확인하고 클릭 한 번으로 업데이트를 설치하며, 모든 업데이트는 실행 전에 서명을 검증합니다. 확인 기능은 끌 수 있고, 끄면 Keepit은 인터넷으로 어떤 요청도 보내지 않습니다.

약속이 아니라 설계로 지키는 개인정보

클립보드 관리자는 암호, 주소, 쓰다 만 메시지를 봅니다. Keepit은 그중 어느 것도 사용자가 직접 보내려 하지 않은 곳으로 나가지 않도록 만들어졌습니다.

없음계정, 서버, 자체 동기화가 없습니다. 로그인할 곳이 없습니다.
없음앱에는 분석, 충돌 보고서, 추적기가 없습니다. 익명으로도 수집하지 않습니다. 웹사이트는 쿠키 없이 페이지 조회수만 셉니다.
1개네트워크 요청은 하나뿐입니다. 하루에 한 번 GitHub에서 업데이트를 확인하는 요청입니다. 끌 수 있으며, App Store 버전에는 네트워크 권한 자체가 없습니다. 직접 확인해 보세요(영어).
1개모든 데이터는 Mac의 폴더 하나에 들어 있습니다. 백업을 만든다면 백업 폴더가 하나 더 있습니다. 이 폴더들을 삭제하면 Keepit의 흔적은 남지 않습니다.
  • 암호를 설정하면 기록과 템플릿이 AES-256-GCM으로 암호화되어 저장됩니다. 키는 PBKDF2(200 000회 반복)로 파생되며 Keepit이 잠길 때마다 메모리에서 지워집니다.
  • Touch ID로 잠금 해제. 암호는 대체 수단으로 남아 있고, 한 번만 표시되는 24단어 복구 문구는 암호를 잊었을 때 데이터를 열어 줍니다. 암호는 화면 키보드로 입력할 수 있습니다. 키 배열이 섞여 있고, 기록될 수 있는 키보드 이벤트가 발생하지 않습니다.
  • 개인정보 보호를 위해 Keepit은 1Password, Bitwarden, KeePassXC, Apple 암호 앱 등 암호 관리자에서 복사한 내용과, 복사한 앱이 숨김으로 표시한 내용을 저장하지 않습니다. 예외 대상은 앱을 기준으로 인식합니다(가능한 범위 내에서, 자세한 내용은 영어). 직접 예외를 추가할 수도 있습니다.
  • Keepit은 메뉴나 단축키로 잠글 수 있고, 원하면 Mac이 지정한 시간 동안 잠겨 있거나 잠자기 상태였을 때 잠기게 할 수도 있습니다. 이 옵션은 기본적으로 꺼져 있으며 설정에서 켭니다. 소스 코드는 공개되어 있고, 빌드는 태그가 지정된 커밋에서 재현할 수 있으며, 서명 키는 보호된 저장소에 보관됩니다. 보안 페이지(영어)

쉽게 설치하고 편하게 사용하세요

데이터 형식은 모든 에디션에서 같습니다. 암호화된 백업 파일로 언제든지 컴퓨터 간에 데이터를 옮길 수 있습니다.

질문

Keepit에 손쉬운 사용 권한이 왜 필요한가요?

두 가지 일에 필요합니다. 첫째, 항목을 선택한 뒤 작업 중이던 앱으로 ⌘V를 보내기 위해서입니다. 둘째, 텍스트 커서를 찾아 그 옆에 메뉴를 열기 위해서입니다. Keepit은 다른 앱을 읽거나 감시하지 않습니다. 권한이 없어도 기록은 계속 남기고 선택한 항목을 클립보드에 넣지만, 붙여넣기는 직접 해야 합니다.

내 Mac 밖으로 나가는 것이 있나요?

데이터는 내 컴퓨터에만 로컬로 저장됩니다. Keepit에는 서버가 없습니다. 유일한 네트워크 요청은 하루에 한 번 GitHub Releases에서 업데이트를 확인하는 것이며, 설정 → 일반에서 끌 수 있습니다. 끄고 나면 Keepit은 어떤 요청도 보내지 않습니다. App Store 버전은 그 요청조차 보내지 않습니다. 계정도, 원격 측정도, 충돌 보고서도 없습니다. 데이터가 인터넷으로 나가는 경우는 클라우드 폴더로 자동 백업을 켰을 때뿐입니다. 암호화된 사본이 선택한 폴더에 기록되고, 그 폴더가 iCloud Drive나 Dropbox에 있으면 해당 서비스가 사용자 계정으로 사본을 동기화합니다. Keepit이 그 서비스에 직접 연결하지는 않습니다.

암호를 잊어버리면 어떻게 되나요?

보호 기능을 켤 때 Keepit이 보여 준 24단어 복구 문구나 같은 Mac의 Touch ID를 사용할 수 있습니다. 둘 다 없으면 데이터를 복구할 수 없습니다. 의도된 설계입니다.

정말 무료인가요? 숨은 조건이 있나요?

네, 완전히 무료입니다. 앱은 MIT 라이선스로 공개되어 있고 코드는 GitHub에 있습니다. Keepit은 it.com 도메인 영역의 설립자가 직접 쓰려고 만들었고, it.com의 좋은 활용 사례가 될 수 있겠다는 생각은 그 뒤에 나왔습니다. 그래서 광고도, 앱 내 구입도, 유료 버전도 없습니다. 프로그램을 쓰는 것 자체가 사람들에게 저희 서비스를 알려 줍니다.

이런 앱을 만들 생각은 어떻게 하게 되었나요?

Keepit은 Windows의 고전적인 클립보드 유틸리티 CLCL의 작업 방식을 macOS로 옮기는 것에서 시작해 독립적인 앱으로 자랐습니다. Swift로 처음부터 작성했고 여러 클립보드 관리자와 스니펫 관리자의 아이디어를 담았습니다. 이 프로젝트는 CLCL의 제작자와 관련이 없지만, 영감을 준 데 대해 감사하고 있습니다.

데이터를 다른 Mac이나 다른 에디션으로 옮기려면 어떻게 하나요?

설정 → 백업 → 폴더에 자동으로 백업을 켜고 iCloud Drive(또는 아무 폴더)를 선택하세요. Keepit이 그곳에 암호화된 전체 .keepit 사본을 보관합니다. 새 Mac에서는 처음 실행할 때 백업에서 복원…을 선택하고 이전 Mac의 암호나 복구 문구를 입력한 다음 대치 또는 병합을 선택합니다. 일회성 내보내기에는 별도의 암호를 쓰는 아카이브로 저장…이 있습니다. 모든 것이 AES-256-GCM으로 암호화되므로 USB 메모리든 클라우드 폴더든 괜찮습니다. 같은 파일이 두 에디션 모두에서 작동합니다.
